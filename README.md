# STARLIT GUILD — 星灯りの旅団

仲間が同時に歩き、戦い、採取する日本語の放置RPG。クリックを重ねて手助けできます。

## 遊び方

アリアとレオンの2人、1つの採取依頼から開始。出発するまでは進みません。達成数に応じて依頼や出会い、装備、野営地が解放されます。新しい仲間は資材と希少素材を集めて専用クエストを開き、その冒険を達成すると加入します。能力は参加条件ではなく目安です。

- 仲間と敵は独立した時計で行動。二連矢、踏み込み、回復、障壁、流星など9人固有の特技・動作があります。
- マップの背景・敵・素材をタップすると手助け、仲間・HP表示をタップすると回復。休憩中はマップのどこでも回復でき、回数制限はありません。移動中も先回りして手伝えます。
- 体力がなくなると休憩・再挑戦。達成後は自動周回し、「帰還」でいつでも戻れます。
- 仲間4人で2隊、6人で3隊。同じ仲間は複数の隊に所属できません。
- 森、山地、水晶の洞窟、古塔で背景が変化。効果音は最初の操作から有効、セーブ画面でオフにできます。
- 1周は15地点（従来の5倍）。3地点ごとに報酬を確保するので途中で帰還しても区間報酬は残ります。依頼一覧の報酬は5区間分の基本合計です。
- 手助け・回復で応援が5たまり、100で全員必殺技。ゲージは地点・周回を越えて持ち越します。
- 寄り道に探索好きの仲間が向かい、宝箱・薬草・精霊と木材を発見。クリックすると優先して調べます。放置でも回収し、保存・再開で二重取得しません。
- 相性のよいペアは約14.5秒ごとに会話と連携技。区間をともに進むと絆が育ち、12・24で連携レベルと会話が変化します。
- 拠点は焚き火→酒場→鍛冶場と薬草園へ発展。木材などを消費して建設し、待機中の仲間がお茶や訓練などをして過ごします。酒場は1件、鍛冶場・薬草園は3件達成後に建設可能です。

## 画面の使い方

- **冒険**：隊名から見守る隊を切り替え、「行き先を選ぶ」で依頼と報酬を比べて出発します。開いている間の行き先選択は隊ごとに保持します。冒険中は「帰還」で戻れます。別の行き先に変えるときも帰還を確認し、自動では再出発しません。
- **パーティ**：隊を一覧で選び、仲間の顔を押して編成します。他の隊への所属も表示します。新しい隊は作成後に選択され、すぐ編成できます。未保存の変更を残して移動するときは、保存・破棄・編成に戻るを選べます。
- **拠点**：建設・強化・差し入れと、仲間の日常を楽しめます。
- **思い出**：未読の物語はタブの赤丸でお知らせ。「未読」で絞り込み、スチルは一覧または会話の画像タップから鑑賞できます。途中で出るスチルは、その話の読了後に鑑賞一覧へ追加します。鑑賞だけでは既読にならず、閉じると元の読書位置に戻ります。

BGM・効果音は、横長のスイッチとON/OFFの文字で状態を表示します。出発済みの冒険は、思い出やスチルを開いている間も進み、報酬通知は鑑賞の邪魔にならないよう非表示になります。

## アリアとレオンの物語

幼なじみで互いを大切に思いながら、まだ気持ちを言い出せないふたりの物語を追加しています。全9依頼に出発と達成後のひと幕、拠点には5つの日常会話があります。

- ふたりを同じ隊に編成して初めて出発するときは、短い物語を読んでから冒険を始めます。途中で戻った場合はキャンプで待機し、読み終えて出発すると「旅の思い出」に残ります。再出発や自動周回では繰り返し開きません。
- ふたりで依頼を終えると後日談が読めます。山道の「星見の巡礼団」には、手を離さなかった日の焚き火の会話があります。留守中の達成でも話は残り、周回は止まりません。
- 道中の掛け合いは寄り道・休憩・行き先・絆に応じて変わります。タップするとそのやり取りを静止した文章で読めます。ふたりの連携技の台詞も絆ごとに変わります。
- 拠点では、ふたりが帰っていると会話を開けます。酒場や絆に応じて話が増え、ミラがお茶を置く場面はミラも拠点にいるときに表示します。「旅の思い出」では解放済みの話をいつでも読めます。
- 「パーティ → アリア／レオンの詳しく」で普段の癖を読めます。ふたりの気持ちは、物語の台詞やしぐさから感じ取れるように描きます。
- 冒険・日常・仲間の加入に合わせたスチルが全13枚あります。地図、焚き火、洞窟の灯り、袖の修繕、押し花、星の祭り、ミラのお茶、ガルの荷物、ルナの星図、ポピーの薬草園を描きます。会話の該当ページから表示され、読了後は「思い出」の鑑賞一覧でも見られます。制作記録と場面ごとの対応は [スチル制作記録](docs/story-art.md) にまとめています。

物語を読むことによる報酬や能力の変化はありません。進行中の冒険は読みながらも続きます。v4の記録に任意の `story`（ふたりで出発・達成した依頼、読了した話）を追加し、端末・ファイル・クラウドコピーで保存します。追加前の記録では、達成済みの依頼の物語を読み返せるように引き継ぎ、起動時の強制再生は行いません。編成が別々の場合は、新しいふたりの冒険の記録や掛け合いを発生させません。

## 仲間になるまで

「パーティ」の「新しい出会い」から、7人それぞれの事情を知り、資材と希少素材を使って専用クエストを開きます。お金だけでの即時加入はありません。ミラの往診、フィンの宝物探し、ガルの橋の護衛など、15地点の冒険を最後まで達成すると、その人物が加入して隊は帰還します。

- 希少素材は、指定の通常依頼を規定回数達成するごとに必ず1個。集め先、必要数、次の1個までの回数を表示します。「持ちもの」にも素材の記録があります。
- 出会いの前に進めた依頼も数えます。出会いはミラからノエルまで、前の仲間を通じて順につながります。
- 各人物に「出会い・準備の途中・支度の完成・加入」の4話、計28話があります。希少素材が半分集まると途中の話が開き、すべて「旅の思い出」で読み返せます。
- 支度の消費は一度だけ。途中帰還や休憩でも開放済みのクエストは残り、再挑戦に追加費用はかかりません。複数の隊が同じ加入クエストへ重複して出発することはできません。
- 留守中も素材の探索と専用クエストは進みます。加入後は編成へ自動挿入せず、「パーティ」から選べます。自動周回の設定自体は保ち、加入クエストだけは一度で帰還します。
- 既存の仲間は失われません。追加前の達成記録も素材集めに数え、既存加入者の物語は読み返せます。v4へ任意の `recruitment.prepared` を追加し、支払いと開放を端末・ファイル・クラウドコピーに記録します。

制作資料：[人物設定](docs/characters.md)・[物語の制作指針](docs/story-writing.md)・[加入の条件とバランス](docs/recruitment.md)。これらの資料はゲーム画面に読み込ませません。

## セーブとアクセス

サイトは所有者のみの限定公開。サイト閲覧の認証とゲーム用アカウントは別であり、ゲーム専用の登録・ログインはありません。ソースと開発履歴は非公開の [upu/starlit-guild](https://github.com/upu/starlit-guild) で管理し、Sitesへの公開時にはSites専用Gitにも保存します。

ユーザーの明示指定により、進行の正本は端末のlocalStorage（`starlit-guild-v4`）。約1秒ごと・各操作・ページを離れる際に保存します。開いている間は約5分ごとにSitesが管理するD1データベースへスナップショットをバックアップします。通信待ちは出発・手助けを無効化しません。閉じている間はクラウド送信しません。再開時に最大12時間分を端末で精算します。

Sitesの閲覧アカウントが取得できる場合、そのIDでバックアップを分離します。認証情報を持たないローカル環境などではHttpOnlyのランダムCookieによるゲスト識別を使います。ゲーム内に追加のログイン画面はありません。バックアップはユーザーと端末ごとに分離し、古い通信で新しい保存を上書きしないよう連番で更新します。復元は新しい記録を追加し、元の記録を残します。

「セーブ・設定」から最初から遊ぶ記録、テスト用記録を追加・切替できます（最大12個）。テスト用だけに序盤・中盤・全解放と達成数・レベル・所持金の調整を表示します。記録を切り替えると、その記録の留守中の冒険が精算されます。通常の冒険にテスト用の資源は混ざりません。ファイル保存は選択中の記録を含み、読み込みは別の記録として追加します。

v1/v2のサーバー上の記録は変更せず、読み込み時に「以前の冒険」として追加します。初回の選択は新しい冒険なので、最初の出発を確認できます。旧APIと旧形式の精算コードは互換性のため残しています。

v3の端末記録・ファイル・クラウドコピーをv4へ引き継ぎます。元の端末キーは残します。既存の進行中の依頼は3地点で終えてから次の周回で15地点へ移行します。旧ページからのバックアップが、新しい形式の保存を上書きすることはできません。

複数タブでは期限付きの端末内リースで書き込みを1タブに絞ります。「このタブで続ける」で引き継げます。ブラウザーのデータを消すと端末の保存は消えるので、クラウドまたはダウンロードしたファイルから復元してください。端末の時計を用いる個人向けゲームであり、競争用の不正対策は含みません。

## 開発

### スマホでの冒険の案内

- 上部の「ヒント」から、初回の出発・手助け・区間報酬・最初の酒場へ案内します。以降は建設、仲間加入、新しい依頼など、現在の進行に合う行動を表示します。新しい案内に赤丸を付け、開いた案内は端末・記録ごとに既読にします。素材の残数だけの変化では赤丸を付け直しません。
- 初達成・レベルアップ・依頼解放・仲間加入・建設・区間報酬を短い通知で伝えます。周回は止めません。建設すると完成した拠点へ移り、酒場・鍛冶場・薬草園や絆に応じて仲間の過ごし方と会話が変わります。
- 仲間画面の「選んだ編成の効果を見る」で、保存前後の能力、所要時間の目安、回復・障壁・探索、ペア連携を比較できます。依頼には苦戦の理由と支度のヒントを表示します。
- 留守中の報酬画面から、次の建設・仲間加入・依頼へ進めます。案内は既存のv4の記録から求め、追加の進行フラグや報酬を保存しません。
- 星灯りのランタンをゲーム内、ブラウザー、ホーム画面のアイコンに使用します。「冒険」の手引きからホーム画面への追加方法を開けます。起動時の通信は必要です。端末や起動方法によって保存領域が分かれる場合があるため、追加前のファイル保管と読み込み方法も案内します。
- 非表示中は定期描画・保存・バックアップを休止し、復帰時に時間を精算します。別タブが進めた記録を引き継いでから書き込みを再開します。
- 主要なタップ領域は44px以上。短い画面ではカード内、極端に高さのない画面では内容部分のスクロールで操作を確保します。動きを減らす端末設定にも対応します。

自動検証に加え、iPhone/Android実機でのインストール、文字拡大、画面ロック・通信断からの復帰、長時間使用時の発熱は別途確認が必要です。

スマホ用の4画面（冒険・パーティ・拠点・思い出）を下部のナビで切り替えます。通常の画面では縦スクロールを抑え、持ちもの・編成・記録・設定はアイコンから開きます。長い設定やログはダイアログ内、収まらない説明はカード内、高さのない画面は内容部分をスクロールできます。

2026-09-10: 15地点の探索中に3地点用の座標を直接参照していたため、保存位置によって再開直後に画面がクラッシュしていました。座標参照を区間内の位置に統一し、全15地点を実際に描画する回帰テストを追加しました。保存形式と既存の記録は変更していません。

継続開発は不具合・機能ごとに [Issue](https://github.com/upu/starlit-guild/issues) を1件、作業タスクも1つの目的に絞る運用を推奨します。Issueには目的・完成条件・セーブ互換性・確認結果を記載し、仕様はこのREADMEとソースに残します。

- `npm run dev` — ローカル起動
- `npm run build` — 公開用ビルド
- `node --test tests/*.test.mjs` — 新旧シミュレーション・移行・セーブ形式
- `npx tsc --noEmit` — 型確認

公開先は `.openai/hosting.json` のSite。Gitの `origin` はGitHubの非公開リポジトリ、`sites` はSites専用リポジトリです。GitHubへのpushだけではゲームは更新されません。公開時には同じソースをSitesにもpushし、そのコミットからビルド・バージョン保存・限定公開を行います。セーブデータやローカルの作業ファイルはGitに含めません。

Drizzleの適用済みマイグレーションは変更せず追加します。`game_device_backups`はv3の端末別バックアップ、旧`game_saves`と`game_save_backups`は引き継ぎ元として保持します。

### 攻撃・発見の演出

通常攻撃・特技に、斬撃、矢の軌跡、回復の光、障壁、流星を追加。全員必殺は参加メンバーの短いカットインと星灯りの波、連携はペアのカットインを表示します。寄り道は宝箱・薬草・精霊の専用画像と回収時の動きで表現します。効果音は武器や技ごとに変え、連打時は重なりを抑えます。セーブ画面の消音は再生中の効果音にも反映します。

進行・報酬・セーブ形式は従来どおり。端末の「動きを減らす」設定では強い動きを省きます。キャラ音声はまだ追加していません。画像の生成プロンプトと確認範囲は [演出素材](docs/presentation-assets.md) に記録しています。

### BGM

拠点では「星灯りの焚き火」（48秒）、探索では「木漏れ日の小径」（40秒）を繰り返します。どちらもこのゲーム用に作曲し、柔らかいシンセ音で合成したオリジナル曲です。外部サービスの登録やAPI料金は不要です。

最初のタップ・Enter・スペースから再生します。拠点画面へ移ると穏やかな曲へ、冒険中は探索の曲へ徐々に切り替わります。「セーブ・設定 → 音・テスト」でBGMをオン・オフにでき、効果音とは別に音量を調整できます。初期音量は25%。BGM設定だけを端末の `starlit-guild-music-v1` に保存し、冒険のセーブ形式は変更しません。非表示・別タブによる操作中・画面終了時はBGMを停止し、復帰時は再生できる状態なら再開します。

楽譜と音源生成は `scripts/compose-bgm.mjs`、再生は `lib/music.ts`。PCM WAVを事前生成し、端末では読み込んだ2曲までを再利用します。新しい曲の読み込み中に画面を離れた場合は遅れて再生しません。自動検証では音量上限・ループ境界・消音・再開・読込失敗後の再試行を確認しています。実機での聴感・長時間再生は未確認です。

- 冒険画面は目標バナー・区間バー・手助け／回復ボタンを省き、画面の高さに合わせてマップを広げます。会話は見出しのないチャット欄で表示し、タップすると全文を読めます。
- 下部ナビは画面下端まで配置し、iPhoneのホームインジケータに必要な余白だけを一度確保します。極端に低い横画面では冒険の内容だけをスクロールできます。

## オリジナルキャラクター

- 5件達成で「その耳はおやつじゃない」：マッドハロウィンの悪食ドライアド、メリルを止める。
- 6件達成でチャチャとの出会い：お茶と筋肉を愛する天使。茶葉と資材を用意し、専用クエストを達成すると加入する。
- 12件達成で「消灯、人形たちの時間」：夜目のきくドールマスター、パンプティ（プティ）のいたずらを止める。

敵役2人は加入せず、依頼の出発・帰還・道中会話に登場。チャチャは編成、固有の大剣攻撃、拠点の日常に対応。新規の立ち絵は `public/characters/`、生成記録は [キャラクター画像の制作記録](docs/original-character-art.md)。既存のv4セーブを維持し、仲間9人・加入準備7人まで保存できる。


### 起動と冒険の画面

- 起動時はタイトル画面から「冒険へ」。プレイ中はタイトルを省き、持ちものとヒント・設定のアイコンだけを上部に置きます。
- 初めての出発ストーリーは出発前に読みます。最後の「冒険を始める」で出発と読了を一度に保存し、途中で戻った場合は出発しません。
- 冒険は自動周回し、「帰還」で戻ります。以前の記録の周回設定は読み込み時には変えず、新しく出発する際に自動周回へ戻します。
- 冒険の描画はPhaser。仲間の移動、踏み込み、射撃、着弾、回復、寄り道を現在の進行に合わせて描きます。HPは隊全体で共有し、先頭の仲間の足元にバーを表示します。仲間をタップするか画面下の「回復」で回復でき、「手助けする」はキーボードでも使えます。
- 編成・会話・設定はReact、進行・保存は既存のv4処理が担当します。描画のたびに報酬を計算することはありません。構成と検証範囲は [Phaser冒険画面](docs/phaser-adventure.md) を参照。
- アリアとレオンは待機・歩行・攻撃・被弾のコマ絵を切り替えます。待機中は短くまばたきし、採集・休憩では武器攻撃を止めます。「動きを減らす」設定にも対応。素材は [動作画像の制作記録](docs/hero-animation-art.md) を参照。
- スチルは画像自体をタップして鑑賞。全画面用のダイアログには中央寄せの移動指定を付けず、画像を画面内に収めます。
- ホーム画面から起動したiOSでは、動的ビューポート単位だけに頼らず実際のウィンドウの高さを使用します。ホームバー用の余白はこの高さの内側で確保します。

### 仲間と来客の思い出

チャチャの立ち絵は銀の鎧と青い服、柔らかな体つきへ調整。プティは黒・緑・黄色の指定衣装を採用。既存の仲間との会話4話とスチル3枚を追加した。

| 会話 | 解放条件 | スチル |
| --- | --- | --- |
