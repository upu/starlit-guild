# STARLIT GUILD — 星灯りの旅団

探索・戦闘・採取を仲間に任せ、クリックで手助けできる日本語の放置RPGです。

## ゲームの流れ

アリアとレオンの2人、1つの採取依頼から開始。達成数に応じて依頼、仲間、装備、野営地が解放されます。能力値は参加条件ではなく目安です。戦闘の得意な仲間は高いダメージ、採取の得意な仲間は速い作業、護衛の得意な仲間は被害軽減や護衛の進行に貢献します。

- マップを移動し、3つの地点で戦闘・採取・護衛を実行。
- 敵・素材をクリックして加勢。応援は3回分、8秒ごとに1回分回復。
- 体力がなくなると休憩し再挑戦。手助けで回復・復帰可能。
- 達成後は自動周回。オフにすると現在の1周で帰還。
- 仲間4人で2隊、6人で3隊。同じ仲間は複数の隊に所属不可。
- 初期編成は1〜2人、10件達成後は最大3人。以前の3人編成は保持。

## セーブと公開

進行はSitesが接続するCloudflare D1に保存。ブラウザーのlocalStorageを進行データの保存先に使用していません。

ゲストは256ビットのランダムキーをHttpOnly Cookieで保持。サーバーにはそのSHA-256ハッシュを識別子として保存します。Cookieを失う前に画面上の自動保存メニューから復元ファイルをダウンロードできます。復元ファイルはゲストセーブへの秘密の鍵なのでGitに入れたり他人に共有しないでください。

アカウントの既存セーブとゲストセーブは独立しています。以前のセーブはログインして開けます。v1は読み込み時に未取得の報酬を精算してv2へ引き継ぎ、元のJSONを`game_save_backups`に保管します。進行中の依頼は新形式で再出発します。

サーバー時刻で最大12時間分を計算します。ブラウザーは同じシミュレーションで移動と行動を描画し、20秒ごとに裏で同期します。同期は操作を無効にせず、操作を順序付きで送り、操作IDによって再送や同時更新による二重適用を防ぎます。

## 開発

- `npm run dev` — ローカル起動
- `npm run build` — 公開用ビルド
- `node --test tests/game.test.mjs` — 行動シミュレーション、放置、パーティ、移行テスト
- `npx tsc --noEmit` — 型確認

公開先は `.openai/hosting.json` のSite。ローカルGitとSites専用ソースリポジトリで管理しています。GitHubリポジトリはまだ作成していません。

スキーマ変更はDrizzleで新しいマイグレーションとして追加し、適用済みファイルは書き換えないでください。v1互換の精算コードは`lib/game-v1.ts`に保管しています。
