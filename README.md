# STARLIT GUILD — 星灯りの旅団

仲間が同時に歩き、戦い、採取する日本語の放置RPG。クリックを重ねて手助けできます。

## 遊び方

アリアとレオンの2人、1つの採取依頼から開始。出発するまでは進みません。達成数に応じて依頼、仲間、装備、野営地が解放されます。能力は参加条件ではなく目安です。

- 仲間と敵は独立した時計で行動。二連矢、踏み込み、回復、障壁、流星など8人固有の特技・動作があります。
- 敵・素材へのクリック、手助けボタン、回復は回数制限なし。移動中も先回りして手伝えます。
- 体力がなくなると休憩・再挑戦。達成後は自動周回し、オフにすると1周で帰還。
- 仲間4人で2隊、6人で3隊。同じ仲間は複数の隊に所属できません。
- 森、山地、水晶の洞窟、古塔で背景が変化。効果音は最初の操作から有効、セーブ画面でオフにできます。
- 1周は15地点（従来の5倍）。3地点ごとに報酬を確保するので途中で帰還しても区間報酬は残ります。依頼一覧の報酬は5区間分の基本合計です。
- 手助け・回復で応援が5たまり、100で全員必殺技。ゲージは地点・周回を越えて持ち越します。
- 寄り道に探索好きの仲間が向かい、宝箱・薬草・精霊と木材を発見。クリックすると優先して調べます。放置でも回収し、保存・再開で二重取得しません。
- 相性のよいペアは約14.5秒ごとに会話と連携技。区間をともに進むと絆が育ち、12・24で連携レベルと会話が変化します。
- 拠点は焚き火→酒場→鍛冶場と薬草園へ発展。木材などを消費して建設し、待機中の仲間がお茶や訓練などをして過ごします。酒場は1件、鍛冶場・薬草園は3件達成後に建設可能です。

## セーブとアクセス

サイトは所有者のみの限定公開。サイト閲覧の認証とゲーム用アカウントは別であり、ゲーム専用の登録・ログインはありません。ソースと開発履歴は非公開の [upu/starlit-guild](https://github.com/upu/starlit-guild) で管理し、Sitesへの公開時にはSites専用Gitにも保存します。

ユーザーの明示指定により、進行の正本は端末のlocalStorage（`starlit-guild-v4`）。約1秒ごと・各操作・ページを離れる際に保存します。開いている間は約5分ごとにSitesが管理するD1データベースへスナップショットをバックアップします。通信待ちは出発・手助けを無効化しません。閉じている間はクラウド送信しません。再開時に最大12時間分を端末で精算します。

Sitesの閲覧アカウントが取得できる場合、そのIDでバックアップを分離します。認証情報を持たないローカル環境などではHttpOnlyのランダムCookieによるゲスト識別を使います。ゲーム内に追加のログイン画面はありません。バックアップはユーザーと端末ごとに分離し、古い通信で新しい保存を上書きしないよう連番で更新します。復元は新しい記録を追加し、元の記録を残します。

「セーブ・設定」から最初から遊ぶ記録、テスト用記録を追加・切替できます（最大12個）。テスト用だけに序盤・中盤・全解放と達成数・レベル・所持金の調整を表示します。記録を切り替えると、その記録の留守中の冒険が精算されます。通常の冒険にテスト用の資源は混ざりません。ファイル保存は選択中の記録を含み、読み込みは別の記録として追加します。

v1/v2のサーバー上の記録は変更せず、読み込み時に「以前の冒険」として追加します。初回の選択は新しい冒険なので、最初の出発を確認できます。旧APIと旧形式の精算コードは互換性のため残しています。

v3の端末記録・ファイル・クラウドコピーをv4へ引き継ぎます。元の端末キーは残します。既存の進行中の依頼は3地点で終えてから次の周回で15地点へ移行します。旧ページからのバックアップが、新しい形式の保存を上書きすることはできません。

複数タブでは期限付きの端末内リースで書き込みを1タブに絞ります。「このタブで続ける」で引き継げます。ブラウザーのデータを消すと端末の保存は消えるので、クラウドまたはダウンロードしたファイルから復元してください。端末の時計を用いる個人向けゲームであり、競争用の不正対策は含みません。

## 開発

スマホ用の4画面（冒険・依頼・仲間・拠点）を下部のナビで切り替えます。主要画面は縦スクロールせず、持ちもの・編成・記録・設定はアイコンから開きます。長い設定やログだけはダイアログ内でスクロールします。

2026-09-10: 15地点の探索中に3地点用の座標を直接参照していたため、保存位置によって再開直後に画面がクラッシュしていました。座標参照を区間内の位置に統一し、全15地点を実際に描画する回帰テストを追加しました。保存形式と既存の記録は変更していません。

継続開発は不具合・機能ごとに [Issue](https://github.com/upu/starlit-guild/issues) を1件、作業タスクも1つの目的に絞る運用を推奨します。Issueには目的・完成条件・セーブ互換性・確認結果を記載し、仕様はこのREADMEとソースに残します。

- `npm run dev` — ローカル起動
- `npm run build` — 公開用ビルド
- `node --test tests/*.test.mjs` — 新旧シミュレーション・移行・セーブ形式
- `npx tsc --noEmit` — 型確認

公開先は `.openai/hosting.json` のSite。Gitの `origin` はGitHubの非公開リポジトリ、`sites` はSites専用リポジトリです。GitHubへのpushだけではゲームは更新されません。公開時には同じソースをSitesにもpushし、そのコミットからビルド・バージョン保存・限定公開を行います。セーブデータやローカルの作業ファイルはGitに含めません。

Drizzleの適用済みマイグレーションは変更せず追加します。`game_device_backups`はv3の端末別バックアップ、旧`game_saves`と`game_save_backups`は引き継ぎ元として保持します。
