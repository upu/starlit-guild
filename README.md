# 星灯りの旅団

日本語のファンタジー放置RPG。8人の仲間、3人編成、9クエスト、絆のボーナス、育成、装備強化、野営地、実績、毎日の差し入れ、冒険ログを実装しています。

進行はサーバー時刻で計算します。オフライン報酬は1回の不在につき12時間まで。自動周回をオフにすると現在の1周で帰還します。ゲームデータは認証されたプレイヤーごとにD1へ保存し、更新番号の比較で二重操作を防止します。ブラウザーの保存領域は進行の保存に使用していません。

## 開発と検証

- `npm run dev` でローカル起動。
- `npm run build` で公開用ファイルを出力。
- `node --test tests/game.test.mjs` で時間計算・報酬・育成のテスト。
- `npx tsc --noEmit` で型検証。

DB構成は `.openai/hosting.json`、生成済みスキーマ変更は `drizzle/` にあります。適用済みマイグレーションを変更せず、追加で更新してください。公開はSitesで管理します。

## 遊び方

冒険タブで依頼を選び、出発します。採取・護衛・討伐の対応能力が依頼の条件以上なら、確実に達成できます。10件と40件の達成で次の地域が解放されます。仲間タブで編成・雇用、ギルドタブで育成・報酬受け取りができます。

毎日の差し入れはUTC 0時（日本時間9時）更新。仲間のレベル上限は50、装備は15段階、野営地は10段階です。
