# Fiction Atlas

作品固有の地名を持たない汎用の地図制作ツール。Python標準ライブラリだけで動く。生成したHTMLはオフラインで閲覧・編集・JSON読込／保存・SVG／HTML保存ができる。

## 制作

既存作品では地理の正本と実際の本文から地名、通行経路、地形、移動時間の制約を拾う。場所の存在が確定していても座標・方角まで確定したとは扱わない。`status`（存在）と `placement`（配置）を別に記録し、根拠の資料・章／シーンを `sources` に残す。空白を埋めるためだけに国境・海岸線・固有名を確定しない。

新規作品なら制作に必要な範囲で地形や集落を提案できる。河川の流れ、峠、交易路、旅程の整合を確認する。距離と旅程が未設定なら数値の縮尺や所要時間を捏造せず、配置案と明記する。

一つのJSONを正本にし、同じ場所を複数の地図へ重複登録しない。世界図と地方図は共通座標上の表示範囲と表示密度で分ける。大陸の形が決まっていなければ世界図は既知地域の位置づけと未設定範囲を示す。世界を拡張しても既存の場所IDを維持する。

データ仕様は [references/format.md](references/format.md)。まず `init` で動く最小例を作り、作品の資料に合わせて編集する。

```powershell
python <このスキル>/scripts/atlas.py init my-world.json --title "作品の地図"
python <このスキル>/scripts/atlas.py validate my-world.json
python <このスキル>/scripts/atlas.py build my-world.json --out atlas.html
```

HTMLを開き、世界図→地方図、検索、場所選択、設定と根拠、地形・街道・ラベルの表示を確認する。地名の重なりは `labelOffset`、地図ごとの `level`、詳細図の範囲で調整する。必要ならブラウザーの「配置を編集」で地点をドラッグし、名称・メモ・座標を変更する。編集内容は明示的にJSON保存するまでファイルへ反映されない。元ファイルは上書きしない。

ブラウザーで地形・街道・地図範囲・根拠を変えるにはJSONを編集して読み直す。地形描画は自由な点列（森・山・平原・水域・河川・海岸／陸地）で、画像生成への依存はない。絵画的な仕上げを依頼されたときだけ画像生成を併用し、地名と位置の正本はデータに残す。

## 納品と更新

既存作品のシナリオ・クエスト制作から呼ばれた場合は、まず既存の地図データと根拠本文を照合する。既存JSONを `init` で置き換えない。新しい場所・行路・地理設定を追加変更したときは、担当する設定資料と本文、地図データ、影響する表示用ファイルを同じ作業で揃える。地理に変更がない確認だけなら再生成は不要。作品固有の作業順序やPR規則はその作品の手順に従い、この汎用スキルへ固有名や設定を持ち込まない。

- JSON、単独HTML、各縮尺のSVG、設定の根拠と未設定事項を渡す。SVGはHTMLから保存できる。
- HTMLは表示中の範囲をSVGとして保存する。全景が必要なら「全体へ戻す」を押してから保存する。
- 他の作品では `init` から別ファイルを作る。既存作品の固有名・設定を流用しない。
- 更新後は `validate` と代表的な表示を確認する。文面の存在と配置の確定を混同しない。
- 地図は創作資料。ゲームへの組み込み・サイト公開・設定の正式採用まで自動的に行わない。
