# 見下ろし視点の背景原本

会話・冒険の共通カメラ用。1枚の原本または2列×2行の背景シートを `config/rpg-backgrounds.json` で各場面へ対応させる。切り出しと既存配信URLへの生成は `scripts/rpg-backgrounds.mjs` を両方の背景パイプラインから使う。

制作ツール、参照した変更前コミット、参照画像と全文プロンプトは `docs/art-generation/rpg-camera-20261013.json`。変更前の `story-stage` / `scenery` 原本は保持する。森の冒険背景は既存の見下ろし構図をそのまま使う。
