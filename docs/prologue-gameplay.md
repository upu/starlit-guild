# 序章のゲーム実装

2026-09-11。第一部プロットの序章に対応する実装。第一章の塔の噂以後はまだゲームに入れていない。

- 新しい記録は `initialPrologueState` で作り、任意フィールド `prologue: true` を保存する。従来の記録は追加フィールドなしで読み込み、解放済みの遊びを保つ。ユーザーの端末保存を初期化・置換しない。
- 最初は冒険だけ。巻物の「クエスト」から「街への交易」を選ぶと「いつもの待ち合わせ」を開く。読了と出発・出発話の既読保存を一度の操作で行う。出発前に閉じた場合は出発せず、次の選択で再び読める。
- 交易路は荷物の運搬・頼まれた薬草の採取・小さな魔物との戦闘の全15地点。預かった荷物には既存の箱の絵を使い、第三の同行者は表示しない。薬草の依頼主は街の取引先に統一した。
- タップで手助けと回復ができる。序章では団長の応援ゲージと蓄積・全員必殺は無効。ふたり自身の通常行動・特技・連携は続く。
- 交易は毎回到着で停止する。初回の達成では「クエストクリア」の表示を出し、押すと「荷物を渡したら」を開く。留守中に達成しても未読の到着話を保存し、復帰時にクリア表示から進む。クリア表示の段階では既読にせず、再読み込みしても表示する。最後の「閉じる」で既読になり、次の交易へ進める。イベント会話は×・画面外タップ・Escで途中終了しない。再読では報酬を増やさない。
- 交易は繰り返し選べる。`Quest.availability` は `repeatable` / `once` を扱う（省略時は従来の繰り返し型）。既存の加入クエストは `once`。一度きりのクエストは達成で停止し、達成後の再出発を拒否する。
- 本の「旅の手帳」に思い出・ヒント・セーブと設定を集約する。思い出は初回の交易達成後に表示。序章以外でも本と巻物の入口を使い、思い出の下部タブは置かない。
- ユーザー指定により、交易後も冒険だけを維持する。交易を繰り返しても他のクエスト・パーティ編成・共同拠点・仲間の加入へ進まない。これらの解放時期は後の章で実装する。

初期画面の操作整理：クエストは画像生成した巻物アイコンだけを上部に置き、最初は「ここからクエストを選ぼう」の吹き出しでその入口を案内する。中央・下部にはクエスト選択ボタンを置かない。クエスト一覧の確定は「出発」。繰り返し可の表示・説明は省く。セーブ・設定の入口は手帳内の歯車。会話欄はホバー・フォーカス・タップで背景色を変えない。

手助け・回復・寄り道の別ボタンは置かず、マップを直接操作する。キーボードではマップにフォーカスし Enter / Space で手助け、H で回復できる。序章では寄り道の発生を止め、以前の序章セーブに保留中の寄り道がある場合は報酬を付与せず仲間を戻す。既に獲得した資源や進行は維持する。通常の採取対象・交易の荷物は依頼の対象として残す。

検証は `tests/prologue.test.mjs` と既存の描画・セーブ・端末ライフサイクルのテストで行う。序章の確認は別のテスト記録を作り「序盤」を選ぶか、既存記録を残す「最初から遊ぶ」から行える。
