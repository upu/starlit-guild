# 序章のゲーム実装

2026-09-13。第一部プロットの1-1〜1-9に対応する実装。1-8は水路の修理、1-9は苔の撤去と塔の再点灯・エピローグ。

- 新しい記録は `initialPrologueState` で作り、任意フィールド `prologue: true` を保存する。従来の記録は追加フィールドなしで読み込み、解放済みの遊びを保つ。ユーザーの端末保存を初期化・置換しない。
- 最初は冒険だけ。巻物の「クエスト」で「街への交易」を選び、「この行先にする」で待機画面へ戻る。待機画面の「出発」で「いつもの待ち合わせ」を開く。読了と出発・出発話の既読保存を一度の操作で行う。出発前に閉じた場合は出発せず、同じ行先の待機画面から再び開ける。
- 交易路は荷物の運搬・頼まれた薬草の採取・小さな魔物との戦闘の全15地点。預かった荷物には既存の箱の絵を使い、第三の同行者は表示しない。薬草の依頼主は街の取引先に統一した。
- タップで手助けと回復ができる。序章では団長の応援ゲージと蓄積・全員必殺は無効。ふたり自身の通常行動・特技・連携は続く。
- 交易は毎回到着で停止する。初回の達成では「クエストクリア」の表示を出し、押すと「荷物を渡したら」を開く。留守中に達成しても未読の到着話を保存し、復帰時にクリア表示から進む。クリア表示の段階では既読にせず、再読み込みしても表示する。最後の「閉じる」で既読になり、次の交易へ進める。イベント会話は×・画面外タップ・Escで途中終了しない。再読では報酬を増やさない。
- 交易は繰り返し選べる。`Quest.availability` は `repeatable` / `once` を扱う（省略時は従来の繰り返し型）。既存の加入クエストは `once`。一度きりのクエストは達成で停止し、達成後の再出発を拒否する。
- 本の「旅の手帳」にヒント・思い出・アルバムの順で入口を並べ、セーブと設定も集約する。各入口は最初から表示し、思い出や画像は進行に応じて増える。序章以外でも本と巻物の入口を使い、思い出の下部タブは置かない。
- 1-1の達成話を読み終えると1-2「夕暮れの帰り道」、1-2の達成話を読み終えると1-3「街の配達仕事」が開く。各ステージは初回に出発話を表示し、達成時に停止する。初回の達成話はクリア表示から読め、未読の間は次の出発を拒否する。留守中でも一度だけ達成して停止し、復帰後に同じ会話へ進む。
- 1-2は荷運びと小型魔物との戦闘。1-3は荷札確認・荷運び・受け渡しで、戦闘は発生しない。場面別の背景をクエスト一覧と冒険マップで共用する。道中の掛け合いは各仕事とアリア・レオンの二人に限定する。
- 1-3の達成話読了で1-4「丘の塔へ寄り道」、1-4の達成話読了で1-5「苔灯と帰る夜道」を解放する。1-4は採取10地点と小型魔物との戦闘5地点。塔へ到着後の会話で、管理人の許可を得て外側の苔を少し分けてもらう。光る苔の一枚絵は該当行から表示し、読了後はアルバムから鑑賞できる。
- 1-5は苔灯で足元を確かめる10地点と小型魔物との戦闘5地点。専用の苔灯画像を対象物として表示する。苔灯に魔物除け・回復・防御効果は付けない。採取・足元確認では武器を振る特技表示を出さず、戦闘地点では通常どおり戦う。帰着後の会話で光の弱まりと森の苔への見覚えを描き、原因の断定はしない。
- 達成済みステージは手動で再出発でき、既読の会話は手帳で読み返せる。再読は報酬を付与せず、周回の達成報酬だけが増える。ヒントは次の未達成ステージを案内する。次のステージを解放しただけでは背景を変えず、一覧で「この行先にする」を押すと待機背景とクエスト名が選択先へ切り替わる。開幕会話もその背景で始まる。候補を見ているだけの間は変更しない。冒険中の変更は帰還確認を挟み、帰還後は新しい行先で待機する。1-9後はここまでの探索・仕事と思い出を楽しめる。
- 解放には既存の `done` と `story.completed` / `story.read` を使う。待機背景を再読み込み後も保つため、隊に任意の `lastQuest` を保存し、出発時に更新する。項目がない旧記録の進行中クエストは達成・中断時に補う。形式はv4のまま、旧記録での欠落を許容する。1-1を繰り返していた序章セーブも、その達成話を既読なら1-2から続けられる。従来モードの既存クエスト・編成・拠点は維持する。
- 1-5の達成話読了で1-6「森の苔を探して」を解放する。全15地点で木陰・葉の形・群落の周りを探索し、戦闘や武器を振る特技表示は出さない。苔を大量に採る進行や薬草の獲得報酬は設けず、少量の標本採取と比較は達成話で描く。森の専用背景を一覧・冒険で共用し、比較の一枚絵はアリアが二つの入れ物を顔の近くまで持ち上げる行から表示する。水分を戻しても強い光が戻らないと確かめ、管理人への相談を決めるまでで停止する。
- 1-6の達成話読了で1-7「古い水路をたどって」を解放する。出発話で塔の近くと離れた場所の標本を比較し、管理人の古い管理図を読む。全15地点は調査10地点と小型スライムとの戦闘5地点。達成話で倒木・土砂の詰まりと奥の群落を確認し、復旧の相談へ進む。
- 1-7の達成話読了で1-8「水の通り道を戻す仕事」を解放する。全15地点は戦闘3地点と作業12地点。足場・道具・周囲の安全確認から、作業者による切り分けと排水、枝の回収と継ぎ目の補修、下流までの点検へ順に進む。苔を薬草資源として獲得せず、作業地点で武器の特技を表示しない。10地点目から排水後の背景へ切り替え、達成後の待機もその背景にする。再出発時は作業前から再現する。
- 1-8の達成話では水路の修理を終え、暗い塔と残った苔を確認する。読了後に1-9「もう一度、あの灯りを」を解放。全15地点は戦闘2地点と撤去・運搬・点検13地点。排水後の背景を使い、最後の地点は点検口を閉じる作業。達成話で塔の再点灯、管理人への点検引き継ぎ、後日の交易と帰路、二人の約束、「第一部 完」まで描く。再点灯の行から専用スチルを表示し、読了後はアルバムでも鑑賞できる。
- ユーザー指定により、1-9後も冒険だけを維持する。交易を繰り返しても第一部以外のクエスト・パーティ編成・共同拠点・仲間の加入へ進まない。これらの解放時期は後の章で実装する。追加セーブ項目は設けず、1-8まで進めた既存の序章記録からそのまま続行できる。旧1-8の出発・達成・読了IDと15地点の進行を維持し、既読の1-8を読み直すことは要求しない。既存の資源や履歴は変更せず、新たに1-9を遊べる。

初期画面の操作整理：クエストは画像生成した巻物アイコンだけを上部に置き、行先を選ぶ前は「ここからクエストを選ぼう」の吹き出しで案内する。中央・下部にはクエスト選択ボタンを置かない。一覧の確定は「この行先にする」。選択後の待機画面では上部にクエスト名と「出発」を表示する。未出発の選択は画面内で隊ごとに保持し、セーブの `lastQuest` や報酬を変更しない。再読み込み時は直前に実際に出発した場所へ戻る。繰り返し可の表示・説明は省く。セーブ・設定の入口は手帳内の歯車。会話欄はホバー・フォーカス・タップで背景色を変えない。

待機中のアリアとレオンの掛け合いは `lib/idle-banter.ts` の6組。30秒ごとに次の候補へ切り替え、一組の応答を途中で打ち切らず、既存の会話欄で順に表示する。準備・靴紐・荷物・並んで歩くことなど、ステージの先を明かさない内容にする。同じ候補を時計更新のたびに再追加せず、メニューや画面非表示中は自動送りを止める。

待機画面の「第一部 · 1-1 交易路（昼）」の見出しは表示しない。`1-1` は「第一部のステージ1」であり、一覧では番号を重複させない。「街への交易」はクエスト名、「街へ続く交易路」はフィールド名として使う。

会話は会話欄のタップで一人の発言（または地の文）ずつ下に追加する。シナリオは表示済みの発言を残し、あふれた分は会話欄内でスクロールして読み返せる。「前へ」「次へ」ボタンは置かない。スクロール・ドラッグ・文字選択では進めず、キーボードではEnterまたはSpaceで進められる。最後の発言を表示した後のタップで読了し、出発話は冒険を始め、それ以外は閉じる。操作可能状態を確認して一度だけ実行する。

画像付きのイベントは画面内に収め、本文と画像の領域を分離する。上側の約半分を画像、下側を会話とタップ案内に使う。画像は縦横比を保って全体を大きく表示し、画像タップは拡大専用で会話を進めない。画像のない会話は下端を固定し、必要な分だけ上へ広がって画面上限で本文スクロールに切り替わる。

マップ下の掛け合いは文章量に応じて3.5秒以上ずつ自動で追加し、返答を表示する前に別の掛け合いへ飛ばさない。欄の高さは112px（画面高700px以下では96px）に固定し、履歴が増えてもマップを押し縮めない。表示領域を超えた履歴はスクロール可能。長時間放置時のメモリ使用を抑えるため直近100発言を保持する。上へスクロールして読み返している間は最新位置へ引き戻さず、最下部へ戻ると追従を再開する。画面非表示・メニュー表示中は自動送りを止める。

思い出はステージ順に、各クエストの出発前→達成後を並べる。手帳や思い出の入口には画像を表示せず、「旅の手帳 → アルバム」を開いてから画像一覧を表示する。アルバムからは手帳へ戻る。物語中の画像はその場面に達した行から引き続き表示する。

手助け・回復・寄り道の別ボタンは置かず、マップを直接操作する。キーボードではマップにフォーカスし Enter / Space で手助け、H で回復できる。序章では寄り道の発生を止め、以前の序章セーブに保留中の寄り道がある場合は報酬を付与せず仲間を戻す。既に獲得した資源や進行は維持する。通常の採取対象・交易の荷物は依頼の対象として残す。

検証は `tests/prologue.test.mjs`、`tests/part-one-stages.test.mjs` と既存の描画・セーブ・端末ライフサイクルのテストで行う。序章の確認は別のテスト記録を作り「序盤」を選ぶか、既存記録を残す「最初から遊ぶ」から行える。
