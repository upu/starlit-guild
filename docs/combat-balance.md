# 戦闘の難易度と複数の敵

現行実装の調整値。人物設定・物語の変更は含まない。計算の正本は `lib/combat.ts`、行動と報酬は `lib/game.ts`。

## 数値を大きくしすぎない成長

- 難易度段階 `r` は第一部の1-1〜1-9で順に `0, 1, 2, 6, 10, 12, 17, 21, 25`。後半ほど育成・装備を必要とする。従来依頼・加入依頼は `max(4, 4 + round((need - 30) / 5))`。同じ依頼の周回数・累計達成数では上がらない。
- 単体のHPは `36 + 3r`。敵の耐性は `r`。
- 各人物の突破力は `レベル - 1 + 共通装備強化 × 2 + 装備中の武器tier × 3`。購入しただけの武器や防具は突破力に加算しない。独立した育成通貨・保存項目・画面上の能力欄は追加しない。
- ダメージは `max(1, round(基礎威力 / 1.15 ^ max(0, 耐性 - 突破力)))`。基礎威力は減衰前に丸めず、減衰後に整数化する。敵の残りHPを上回る分は切り捨て、次の敵へ貫通させない。
- 育成が同じなら、耐性が1上がるごとに丸め前のダメージが1/1.15になる。HPの小幅増加も合わさる。最低1に達した後は減衰だけでは難易度を上げられないため、生存時間も試走で確認する。
- 耐性以下の相手には減衰をかけない。突破力の余剰分でダメージを指数的に増やすことはしない。

通常攻撃・特技・連携・必殺・タップの手助けすべてに同じ減衰を適用する。通常攻撃と特技は既存の能力と倍率を使う。新しい戦闘の連携は `10 + 連携Lv × 4`、必殺は人物ごとに `ceil(12 + 討伐能力 × 0.4)` を基礎威力とする。連携の突破力はペアの平均、手助けは生存中の隊員の平均。連携はペアの両方が行動可能なときに発動する。

採取・運搬には耐性を適用しない。所要時間の目安には地点ごとのHP・敵数・減衰・特技と行動間隔を反映するが、休憩・回復・連携・手助け・途中の成長は予測しない。

## 敵の編成

- 通常の敵は1〜3体。最初のステージは1体、次は最大2体、以降は最大3体。地点の3区間ごとに編成を変え、同じ依頼の周回では同じ編成にする。
- 竜、メリル、プティなど `enemy >= 10` の固有の相手は1体のまま。
- `n` 体なら各HPは `round((36 + 3r) × (1 + 0.12 × (n - 1)) / n)`。群れの合計HPは単体の約1.12倍・1.24倍に留める。
- 各敵の攻撃力は `(4 + 0.45r) / n`。隊の護衛能力による軽減も `n` で分け、最低1ダメージ。障壁は既存の共通残量から消費する。
- 行動間隔は先頭から1450・1700・1950ms、初回攻撃は到着設定から3700・4150・4600ms。敵のHPが0になるとその敵は行動しない。
- 味方は先頭の生存敵へ集中する。同時刻の味方行動中に倒した場合も、後続の人物は次の生存敵へ向かう。全滅させて初めて地点を達成し、区間報酬は従来どおり一度だけ確保する。
- 各敵にHPバーを表示し、撃破後も生存敵の位置を詰めない。攻撃演出はイベントの敵IDに向かう。見出しと読み上げ情報には残数・個別HPを反映する。

## 保存と互換性

`Run.enemies` は任意項目。新しい戦闘では1〜3体、採取・運搬では空配列。各敵のHP・最大HP・耐性・攻撃力・行動間隔・次回行動時刻を保存する。既存の `target` / `targetMax` は合計HP、`enemyAt` は生存敵の次回行動時刻の最小値として同期する。`GameEvent.enemy` は攻撃元・攻撃先の敵IDで、味方の `target` とは分ける。

旧記録の進行中の地点では `enemies` を補わず、残りHP・旧計算・時計を保つ。次の地点、新しい出発、休憩後の再挑戦から新方式に切り替える。セーブ形式はv4を維持し、読み込み時には敵IDの重複、HP超過、合計値の不一致、不正な時計、非戦闘地点の敵を拒否する。留守中精算の12時間上限で時間をずらすときは、各敵の時計も同じだけずらす。

## 第一部の育成と手助け

初回の達成は停止し、未読の達成話を読み終えるまで次へ出発できない。読了済みのステージへ再出発すると、隊の周回設定に従って自動周回する。既読ステージの周回では到着話を促す通知を繰り返さない。帰還すると停止し、途中までの区間報酬・経験値を保持する。第一部で他の仲間や編成を解放する変更は含まない。

初期装備で一度ずつ進むだけでは後半で止まる。安全な既読ステージで放置育成する、店の武器・防具を装備する、回数制限のないタップで押し切る、という選択肢を残す。連打にも最低1の減衰がかかり、1回あたりの効果で育成を無視することはできないが、手数で補える。

## 再調整の確認方法

`node scripts/check-combat-balance.mjs` で、独立した一時状態を用いて第一部の連続進行、同レベルでの装備比較、実際の自動周回による育成、連打、従来依頼を比較する。所要時間、休憩、最大敵数、最大個体HP、倒し切った一撃を除く通常ダメージを出す。通常ダメージの集計には特技・連携を含めない。

今回の調整値による自動試走（会話の読書時間を除く）：

| 条件 | 結果 |

| 1-8、Lv8、初期装備 | 10分内に完走せず |
| 1-8、Lv8、店の武器と革の上着 | 約100秒、休憩なし |
| 1-9、Lv10、初期装備 | 10分内に完走せず |
| 1-9、Lv10、店の武器と革の上着 | 約98秒、休憩なし |
| 1-9、Lv15、初期装備 | 約77秒、休憩なし |
| 初期状態から店で購入・装備し、苦戦時に湿地を5分単位で自動周回 | 追加の育成25分、失敗した挑戦も含め全体約52分で1-9まで達成 |
