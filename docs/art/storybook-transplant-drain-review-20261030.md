# 4-9 帰還時の排水路確認

帰還会話の塔の場面では、地の文にある排水路の確認が動きに反映されていなかった。作業者が苔を剥がし、レオンが籠を受け取って戻った後、アリアと管理人が水路の脇へ歩き、リコも二人の近くへ合流する。後続の管理人とリコの会話ではその位置を保つ。リコは作業者、ミラ、レオンの手前を回る。既存の背景・地理やストーリー本文は変えていない。

PC 1280×720と390×844 CSS pxのブラウザーで、籠の回収後から水路への移動・会話を確認した。狭幅では既存の拡大によって水路と二人の頭が切れたため、この背景では全体を表示する。途中でタップした場合も、移動完了後に次の台詞へ進むことを390px幅で確認した。`tests/storybook-transplant-return.test.mjs` は回収後の順序、移動時間、途中の経路間隔、後続会話での位置を検査する。スマートフォン実機と全章の最終確認は未完了。
