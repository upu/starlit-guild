# 3-2 ベルネの往診：冒険表示の確認

「石を敷いた街」の往診を、青い戸の家とその隣家、井戸、作業台、石を外した箇所が見える石畳の街で描く。三種類の仕事を十五地点の順序に合わせ、フィンが包みや水桶を運び、アリアとレオンが石畳を確かめる。住人二人はそれぞれの戸口に残り、往診先が切り替わるたび同じ人物が瞬間移動しない。ミラは訪問先の近くで待つ。町の地理、本文、セーブ、進行と戦闘計算は変更していない。

包みは台に合わせた立ち姿で受け取り、水桶は地面から持ち上げる。物が体の背後へ隠れないよう手前に描画し、桶の取っ手を手の位置へ合わせる。井戸と台の脚には通過できない範囲を設定し、左の戸口と井戸の屋根が人物に重なるため、往診先は青い戸と右の戸の二軒を使う。進行表示は見えている作業位置へ置き、最後の確認後はアリアが立ち姿に戻る。描画上の仕事順を保つために演出側で移動と受け渡しを待ち、実際のゲーム進行は変更しない。
