# 4-1 冒険画面の試作

「塔を直した人たちへ」はリンデの町で依頼の手紙を渡し、日取りを確かめ、返事を受け取る。既存のリンデの倉庫・食堂と、縮尺だけを参考にしたベルネの町並みから、見下ろしの町の広場を作った。[生成記録](../art-generation/storybook-linde-delivery-20261028.json)に参照と指示を残す。

`/sprite-lab/storybook/linde-delivery` は一時データによる試作。二軒の人は店先で待ち、レオンが手紙を手に近づき、手渡し・日取りの確認・返事を受け取る。背景・人物・小物を同じ縮尺で描く。実際の作業の進行を変えず、描画用の順番を保つ。ゲーム本編には未適用。

PC幅と390×844 CSS pxのブラウザー表示で背景・人物の配置を確認。390px幅では人物、とくに手紙と手先が小さかったため、狭幅では背景・人物・手紙を一緒に約1.27倍にし、両方の訪問先が見える画角へ寄せた。拡大後も手紙の細部は小さい。手紙の連続性、セリフや進行表示との同期、全15工程の連続再生を実画面で再確認してから本編へ適用する。スマートフォン実機は未確認。

試作の進行表示は実際に描いている工程へ追従するようにした。ゲーム上の作業完了後も最後の返事を受け取り、レオンが仲間に戻るまで「到着しました」に切り替えない。返事は帰着後も手元に残す。PC幅と390px幅で終盤と帰着を確認し、連続手助け・動きを減らす設定では自動テストでも帰着を確認。幅600pxで背景下端に出ていた暗い帯は、カメラ位置を背景の範囲内へ収めて修正した。

本編と同じ画面構成の一時データ見本 `/sprite-lab/storybook/linde-delivery-phone` を追加。縦長画面では横長背景の両端が切れていたため、同じ二軒を縦長に組み直した[背景](../art-generation/storybook-linde-delivery-portrait-20261028.json)を使う。座標・小物・人物も画角に合わせ、画面の上方にいる人物が背景の後ろに消える重なり順を直した。PC幅では会話欄の上へ仲間を寄せ、作業物のない場所に出ていた進捗バーを消した。390×844 CSS pxでは両方の住人とレオンの二軒目での受け渡しを確認。連続手助け後、作業の描画を待って完了画面が開き、次の操作で帰還会話を表示することを確認した。一時データでの確認であり、実機・本編の既存セーブは使っていない。

連携演出は、PC幅では広場の右側、390px幅では人物と会話欄の間へ移し、姿や手元を覆わないようにした。連携の内容と継続時間は変えていない。一時データの本編構成で、PC幅の `work/linde-complete-pc/000.png`〜`069.png` とスマホ幅の `work/linde-complete-mobile/000.png`〜`069.png` を約0.7秒間隔で記録し、二軒の往復、手元、連携演出、人物の欠けを確認した。両幅とも記録後に完了画面を確認したが、スマホ幅の末尾には帰着の全過程が含まれないため、そこは別途確認が必要。

縦横比の変更時は、0.5秒かけて暗くし、中央で背景を切り替えて戻す。人物の元の地面座標を新しい背景へ写し直し、切り替え前の画面座標を目標として歩かせない。正方形付近のわずかなリサイズでは頻繁に切り替えず、停止中・動きを減らす設定では即座に表示を合わせる。縦から横への切り替えを `work/linde-resize-review/00.png`〜`11.png` で確認。一時データの「帰着の手前から」で最後の返事と帰着から完了画面までを `work/linde-return-mobile/00.png`〜`29.png` に記録した。手紙は小さい画面では細部まで判別しにくい。

横から縦への切り替えも `work/linde-resize-review/up-00.png`〜`up-11.png` で確認した。その際に店の人の足元をレオンが横切る箇所を見つけ、住人の身体が占める範囲を考慮して手前を回る経路に修正。PC幅 `work/linde-avoid-pc-fixed/00.png`〜`57.png`、390px幅 `work/linde-avoid-mobile-fixed/00.png`〜`59.png` で二軒間の移動と接近を確認した。通過中は手前の人物が一部重なるが、足元を踏んで背後に消える動きは見られない。

4-1の出発時編成は `storyParty` で四人に固定され、リコは含まれない。レオンが行動できない場合は、アリア・ミラ・フィンから行動できる人を選び、手紙の持ち歩きと受け渡しを交代する。全員が動けない場合も完了を待ち続けない。各人が唯一行動可能な試作はPC表示の受け渡しを `work/linde-courier-review/` に記録し、自動検査で交代役の歩行・手紙・帰着を確認した。実機は未確認。

倒れた人物が受け渡し位置を塞ぐ場合は、交代役が住人の反対側へ回り、住人もそちらへ向いて手紙を渡す。途中でレオンが回復しても、同じ訪問先では方向を戻さない。PC幅 `work/linde-side-stable-pc/00.jpg`〜`37.jpg` と390px幅 `work/linde-side-stable-mobile/00.jpg`〜`37.jpg` で、交代・反対側への接近・回復後の位置を確認。返事を受け取って帰る途中の交代は、両画幅の自動検査で反対側への到着と時間切れ前の帰着を確認した。双方が塞がれた場合に備えて完了後最長10秒の待ち解除は残す。

担当者が手紙を持ったまま行動できなくなったときは、最後に表示した手元から地面へ落とし、交代役が歩いて近づき、しゃがんで拾ってから配達を続ける。返事を持って帰る途中なら拾って仲間へ戻る。住人に渡し終えた手紙は住人の手に残し、向き直るときも位置を補間する。PC幅 `work/linde-pickup-pc/00.jpg`〜`54.jpg` と390px幅 `work/linde-pickup-mobile/00.jpg`〜`49.jpg` で、移動中の交代と拾得を確認した。両画幅の自動検査で返事の落下・拾得・帰着、拾う途中の再交代でも手紙の位置が飛ばないことを確認した。

ミラとフィンが拾う場合、仲間の位置による回避処理で拾得位置から押し出され、足が止まるケースを修正。拾得役の位置を優先し、フィンにはしゃがんだ手元まで届く落下位置を設けた。PC幅と390px幅で両者の拾得から住人への接近を連続表示で確認した（`work/linde-pickup-mira-pc-fixed/`、`work/linde-pickup-finn-pc-fixed/`、`work/linde-pickup-mira-mobile/`、`work/linde-pickup-finn-mobile/`）。住人が持つ手紙も、交代時に最後に描いた位置から補間する。住人に渡った後の交代を両幅で確認した（`work/linde-resident-hold-pc/`、`work/linde-resident-hold-mobile/`）。

本編の4-1にも背景と配達演出を自動適用し、クリア後は返事を持って仲間へ戻るまで表示を待つよう接続した。見本の一時データを使い、試作用の指定を付けない本編と同じ接続で、PC幅 `work/linde-default-pc/` と390px幅 `work/linde-default-mobile/` の最終訪問から帰着・クリア画面までを連続確認し、次の操作で帰還会話が開くことも確認した。比較用の背景指定と従来表示のオフ指定は優先する。

本編接続の一時データで、最初から連続手助けした際の往復と帰着も両幅で記録した（`work/linde-default-full-pc/`、`work/linde-default-full-mobile/`）。両幅とも最後まで移動してクリア画面を確認した。
