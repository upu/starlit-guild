# 2-5 分かれ道の道標：固定舞台と道標の受け渡し

2-5 `spinning-signpost` を本編の既定表示へ適用し、既定対応は16/37。確認用の `/sprite-lab/storybook/signpost` も本編の既定設定を使う。用語集、第二章の出発・帰着、`chapterTwoWork` の9工程、地図の分かれ道と古い作業場を照合した。新しい地名・方角・行路は追加しない。既存の `mountain-fork-v1.png` を使い、同じ分かれ道で道標を点検・回収する。

## 配置と所有者

`lib/road-signpost.ts` が1536×1024の背景と人物を `fixedRoadLayout` の共通縮尺へ投影する。戦闘の種類にかかわらず表示上の `stage` をforestに固定し、背景・足元・道具で別の横縮尺を使わない。敵・味方を置き換えた後の矢・斬撃・回復は `road-fixed-effects.ts` で接点を投影し直す。進行・戦闘計算・セーブ座標は変えない。

二つの配達袋とミラの薬箱は、ミラの近くに置き、工程が変わっても同じ位置に保持する。袋は既存の閉じた `packing-bag-close-3-v1.webp`、薬箱は `homeward-medicine-v1.webp`。新規原画の生成はしていない。道標の物は常に一つとし、点検中の地面、人形の背中、回収中のレオンの手元、元の場所へ所有者をつなぐ。元の「道標を運ぶ」は汎用の荷車動作を使わず、専用の手運びに置き換えた。

## 回収と立て直し

`RoadSignpostCarry` が倒れる・近づく・しゃがんでつかむ・持ち上げる・4姿勢で向き直る・歩く・立て直す、を保持する。既存のレオンの運搬・作業・歩行・向き直り素材を共通倍率で使う。歩行は実移動距離の `RoadGait`。道標はロープ付近の支点で持つため、汎用の道具表示へ任意の `origin` を追加し、手の位置で回転させる。従来の道具は既定の中央下端のまま。

実進行では、点検中の先回りした人形との戦闘を終えると、戦闘だけの工程が同一更新内で通り過ぎる場合がある。描画側は停止した人形を短く残してから回収へ進み、点検・停止・回収を飛ばさない。これは終わった戦闘の停止表示であり、新しい戦闘・ダメージを発生させない。点検中に現れた実際の敵や効果も隠さない。回収が済むまで次の工程の見た目を待たせる。

非表示の作業画像も描画経路で参照されるため、専用frame名を画像へ直接渡すと「frameがない」という警告が出た。固定舞台用の手描き画像は `__BASE` を選ぶよう修正した。最終確認時に残っていたログは修正前の08:23台のもので、確認時刻08:37UTC以降の再発とは扱わない。

## 所有者の接続を修正した確認

上記の初回検査では、人形が現れると道標が地面から背中へ飛んだ。`road-signpost-owner.ts` でこの接続を修正した。初回は出発会話の続きとして既に背負っている。以後は人形が分岐側から道標へ近づき、身を低くして拾い、背負って離れる。非戦闘の人形から実際の敵へ、同じ足位置・同じ体格で切り替える。停止後は道標が同じロープ位置から倒れ、人形が奥へ退場する。道標の表示原点が変わる瞬間も画像の四隅は移動しない。戦闘の追加やセーブ変更はない。

修正後のPC1243×1244は `work/signpost-owner-pc.json` の666枚、0.26〜92.186秒。ブラウザースマホ390×844は `work/signpost-owner-mobile.json` の1100枚、0〜94.546秒で、記録操作の間に空きがある。PCの全体抜粋と再取得の250ms刻みの拾い上げ、スマホの全体抜粋を目視した。両幅で到着表示まで確認。スマホの開始側は別タブの `work/signpost-owner-cold-mobile.json`（323枚、0〜23.975秒）と開始状態のスクリーンショットで補った。毎フレーム動画やスマホ実機の確認とは区別する。
