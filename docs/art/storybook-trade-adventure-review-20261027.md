# 1-1・1-2 荷車の継続表示（2026-10-27）

用語集の `village-trade` / `evening-trade-road`、既存の交易路、村から預かる品と帰りの品の描写を照合。本編の既定の手描き表示へ適用。場所・台詞・一枚絵・保存・進行と戦闘判定は変更していない。

## 今回の進展

- 作業物としての荷車は、採取・戦闘に切り替わると非表示になる構造だった。`lib/road-journey-cart.ts` に描画専用の荷車を保持し、移動・駐車・持ち手へ戻る状態を追加。作業地点が変わっても荷車を作り直さない。
- 二人が持ち手へ着くまでは荷車を動かさず、運搬時も時間あたりの移動量を制限。行きは既存の交易品入り荷車、帰りは既存の帰り荷の荷車を使う。手元と車輪底の基準を同じ値から求める。
- 採取地点は車輪と重ならない道の手前側へ配置。車体の足場を避ける経路を追加。実再生で敵と荷車が重なったため、敵の表示位置と攻撃の着弾位置も揃えて避ける。
- 昼の林道を既存素材で揃え、同じ構図の夕方の原画を生成・保存。原画・指示は `docs/art-generation/storybook-trade-adventure-20261027.json`、再配置は `scripts/build-storybook-trade.mjs`。
- 冒険完了時に描画識別子が待機へ切り替わっていたため、`lib/road-paint-key.ts` で同じ交易の帰着だけを継続。最後の戦闘後も持ち手へ戻り、荷車を到着地点まで運ぶ。新しい冒険や別の行先には引き継がず、初めから待機中の画面へ荷車を作らない。減速設定では完了時の静止配置へ移す。
- カメラが戻る際に押し手が逆向きになる問題を実表示で発見し、接触中の人物の向きを維持。停止時は足を上げた歩行コマを保持せず接地したコマへ戻す。
- スマホで荷車だけが相対的に大きくなる差を修正。交易路の車幅・持ち手・車体の足場・作業バーは人物高の145/128倍を共通基準にする。到着先は固定世界座標の手描きの倉庫と道標を使用し、旧マーカーを表示しない。倉庫は既存の街の配達場面と同じ対人倍率を使う。

見本は `/sprite-lab/storybook/trade` と `/sprite-lab/storybook/trade-return`。描画専用の入力を使い、ユーザーの保存を変更しない。新しい荷車の描画は `app/phaser/road-journey-cart.ts`、共有する足場・作業物の高さは `lib/road-view.ts` / `road-work-layout.ts` / `road-storybook-work.ts`。
