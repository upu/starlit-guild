# 2-7 作業場の蜜と控え（2026-10-30）

`sweet-blockade-return` の冒頭は、アリアが取り戻した蜜をミラの布へ載せる。元の見本では布が大きく顔にかかり、ミラの差し出す手と布が反対側へ離れていた。手の届く位置を優先して二人を近づけると頭が重なったため、ミラの受け取り姿勢を追加し、人物の間隔を保ったまま手と布・蜜を合わせた。受領後は既存の携行姿勢へ戻し、蜜と布も手元へ寄る。素材の原画・指示・ハッシュは [制作記録](../art-generation/storybook-mira-workshop-reach-20261030.json)。

同じ作業場で運び手が控えを見て書く場面は、旧ドット絵への切替が残っていた。既存の同じ運び手の手描き素材へ、歩行・控えの確認・二つの筆記姿勢を接続した。控えは姿勢の中に描かれているため、別の控えが浮いて重ならないようにする。台詞、人物の設定、セーブは変更しない。

会話2では、矢で弾かれた人形が少女のそばへ戻る台詞に合わせて、作業台の脇から少女の近くへ移動する。謝罪と運び手の登場まで同じ位置を保ち、人形たちがお辞儀する姿勢も維持する。会話見本を冒頭から進め、移動後の位置をPC画面で確認した。

分かれ道では、蜜を袋にしまうミラのしゃがみ姿に旧画像が残っていた。携行姿勢と同じ縮尺で足元を揃えた手描き素材に切り替えた。`/sprite-lab/storybook/blockade-fork-review` で道標の受け渡し、荷造り、手当てを時刻別に確認できる。PC画面で荷造りの途中と終了後を確認し、390×844 CSS pxでも舞台の幅を確認した。スマートフォン実機での確認は未実施。

道標を運んだ人形は、レオンの真後ろに隠れないよう受け渡し時に横へずらした。道標の位置は双方の間に保ち、受け渡し前後の位置と傾きの連続性を検査する。PCと390×844 CSS pxのブラウザーで運搬・受け渡し・設置後を部分確認した。

PC幅と390×844 CSS pxのブラウザーで、時刻を指定できる `/sprite-lab/storybook/workshop-handoff` の受け渡し直前・受領後を部分確認し、会話見本の運び手の記録姿勢も確認した。手描き素材の読み込みと背景の適用を実画面で確かめた。厳密な全フレーム、全32表示の連続再生、スマートフォン実機は未確認。細かな指の動きは既存姿勢と二コマの切替で表現する。

受け渡し前後の同一位置、移動中の二人の間隔、新姿勢と既存の歩行姿勢の手の画素・足元、運び手の筆記と画像の先読みを含む関連25テスト、型検査、対象lint、Node 26の `vinext build` は成功。ビルドには既存のVite設定・同名CSS出力などの警告がある。
