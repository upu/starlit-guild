# 4-9の荷車の縮尺・冒頭の隊列と全工程の再確認

4-9 `moss-transplant` の既存の会話・運搬・土仕事・籠の置き下ろしを、PC幅とブラウザーのスマホ幅で再確認した。用語集と地図の `brekka-tower` / `new-moss-beds` を照合し、塔から離れた新しい苔床という既存の場所を維持する。地理・本文・戦闘計算・保存形式を変更せず、地図の再生成や新しい画像の制作も行っていない。

## 荷車を身体の縮尺に揃える

冒険の荷車は画面幅から大きさを決め、PC幅では人物より先に上限に達していた。会話の荷車と比べ、PCの冒険では小さく見え、スマホ幅との身体比率も異なっていた。

苗の荷車だけ、会話の登録値（荷車幅25、人物セル19、192pxセル中の144pxの身体）を同じ身体寸法へ換算する `seedlingCartWidth` を使う。描画、前後の持ち手、同行者が避ける車体、籠を置く場所の判定へ同じ寸法を渡す。車輪も実際に描いた荷車の寸法を使う。汎用の荷車や比較表示は既存の計算を維持した。

`tests/road-seedling-cart-scale.test.mjs` は実際の会話の最終表示から登録比率を読み、実際の冒険側の外観選択を使って、1180×790、936×624、390×740、374×249で身体比率と二人の掌・持ち手の一致を検査する。既存の運搬接点検査も、新しい描画寸法を基準に更新した。

## 最初から押し手・引き手の隊列を保つ

荷車の寸法を揃えると、開始直後にレオンが旧来の列に残り、アリアが持ち手から離れる問題が検査で見つかった。会話ではすでにアリアとフィンが押し引きしているため、二人が動ける手描きの苗運搬では、冒険の移動開始時からフィンを引き手とし、同行者も同じ荷車を基準に置く。冒頭の二人は持ち手に接した姿勢を使う。

戦闘中、土仕事、片方が力尽きた場合やしびれている場合はこの二人の隊列を強制しない。比較表示へも冒頭の指定を追加しない。通行の共通回避を弱める変更は採用せず、苗運搬の初期配置で解決した。

`tests/storybook-seedling-cart-start.test.mjs` は元の二寸法に本編のPC・縦長寸法を加え、冒頭の両者の姿勢と3秒間の持ち手、保存不変を確認する。力尽き・しびれの各二人を固定しない検査も追加した。12通りの戦闘後の合流と左右の選択、既存の籠・車体・持ち手の回避は維持する。

## 本編構成で再生した範囲

記録は `work/transplant-sequence-20261031/`。ユーザーの端末セーブを使わず、Lv40の一時データと実際の `PhoneFrame` で確認した。全工程用は `/sprite-lab/storybook/transplant-phone`、会話の最後からの接続は既存の `/sprite-lab/storybook/transplant-seam`。

- PC1280×900とブラウザー390×844 CSS pxで、`{pc,mobile}-full-a/b/c` を40秒・40秒・25秒ずつ記録した。区間間は確認用の一時停止で進行・描画を止めて続きから再開する。15地点の最初から運搬、戦闘、土仕事、籠の置き下ろしと回収、最後の作業、完了カードまでを含む。連続手助けは使っていない。
- 約250msごとの静止画と時刻の一覧を保存し、各区間の抜粋と原寸画像で身体、頭と足先、荷車・手元、籠、同行者、地面と前後関係を目視した。全フレーム動画の検査ではない。
- 完了カードからそのまま帰還会話を開き、両幅の `*-return-start` で1/25まで記録した。新しい苔床へ画角を切り替える。布の手渡しが終わり、アリアが離れた終点の配置も確認した。25表示すべての再生は今回の範囲外。
- 最後に会話からの接続を両幅で撮り直した。`*-final-last-line` で最終表示を保ち、次のタップ後の `*-final-exit-road` で荷車へ合流、押し引きして退出、冒険開始までを記録した。冒険の時計はこの見本では開始時に止め、二人の持ち場とリコの籠が最初から表示されることを確認する。別の全工程見本での開始とは区別する。
- `pc-hold-last` / `pc-exit-to-road` は荷車を直す前の比較用。最終の接点確認には `*-final-*` を使う。

同じ確認用タブのエラーログには、途中の検討で一時的に共通回避へ触れた際の古いHMRエラーが一件残る。この検討は取り消している。ログを消さず、各最終再生の最初の画像の保存時刻から抽出した `current-errors.json` で、PC全工程・スマホ全工程・最後の接続の再生開始以降は新規エラーなしであることを確認した。
