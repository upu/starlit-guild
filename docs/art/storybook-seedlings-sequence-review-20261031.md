# 4-8 苗の積み出し口の戦闘と前後の会話（2026-10-31）

出発前から本編の開始、PC幅の帰還最終タップと、メリルが最終ナレーション中に退出する追加修正は [接続の確認](storybook-departure-seams-review-20261031.md) を参照する。以下は先に行った通し確認。

4-8「苔は渡さない」（`merrill-seedlings`）を、PC幅1280×900とスマートフォン幅390×844 CSS pxで確認した。用語集・第四章の台本にある塔の裏手の積み出し口を使う。今回のゲーム表示の変更はフィンの名前の位置。人物・背景・小道具の画像、身体の倍率、接点・経路・台詞・戦闘計算・セーブは維持する。全章のゴールは継続中。

## 通常進行から帰還まで

本編と同じPhoneFrameの `/sprite-lab/storybook/merrill-seedlings-phone` を使用した。既存のLv25の初期装備の見本では回復に対して攻撃が弱く長引いたため、表示確認用のLv35の開始条件を追加した。保存しない一時データで、開始・召喚・演奏・近接攻撃・撃破・全員の帰着・クリアを両幅で一続きに撮影した。連続手助け・敵HPの変更・戦闘途中への移動はこの再生で使っていない。攻略バランスの測定とは区別する。

レオンとフィンが相手へ近づく、リコが場所を空ける、コロタケが倒れた位置に残る、演奏に合わせて効果が出る、戦闘後に元の場所へ戻る流れを一覧と選んだ画像で確認した。人物・小道具・建物の比率、攻撃と歩行の切替、横長と縦長それぞれの画面端を照合した。今回の再生で新しい頭足の欠けや体格の急変は見つからなかった。

両幅で実際のクリア表示の「次へ」から帰還会話「感想は一株分」へ入り、41表示を順に再生した。苗を渡す、琴を弾く、感想を書き消す、道順の紙を渡す、4体を順番に拾って鍋へ入れる、地面の鍋へ屈んで手を伸ばし持ち上げる、立って抱えて歩く、最後の台詞までを確認した。長い回収は約19秒を省略せず採取した。スマホ幅では最後の「閉じる」のタップ後も6秒を採取し、退場からキャンプへ戻ることを確認した。

## 出発前と名前の修正

出発前「食べていい方は、どれ」35表示も共通StoryReaderの `/sprite-lab/storybook/reader` で両幅を順に再生した。冒頭の湿った布は、手持ちから籠へ掛かった状態に切り替わる。15〜35表示は既存の一枚絵 `lico-protects-seedlings.webp` のままで、舞台の人物描画が残らず、同じ会話欄で読み進められることを確認した。

人物セルを小さくした後もフィンの名前の横ずらしが残り、スマホ幅ではアリアの名前と一部重なっていた。`lib/storybook/seedlings-actors.ts` で名前をフィンの真上へ戻した。身体と足元の位置は動かさない。両幅の実DOMで、名前同士の矩形が重ならないこと、フィンの名前の中央が本人の表示枠の中央にあることを確認し、画像でも照合した。

帰還の全41表示と出発前の前半には名前の修正前の採取も含まれる。身体と物の動作は変更していないため、それらの一連の採取と、修正後の両幅の名前の採取を合わせて判断する。スマホ幅は名前の最終調整後にも冒頭の布の動作を開始操作から再採取した。

## 確認用操作欄の修正

舞台を隠さず確認できるよう操作欄を畳めるようにした。最初のnative detailsでは、読み込み直後に畳むとopen属性がReactの想定と異なり、hydrationの不一致が1件記録された。Reactのstateで開閉するボタンへ変更し、新しい確認タブで描画の準備完了とLv35の反映を確認してから再生した。修正後は両幅とも開始からクリアまで再採取し、ブラウザーエラーは0件だった。以前の警告を含むログは残し、最終ログと区別する。
