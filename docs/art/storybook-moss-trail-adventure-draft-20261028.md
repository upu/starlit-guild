# 4-4 荷車を追う道の冒険見本

2026-10-31追記：[通常進行の補足](storybook-reception-brekka-trail-review-20261031.md)で両幅の冒頭から分岐・追跡終了・クリアと帰還会話冒頭を分割再生した。筆記の区間は一時停止を挟まず両幅で補い、台詞に合わせた停止・手帳・追跡再開を確認した。以下の全工程の順序・筆記からの再開の不足はこの範囲で解消し、全歩行コマの個別目視・実機確認とは区別する。

用語集の `glowing-moss-trail`。台本ではミラとフィンが宿に残り、アリアとレオンが空籠の荷車を間を空けて追う。醸造所から裏通りへ向かい、行き先までは分からずに道順を持ち帰る。地図帳の宿・醸造所・裏通りの関係を照合し、新しい地理は追加しない。

一時データの `/sprite-lab/storybook/moss-trail-adventure` と縦長見本で、会話に使う醸造所の裏・御者・空籠の荷車・車輪を再利用。二人の隊列を御者より後ろへ置き、進行に応じて荷車とともに前へ進める。車輪の回転と御者の歩行を移動量に合わせ、停止・休憩時は止める。曲がり角を記録する区間では、停止中のレオンに手帳の姿勢を使う。実際のクエスト・隊員・セーブは変更しない。

縦長の背景は既存の醸造所の構図を基準に、会話の目印となる青い布を追加した。原本・指示は `docs/art-generation/storybook-brekka-trail-portrait-20261028.json`。PC幅 `work/moss-trail-facing-pc/` と390×844ブラウザー枠 `work/moss-trail-facing-mobile/` で追跡の一部を再生し、御者の向きと布を確認した。スマートフォン実機の確認ではない。

醸造所から既存の洗い場と青い布がある分かれ道へ、暗転を挟んで移るようにした。荷車と二人は距離を保って斜めに進み、車輪に小さな苔片が付いて回る。縦長背景の原本・指示は `docs/art-generation/storybook-brekka-fork-portrait-20261028.json`。PC幅 `work/moss-trail-fork-pc/` と390×844ブラウザー枠 `work/moss-trail-fork-mobile/` で転換の前後を連続確認した。スマートフォン実機の確認ではない。

本編の冒険表示へ接続し、完了後も最後の移動と暗転を終えてからクエストクリア・帰還会話へ渡す。セーブや進行時計を止めるのではなく、描画用の最後の状態だけを一時保持する。帰還会話は醸造所から出直さず、冒険終盤と同じ分かれ道の背景・近い人物と荷車の縮尺で追跡を続ける。地名や道筋の設定は変更していない。

見本の `/sprite-lab/storybook/moss-trail-phone` で、PC幅 `work/moss-trail-phone-ending/` と390×844ブラウザー枠 `work/moss-trail-phone-mobile/` の終盤から帰還会話へ移り、変更後は両幅で会話冒頭から苔が落ちる台詞までを確認した。スマホ幅で次の一枚絵が表示されることも確認した。スマートフォン実機の確認ではない。

道順を書く掛け合いは地点ではなく実際に表示中の台詞へ連動する。レオンが手帳を書く間、二人は足を止め、荷車を見ながら追跡を再開する。PC幅では掛け合い欄に人物が重ならないよう道上の位置を調整し、縦長では隊列を画面内に収めた。見本の `work/moss-trail-note-revised-pc/` と `work/moss-trail-note-final-mobile/` で台詞・手帳の姿勢と表示位置を確認した。

`tests/road-moss-trail.test.mjs` は両幅で二人が荷車を追うこと、実進行・セーブ不変、歩行と車輪、停止、引き手と手の位置、暗転中の背景変更、完了時の待機、台詞と手帳の連動、縦長画面の両端を検査する。全工程の実画面通しと全歩行コマの接点は引き続き未確認。
