# 林道の冒険の手描き統一（2026-10-27）

対象は1-6 `forest-wetland` と2-2 `moonlit-herbs`。地図帳の湿地・薬草の林と各章の既存本文を照合。場所や経路を追加せず、会話・一枚絵・報酬・進行・セーブの判定は維持した。

## 変更

- 会話の奥へ進む構図を冒険へ流用せず、人物の通行帯が左右へ続く林道を作成。昼と月夜で同じ地面の構図を保った。人物だけを縮小せず、根・小石・葉の描き込みも既存の冒険の倍率へ合わせた。
- 背景の左右端をそのまま隣接させると切れ目が見えたため、林道に限り交互の反転タイルを使用。同じ原画の端同士が接続し、周期を越えても地面が連続する。既存の街道・山道・夜の苗運搬には適用しない。
- アリア・レオン各4姿勢の採取原画を作成。立位134/144pxを校正基準に同一倍率で梱包し、しゃがむときも同じ頭・足の大きさと足底176pxを保つ。土を掘る道具を持たず、葉へ手を伸ばす・摘む・持ち上げて裏を見る姿勢を使用。
- 苔は会話で使う手描きの群落、薬草は根元に生えた新しい葉の小群落。スマホ幅で相対的に大きすぎたため、人物高の0.6倍を幅の基準とした。表示物・手を伸ばす位置・障害物の寸法は同じ値から求める。
- 共通の人物間隔より足場の左右間隔が狭く、描画補正後にアリアが採取姿勢へ入れない問題を実再生で発見。新原画の腕の長さへ合わせて間隔を広げ、`RoadMotion` の補正後も二人が採取者として残ることを検査に追加した。
