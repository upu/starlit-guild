# 2-4 山道の移動・戦闘と名前の位置（2026-10-31）

用語集の2-4「山道の入口」（`mountain-entrance`）。ミラ加入後の三人が山向こうへ続く道を進み、帰還会話は山道の休憩場所。新しい場所・道筋・シナリオ本文は追加していない。

## 実画面で見つけた問題と修正

霧狼の名前が頭から大きく離れていた。通常敵の画像は1024px角に384px高の姿を配置しており、透明な上余白を名前配置の障害物と頭位置に含めていた。以前に直した人形・ゴーレムと同じく、狼・スライムも実画像の見えている範囲を使うよう修正した。左右反転で輪郭がはみ出さない幅を取り、狼とスライムの画像を、戦闘上の同じ種類名ではなく表示フレームから識別する。

登録画像の可視範囲は狼が(290,576)から445×384px、スライムが(255,576)から515×384px。両向きの範囲はそれぞれ(289,576)から446×384px、(254,576)から516×384pxとしている。画像・人物の大きさ・戦闘判定は変更せず、名前と表示物の重なり判定だけを変えた。描画情報が未指定の敵も従来の名前へフォールバックする。比較用の従来表示と、未変換の通常敵画像の範囲は維持する。

## 通し確認

`/sprite-lab/storybook/mountain-phone` を追加し、本編と同じ `PhoneFrame` と冒険の既定選択を使う、保存しない一時データで確認した。Lv18は動きの確認条件であり、標準攻略時間・難度の検証ではない。既存の見本と同じ停止・再開を共用する。

PC幅1280×900とスマートフォン幅390×844 CSS pxで、最初から通常速度で移動・戦闘、クリア、帰還会話1/11まで進めた。連続手助け・帰着直前への移動・演出スキップは使用せず、記録を区切る間のみ一時停止した。単体の狼、複数の狼、残数の変化、三人の移動・攻撃・回復、縮尺と足元、背景の連続性を一覧と選んだ原寸画像で確認した。スマートフォン幅の複数名は画面内に折り返す。敵が右端から入る途中は一部が画角外にあり、接近後に全身が収まる。

今回の冒険の確認では名前の問題以外に新たな欠けや進行停止を見つけなかった。スライムの透明余白は画像・位置計算のテストで検査したが、スライムを含む全ステージの実画面再生は今回の範囲ではない。追記：[前後の会話の確認](storybook-mountain-dialogue-review-20261031.md)で、出発前14表示と帰還全11表示を両幅で再生し、休憩の手元を修正した。出発前から本編の冒険開始への接続、全章の最終確認、スマートフォン実機は引き続き必要。
