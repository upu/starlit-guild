# タイルとパーツで動く旅団ホームの試作

入口は `/guild-lab`。テスト機能ONの環境だけで開ける、レオンとアリア2人の描画用試作。既存ホームとは別画面で比較し、セーブ・生産・在室判定・日常会話の選択には接続しない。全員や菜園への展開、正式ホームへの置き換えは未実施。

## 実装

- `app/guild-lab/`: 試作ページ、行動・拡大・一時停止・タイルと関節の表示。レオンへのタップと同じ反応を「レオンに声をかける」ボタンでも起こせる。
- `app/phaser/guild-lab-game.ts` / `guild-lab-controller.ts`: Phaserの生成・破棄、活動への移動、表示時刻、カメラ、入力。`guild-lab-resolution.ts` は親要素のCSS寸法×DPR（上限3）へバッファを揃え、ResizeObserverとwindow resizeで追従する。Scale Managerとレンダラーを同じ寸法に揃え、CSSのタップ座標は一度だけ変換する。要求された移動だけ行い、到着すると休憩・作業・待機に移る。
- `app/phaser/guild-tile-room.ts`: 共通32単位の床タイル、2マス四方の壁タイル、タイル寸法に合わせた家具。家具画像は既存 `furniture-v3` を使用し、床へ焼き込まない。人物と机・椅子の重なりは活動位置に合わせる。
- `app/phaser/guild-cutout.ts`: キャラIDから素材とrigを選び、部位をPhaser Containerの親子関係に配置。アリアは後ろ髪とスカートも独立部品として揺らす。全身の連番画像は使用しない。表情とまばたきは頭の同じ座標へ差分パッチを重ねる。スプーンはPhaser Graphicsの小道具。
- `lib/guild-lab-model.ts`: 家具の占有寸法、活動位置、通路、二関節の角度計算、接地・遊脚・飲茶の動き。`guild-lab-art.ts` は素材のアルファ境界と差分の測定値。`guild-lab-rig.ts` は部位ごとの取り付け位置、骨の長さ、描画順、反転、関節からの延長量をまとめる。`guild-lab-contact.ts` は靴底から影の位置と幅を求める。
- `lib/guild-lab-affection.ts`: 保存しない場面内の反応。`app/phaser/guild-lab-face.ts` は表情の合成、`guild-lab-effects.ts` は感情マークとPhaser ParticleEmitterによる湯気・木くずを描く。

キャラ・家具は初期試作の50%に揃え、床は24×16マス。アリアの頭はレオンの95%の高さ。カップの縁を各キャラの回転中の口元へ合わせ、取っ手に手が届く角度を計算する。頭の取り付けは各原画の首と襟の測定値から求める。

歩行は900ms周期、接地側の足を移動速度40単位/秒に合わせて後方へ送り、遊脚は弧を描いて前へ出す。接地脚の付け根から足先までを骨の合計長49の96%に保つよう腰を上下させ、足先は床上で固定する。遊脚だけ深く曲げ、歩行中の腕は `guild-lab-arms.ts` で肩とひじの角度を直接動かし、手の水平往復からの逆算は使わない。手前の肩は前25°〜後ろ10°、ひじは後ろ7°〜前28°。奥の肩は前10°〜後ろ5°、ひじ7°〜20°とし、歩行中だけ0.68倍で奥行きを付け、裾の下へ出さない。角度と倍率は `labRig.arms` の設定にまとめる。余弦で振り、位相0では手前の腕と奥の脚、0.5では奥の腕と手前の脚が前へ出る。影は脛の先端延長と関節角度から靴底へ合わせ、接地足に応じて横に少し広がる。マントは背中に沿う細い形、高さ48、歩行時の振幅0.06。現時点は右向きの素材と左右反転による試作で、上下移動も同じ向きの絵を使用する。椅子への座り込みや活動の切替には専用の遷移動作をまだ用意していない。

## 表情と反応

通常顔の眉をやわらげ、笑顔・驚き・眠い顔・あくびを目元と口元のパッチで描く。真剣な顔は元の頭の目元、照れは通常の目元と笑顔の口＋半透明の頬で組み合わせる。表情キーは会話用の `neutral` / `smile` / `surprised` / `tired` / `serious` / `shy` に揃え、あくびは `tired` に一時的なフラグを重ねる。会話データとはまだ接続しない。笑顔は閉じた目なのでまばたきを止め、ほかの表情は従来の閉じ目パッチを使う。

- お茶を飲み終わると笑顔と♪。カップから細い湯気を出す。
- 作業に着くと真剣な顔と汗。作業中も時々切り替え、小さな木くずを出す。
- 待機が26秒続くとあくびから眠い顔へ。タップすると起きる。
- 10〜20秒ごとに見回す・伸び・鼻歌から選ぶ。飲茶中はカップを持つため見回す・鼻歌だけにする。
- レオンをタップすると驚きから笑顔へ切り替わり、軽くつぶれて跳ねる。続けてタップすると照れ、マークも変わる。家具や床へのタップでは頭を少し向ける。

マークは♪・！・汗・z Z・♥・…を図形と文字で描き、頭の右上に跳ねて現れ、消えるときは短く薄れる。部屋全体の縮小表示でも直径16 CSS px以上を保つ。レオンの判定には段階縮小後の画像を含む人物Containerの表示境界を使い、家具と重なる場所では人物を優先する。

一時停止では表示時刻・移動距離・粒子を固定。「動きを減らす」設定では目的地へ即時に移り、まばたき・部位の動き・跳ね・揺れ・粒子を止める。表情の切り替えと静止した感情マークは残す。非表示タブでは描画時間を進めない。読み込み失敗時は再読み込みボタンを表示。

## 差分の測定と縮小

`node scripts/build-guild-lab-affection.mjs` で配信用と `lib/guild-lab-art.ts` を再生成する。内部で `build-guild-lab-rig.mjs` を実行し、v2の基礎アトラスと `work/lab-base-art.json` を作る。通常の再生成では上位のaffectionスクリプトを使う。

頭のアルファ境界で生成画像を位置合わせし、確認済みの目元・口元領域内でRGB差24以上の範囲を求める。生成結果には髪などの微差もあるため、画像全体の差分は使用しない。新しい表情の検索領域は目元(120,159)、122×77pxと口元(161,233)、42×28px。その内部で測定した各パッチの矩形、差分画素数、フレームを `guild-lab-art.ts` に記録する。通常顔は目元だけを使い、口を維持する。外周3pxをフェザー処理する。合成後に元の頭のRGBAを戻し、半透明の輪郭も画素単位で維持する。

従来の閉じ目パッチは頭内の(128,184)、107×45px。口は注釈した口周辺の色条件で抽出した線の重心(178.556,243.889)を記録し、頭の縮尺・回転から飲茶の位置を求める。表情・まばたきは頭と同じ親Container内の測定座標へ配置する。

`guild-lab-filter.ts` は冒険画面の `RoadSpriteFilter` をそのまま再利用する。キャラの0.5倍の親スケールとカメラ倍率を含む表示サイズから縮小段階を選び、元フレームから半分ずつ縮小したCanvasTextureをキャッシュする。倍率・画面サイズが変わったときも元のアトラスから選び直し、縮小済み画像をさらに縮小しない。家具のタップ領域も新しいフレーム寸法へ更新する。冒険画面の処理・既存テストは変更していない。Phaser 4.2.1とChromium WebGLの組み合わせでは、多数の縮小テクスチャとTilemapを混ぜた連続描画で床の矩形が頭へ重なる現象を再現したため、この試作だけ `maxTextures: 1` でテクスチャごとに描画を分ける。飲茶サイクル中の顔の画素もブラウザーテストで検査する。

`node scripts/build-guild-lab-tiles.mjs` で床・壁の原本を各128pxへ縮小し、端の画素を外側2pxへ延長する。Tilemapは128px、margin 2、spacing 4として使い、隣のタイルや透明領域をサンプリングしない。

## 部位の重なり

奥側の腕→奥側の脚→マント→手前側の脚→胴（裾を含む）→襟→頭→カップ→手前側の腕の順。`labRigs` の各キャラの `layer` で指定してContainer内を並べる。レオンの肩は奥側(7, −80)、手前側(−8, −81)。腰は奥側(4, −56)、手前側(−5, −56)へ収め、両腿の付け根を横向きの胴の裾の後ろへ隠す。カップは手前腕より奥、胴より手前へ置き、取っ手を指で包む。アリアは後ろ髪を胴の後ろ、スカートを腿より手前に配置する。

脚は脛・ブーツを先に描き、腿をその前へ重ねてブーツ上端を隠す。腕と脚の両方で、原画上の関節中心を原点にする。上側の先端中心が骨の終点、下側の付け根中心が次の原点へ来るよう、中心間の距離で縮尺を決め、絵自体の傾きも補正する。`labLimbArtwork` はこの計算を共用する。レオンの骨長22＋27と、歩行96%の伸びは維持し、待機は99%へ伸ばす。歩行から待機の腰高さは180msで補間する。

脚の `front: "upper"` と腕の `front: "lower"` は別々の設定。描画順を決める `labLimbPaintOrder` をPhaserとテストで共用し、腿→ブーツの前後関係が腕の変更で戻らないようにする。腿のひざ側は、先に描くブーツの口を隠した状態で弧が目立たないため、今回の輪郭加工は加えない。

レオンの測定値は `guild-lab-source-config.mjs` にフレーム内の原画pxとして記録し、生成する `guild-lab-art.ts` の `armJoints` / `legJoints` に含める。前腕は手袋まで含むため、末端の把持点を従来の手の目標に合わせ、手首の位置も別に記録する。これにより飲茶・作業の手の目標と二関節計算（23＋25単位）を維持する。アリアの測定値は `build-guild-lab-aria.mjs` の透明画素帯から求める。

手前の前腕は配信用アトラス内で反転し、全測定点を `width - 1 - x` に変換する。実行時の `mirror` は使わない。奥の前腕は掌がこちらへ向き、親指が指先側へ曲がった `assets/source/guild/leon-far-palm-v4.png` から差し替える。原本を透明部分で切り抜いて既存フレームの寸法に収める手順は `build-guild-lab-affection.mjs` に記録し、差し替え後の関節中心を測定する。両腕とも `front: "lower"` とし、前腕の手袋・袖口を上腕より手前へ描く。5倍表示で逆の重なり順と比較した画像は `work/arm-layer-{upper,lower}-{walk,tea}.png` に保持する。

手前に重なる前腕の付け根の黒い外周だけ、配信用アトラスで近くの不透明な白い袖色へ置き換える。原本は残し、暗い外周を明るい袖色に置き換えたうえ、付け根の上端からひじ下までアルファを滑らかに上げて背後の上腕となじませる。内部の陰影と手袋は変えない。加工範囲は奥側が y≤42px（付け根(52,27)、フェード開始9px）、手前側が y≤57px（反転後の付け根(79,42)、フェード開始24px）、色の置換は透明境界から5px以内。変化画素数も `guildLabArt.armSeams` に記録する。後ろの上腕の丸い端は維持し、全位相で隙間を塞ぐ。

頭の首位置は原画で耳の下(107,239)とあごの下(198,263)を読み取り、その中点(152.5,251)を `build-guild-lab-rig.mjs` で記録する。胴は最終的な横向き素材の襟上部30pxから淡い色の範囲 x=53〜120px を測り、中心を86.5pxとする。両者を表示倍率で部屋座標へ変換して一致させると、頭の取り付け x は約−0.09となる。y=−85.5は維持する。飲茶の口元・カップも同じ `labRig.head` に追従する。

歩行から待機へは直前の角度から180msで補間する。お茶・作業・伸び・タップ時の跳ねは、従来の目標位置から `labJoint` で角度を求める。「動きを減らす」の歩行・待機では肩0°、ひじ7°の腕を下ろした角度へ固定する。表情・カップ・粒子・脚の動作は変更しない。

## アリアと2人の演出

アリアの外見は `docs/characters/aria-reference-sheet.webp` を正本とし、ミニキャラの塗りは `assets/source/road/aria-walk-v2.png`、表情は会話用アトラス上2行を参照した。室内ではフードを下ろし、弓と矢筒は持たない。原画 `aria-parts-v1.png` から14部品を抽出し、前髪を残した頭は `aria-head-front-v1.png`、同じ頭から生成した笑顔・驚き・眠い・あくびは `aria-head-expressions-v1.png` に保存した。目元・口元の領域だけを可逆WebPアトラス `public/guild/aria-parts-v1.webp` に重ねる。長い後ろ髪とスカートは別フレームで、歩行・待機に合わせてごく小さく回す。アリアの関節点は各部品の透明境界の上下帯から測り、`guild-lab-aria-art.ts` に記録する。

原画と測定値からの再生成は `node scripts/build-guild-lab-affection.mjs leon` と `node scripts/build-guild-lab-affection.mjs aria`。画像パスとレオンの測定点は `scripts/guild-lab-source-config.mjs` に置く。テーブル・皿・手渡す菓子の配信用画像は `node scripts/build-guild-lab-tea-props.mjs` で作る。今回の両キャラのアトラスと測定データは、再生成後のSHA-256が一致した。

テーブルは皿だけを動かせるよう、皿を除いた試作用画像 `lab-table-v1.webp` と透明な皿 `lab-cookie-plate-v1.webp` に分けた。ゲーム本編の家具アトラスは変更していない。2脚の椅子で向かい合い、飲み口の時間をずらす。皿をレオンからアリアへ寄せる→アリアが♪で1つ取る→アリアがレオンへ差し出す→レオンが驚き、少し照れ、受け取る、という順序は `guild-lab-pair.ts` で制御する。2人の間では♥と新しい台詞を使わない。寄り道はアリアが作業台近くの小物に気づく動きで、レオンは交互についていくか見守る。キャラタップは対象だけが反応し、相手はそちらを向く。

URLに `?actors=4` / `?actors=8` を付けると負荷確認用の複製を追加する。PhaserのWebGL draw呼び出しとフレーム間隔をCanvasの `data-draw-calls` / `data-frame-ms` へ記録する。390px・DPR3のヘッドレスChromium、`maxTextures: 1` で各40標本を測ると、最終回は2人43回・20ms（p95 45回・21.67ms）、4人71回・21.66ms（p95 74回・21.67ms）、8人125回・23.31ms（p95 127回・24.99ms）だった。撮り直しの間も描画命令の中央値は43→71→125回で一貫し、フレーム間隔は端末や実行負荷で変動する。詳細は `work/guild-lab-browser/load-results.json`。同条件では30fps目標の範囲に収まった。スマホ実機の体感は未確認。拡大時や長時間の負荷が問題になれば、テクスチャを分離する回避策の原因を解消するか、人物の部品をまとめて描画する方法を検討する。

## 次のキャラを追加する手順

1. 人物の外見資料・ミニキャラ・会話表情を照合し、右斜め向きの頭、襟、胴、マント、腕4、脚4を透明な独立部品として生成する。必要な髪・裾は別部品にする。指示全文を `guild-lab-prompts.json`、原画を `assets/source/guild/` に残す。
2. 原画の各部品を透明境界で切り出し、付け根と先端の中心、首、口を測る。前腕と腿の関節側の輪郭を必要なら薄くし、可逆WebPアトラスと `lib/guild-lab-<id>-art.ts` に測定値を生成する。
3. 同じ頭の表情差分を作り、目元・口元のみを位置合わせしてパッチ化する。表情キーは `neutral` / `smile` / `surprised` / `tired` / `yawn` に揃える。まばたきは目元パッチ、照れはコードの頬を使う。
4. `labRigs` / `labCharacters` にキャラIDを追加し、部位の描画順・腕脚の骨長・頭と襟・カップの口元を設定する。`GuildCutout` 自体にはキャラ専用の関節式を追加しない。
5. 関節点の一致、アトラスの透明範囲、口とカップ、表情パッチ、歩行全位相、座り・作業・タップ・低減モーションを単体テストと390px・DPR3の5倍表示で確認する。

アリアでは、最初の頭に後ろ髪まで描かれたため、頭を編集して前側だけ残し、後ろ髪を別レイヤーにした。表情画像は元の頭と大きさが異なったので、透明境界で切り出して同寸法へ登録した。皿は図形だけではテーブルの絵柄から浮いたため、試作用の透明小道具へ変更した。3人目でも部品の重なりと首・口の位置合わせは目視で再確認する必要がある。

`b781ee6` のレオンと今回の同時刻・5倍の飲茶、歩行8位相は `work/lab-seventh-comparison/` に並べた。撮影画像と負荷のJSONはローカル検査記録で、Git管理する原画・生成指示・配信用アトラスとは分ける。

`tests/test-tools.integration.mjs` はビルド後、環境フラグ7条件で試作の200/404を確認する。Miniflare 5の `convertV4MiniflareOptions` で既存テスト設定を変換する。
