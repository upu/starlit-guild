# 旅団ホーム：ドット絵調の小さな暮らし

旧 `/guild-lab` の部位合成・二関節・表情差分の試作を廃止し、5人の全身コマを使う方式へ移行した。冒険・立ち絵・会話用画像は変更しない。

## 素材と寸法

### 作業台の共通見本

`/guild-lab/work-study` は、道具を持たずに台へ向かう斜め後ろ姿の無地モデル。
`lib/home-work-study.ts` の1.6秒・4姿勢（手を伸ばす→手元を動かす→身を寄せる→戻す）で、台の上の小さな手の動きと肩・上半身の前傾を合わせる。足と添える手は固定する。金槌の打撃や特定の製作品は共通動作に含めない。
水色の奥腕は胴より奥、オレンジの手前腕は胴より手前に描く。奥腕の肩から上腕は胴に隠し、台へ伸ばした部分だけを見せる。
右利き・左利き、4コマ表示・滑らかな補間、低速、姿勢送り、スライダー、関節表示、人物約48pxの小表示を比較できる。左利きの無地モデルは台ごと反対側から見た鏡像で、実素材を反転する指定ではない。
お茶と再生処理を `app/guild-lab/study-player.ts` で共有し、テスト機能ONのみ公開する。動きを減らす設定・OS設定で停止し、非表示タブでは時間を進めず、端末保存へ書き込まない。
採用した共通見本を5人の `*-work-v1.png`（1536×1024、2列2行）へ展開した。道具なしの斜め後ろ姿で、リコだけ左手・ほか4人は右手を中心に動かす。実素材は反転しない。奥腕は胴の向こうに隠し、髪や袖によっては手先まで隠れる。金槌用の火花は作業時に出さない。事務作業にもこの4コマを共用する。作業台の比較ページで「事務机で比較」を選び、同じ手元の動きを書類のある天板に重ねる。専用の羽根ペンや追加の事務素材は作らない。歩行・お茶は維持する。
配信は `scripts/home-work-frames.mjs` → `*-work.webp`（512×128、128pxセル4枚）。4コマで共通の縮尺を使い、靴底の高さと中心を揃える。頭の位置合わせは行わず、描いた前傾を残す。旅団ホームと見本ページは `residentWork` の1.6秒周期を共有する。立ち位置は天板へ届くように近づけ、リコは右寄り、ほか4人は左寄りとする。移動経路・保存する家具の占有マスは変えず、表示とタップ判定に同じ補正を使う。
生成は組み込みimage_genを7回、初回5枚とアリア・リコの腕修正各1回。採用した5原本を無加工で保存。[指示全文・参照・採否](../art-generation/home-pixel-work.json)。アリアの2コマ目で重複して見えた奥腕と、リコの背中側に出た手を修正した。拡大と小表示で、手前腕の動き・奥腕の遮蔽・天板との位置・足元を目視確認した。生成コマ間の衣装や髪の細部には微差が残り、全関節が無地モデルと完全一致するものではない。
検査は `tests/home-work-study.test.mjs` / `tests/home-work-study.browser.mjs`、実際の部屋は `tests/home-room.browser.mjs`。左右の無地モデルと5人×4姿勢、320/390/844/1000pxの撮影は `work/pixel-home/work-study/`。スマホ実機は未確認。

### お茶と会話の共通見本と5人の比較

`/guild-lab/tea-study` は椅子・テーブルと2人の無地モデルを使った制作見本。
`lib/home-tea-study.ts` の8秒・4姿勢（構える→持ち上げる→飲む→下ろす）を、連続再生・低速・姿勢送り・スライダーで確認する。
腰と足裏を固定し、空いた手はひざ元、もう片手で取っ手を持ってカップの縁を口元へ運ぶ。
カップは下ろしたときもテーブルの高さで構え、ひざ元には下げない。
2人は4秒ずらす。笑顔とうなずきは独立した反応として、相手が飲む間の構えに重ね、飲茶のコマ数には含めない。人物の寸法を変えずに頭だけ小さく傾ける。
無地モデルの向かい側の人物は鏡像のため利き手も反対。5人の実素材では左右向きを描き分け、リコだけ左手、ほか4人は右手を維持する。

動きと家具の接点を見るSVG見本と、旅団で使う5人のお茶コマを同じ時刻で比較する。受入済みの歩行は変更しない。
テスト機能ONのみ公開。再生は手動開始で、「動きを減らす」・OS設定・タブ非表示で停止し、端末保存へ書き込まない。
仲間を選ぶと左右向きと4姿勢を切り替えられる。実素材は斜め向きで、見本の真横向きとは分ける。
検査は `tests/home-tea-study.test.mjs` / `tests/home-tea-study.browser.mjs`。
姿勢一覧と320/390/844/1000pxの画像は `work/pixel-home/tea-study/`。ブラウザー確認とスマホ実機は区別する。

ミラのお茶は、採用済みの顔アップを基準に、頬だけでなくこめかみ・目の幅と間隔・あごを含む顔全体を細め、目と眉の位置を上げた。眠たげなまぶたを残し、左右各4コマの原本と共通の配信アトラスへ反映する。頭全体の縮小や実行時の変形は行わない。[指示全文・参照・採否](../art-generation/home-pixel-tea-mira-face.json)。

さらに顔の細さを強める修正では、目の横幅・左右の間隔まで含めて調整した。高めの目の位置と髪全体の大きさは保ち、左右各4コマへ適用する。[追加の生成記録](../art-generation/home-pixel-tea-mira-narrower.json)。指示内の縮小率は生成の目安であり、測定結果ではない。

フィンとリコも、細めたミラを基準に顔全体・目の幅と間隔を調整。フィンの余裕のある目元、リコの丸眼鏡と緑の瞳、各自の髪の大きさは残す。左右各4コマとも、フィンは右手、リコは左手でカップを持つ。[生成指示・参照・保存先](../art-generation/home-pixel-tea-finn-lico-face.json)。

### 配信用素材

- 原本：`assets/source/home-pixel/`。内蔵 image_gen で5人、家具、床の7枚と、歩行専用の5枚、椅子と後ろ姿の5枚、感情マーク・菜園小物の2枚を生成。指示全文は [生成記録](../art-generation/home-pixel.json) 、[歩行の生成記録](../art-generation/home-pixel-walk-v2.json)、[着席・後ろ姿・小物の生成記録](../art-generation/home-pixel-actions.json)。原本は保存し、配信用だけを生成する。
- 5人は正面・横向き16コマ、生活12コマ（後ろ歩き6、旧お茶2、金槌2、書類2）、専用のお茶8コマ（左右各4）、道具なしの作業4コマ、水やり4コマを持つ。旧16コマ内のお茶・金槌・書類・菜園と生活シートの旧お茶・金槌・書類は表示しない。画面上の待機は高さ48単位・セル64×64。配信画像は高さ96px・セル128×128へそろえ、顔の読みやすさを残しながら画素の粒を見せる。
- 温かいドット絵調。元画像の細かな塗りを含むため、厳密な手打ち48pxピクセルアートではない。
- 絵柄の正本は10月3日01時台の5人の基本シート `*-v1.png`。頭身・陰影の粒感をこの原画に合わせ、歩行は頬の丸みを控えめにし、腕を体の横で小さく振る前半・後半各4コマの `*-walk-v9-a.png` / `*-walk-v9-b.png`、背面歩行は6コマの `*-rear-walk-v3.png`（リコのみv4）を使う。ミラの待機・手振りは輪郭を合わせた `mira-v3.png`。リコは後頭部の中央で結び、首の後ろへ下ろすポニーテールへ修正した `lico-v4.png` と `lico-actions-v3.png` を使い、歩行・お茶・机仕事でも髪型をそろえる。ミラの重いまぶたと目の下の影、優しい微笑み、リコの眼鏡を残す。[原画基準へ戻した生成記録](../art-generation/home-pixel-original-style.json)と[頬・ポニーテールの生成記録](../art-generation/home-pixel-face-hair.json)に指示と採否を保存。
- 論理画面384×312、1マス24、16列13行。家具は足元から描き、歩行判定・席の位置は同じマス座標を使う。家具6種類と固定菜園、6席のテーブル。
- 配信用は `public/home-pixel/` のlossless WebP。`npm run home-art:optimize` で透明境界と頭の連結部分の測定→立ち姿96pxへの正規化→頭の中心合わせ→固定セル化。原本から配信画像へはLanczos3で一度縮小し、目や輪郭の欠けを防ぐ。PhaserではNEAREST補間にして、画面拡大で粒がぼやけないようにする。家具・床は既存のnearestを維持する。生成物の一致は `npm run home-art:check`。靴底・感情マーク・湯気・作業の粒子・空椅子は人物の表示寸法へ追従し、タップ範囲の上端も人物の高さに合わせる。
- 歩行は1周期24単位の実移動距離に合わせ、正面・横向き8コマ、奥へ向かう移動は後ろ向き6コマを送る。停止・挨拶中は歩行距離も止まる。足やマントの外接矩形で左右の中心を決めず、原画上部38%の最大連結部分（頭）で位置合わせする。持ち上げた金槌・羽根ペンは頭の測定に含めない。位置ずれとは別に、歩行中は一歩12単位ごとに全身を変形せず、足を通す位相だけ表示0.5単位上へ動かす。接地位相で戻す。正面と後ろ向きで同じ距離の周期を使い、静止・挨拶・動きを減らす設定では止める。測定結果は配信用の anchors.json に保存する。
- シートの段境界は透明な行で検出し、隣のコマの髪などを混入させない。頭は原本だけでなく、縮小後の透明境界・連結部分も測り直して位置を合わせる。原画の粒感を保つことと、顔を低解像度化して欠けさせることは区別する。
- バッファは表示寸法×DPR（上限3）。「拡大する」で2倍、「部屋全体」で元へ戻す。拡大中はスワイプ・ドラッグ・矢印キーで移動し、Homeキーで中央へ戻す。部屋の外へ出ないようカメラ位置を制限する。`HomeRoomView` がドラッグとタップを分け、現在のCanvas矩形とカメラからタップ位置を変換する。倍率・カメラ位置は端末保存へ書き込まない。

## 部屋と生活

`lib/home-actor.ts` は部屋やセーブから独立した人物・動作の定義。今後、冒険・待機・会話の上半分へ使うときは、この全身コマとフレーム規約を再利用できる。今回、それらの画面の表示は置き換えていない。

`lib/home-room-layout.ts`：家具の占有範囲、6席・作業位置、4方向の経路探索。家具の重なり、入口の閉塞、使う位置に到達できない配置を拒否する。`home-room-schema.ts` で保存データにも同じ検査を適用する。

お茶は椅子と人物を一緒に描いた全身コマを使い、着席中の空椅子は非表示にする。膝を直角に曲げ、すねを下ろし、カップは取っ手を片手で持ち、空いた手は膝に置く。座る瞬間に床座りコマへ切り替えない。

### 斜め向きのお茶4コマ

共通見本の「構える・持ち上げる・飲む・下ろす」を5人へ反映。正面寄りの斜め向きで両目を見せ、カップはひざ元へ下げない。`*-tea-v1-right.png` / `*-tea-v1-left.png` の各2×2原本から、右4コマ・左4コマの `*-tea.webp` を作る。1コマ128px、人物96px高、表示セル64単位、8秒周期。原本は生成出力を無加工で保存し、既存と同じ縮小・頭の位置合わせ・可逆WebPの工程を通す。

リコは左手、ほか4人は右手。左向きを描き分け、茶席で画像を反転しない。歩行・作業・背面の配信画像は維持する。制作ページ `/guild-lab/tea-study` は同じ配信素材を使い、5人・左右向き・4姿勢・拡大と小表示を比較する。無地モデルは横向きの動作ガイドであり、実素材のカメラ角度とは分ける。表情とうなずきの重ね方は無地モデルでの見本のまま。実素材は各コマに描いた表情とホームの既存の感情マークを使う。

「顔を小さく」の指示は、頭全体の縮小ではなく頬の下側を上げて輪郭をすっきりさせる意味と確認。ミラ・フィン・リコは頬からあごを持ち上げる画像編集へ修正した。表示時の顔だけの変形はしない。[生成指示・参照・採否](../art-generation/home-pixel-tea.json)。初回の頭全体を縮めた候補、利き手が入れ替わる候補、カップが浮く候補は最終原本にしない。

目視記録は `work/pixel-home/tea-study/<id>-right.png` / `<id>-left.png`、ホームは `work/pixel-home/tea-390.png`。4コマでカップを片手に保ち、椅子に座る姿勢と頬の輪郭を確認。描き分けのため左右で服の細部に差があり、コマ間の微小な髪の輪郭・大きさの差も残る。頬の上げ幅の最終的な好みはユーザー確認とし、自動検査を見た目の承認に代えない。ブラウザー確認とスマホ実機を区別し、実機は未確認。

テーブルは6人用の大きさを維持し、天板には注ぎ口のあるティーポットだけを置く。人物が持つカップと重複するカップ・皿は置かない。原本は `table-v2.png`、指示は [背面・テーブルの生成記録](../art-generation/home-pixel-rear-table.json)。

テーブル奥の席は、通路上の到着位置から座面へ32単位寄せて描く。椅子・着席した人物・タップ判定で同じ補正を使い、移動経路は家具の占有範囲の外に保つ。

人物の小表示に合わせ、テーブル・事務机・作業台の絵を以前の84%にする。テーブルの6席も同じ床の基準点へ84%で寄せる。`lib/home-room-presentation.ts` が空椅子・着席人物・タップに共通の位置を返す。既存の家具の占有マス、保存済み座標、移動経路は維持し、家具を動かすと絵と椅子も同じ移動量で動く。

`lib/home-room-life.ts`：席を予約して歩き、着いたらお茶・手入れ・書類・水やり。目的地で30秒前後過ごす。お茶の仲間同士の小さな反応、タップへの手振りやハート、湯気・水滴。作業中の担当者は作業台に固定。減らす設定とOSのprefers-reduced-motionはコマ・移動・粒子を止める。一時停止と非表示タブでも時計を進めない。

本編では在室判定・菜園担当・作物の進捗を既存データから受け取る。生活時計から報酬や作物を増やさない。机と作業台は手前の中央マスから奥を向いて使う。作業台と事務机は、道具を固定せず手元を動かす同じ4コマを使う。リコが左手、ほか4人は右手で、画像は反転しない。挨拶中も机仕事の向きを保ち、ハートだけで反応する。過去の横側からしか机に接近できない配置もセーブ検査で読み込めるように保つが、新しい家具配置の確定には手前の通路が必要。

リンデは日当たりのよい花の門・苗棚と薬草、ブレッカは木陰の乾燥小屋・苔むした柵と苔床。ブレッカの栽培所は塔から離れている既存設定に従い、塔は追加しない。両方とも床はタイル、小物は個別画像で、背景小物は北側の非通行帯へ置く。♪・♥・…は透明な感情マーク画像で、文字の背景枠は使わない。

配置だけは `guildArrange` で既存セーブの任意項目 `guild.home` に保存。旧セーブには初期配置を表示する。家具編集は下書き→確定で保存、取り消しで復元。テーブル・作業台・事務机は最低1つ残す。配置用の家具は無償、購入経済は追加していない。

`/guild-lab` はテスト機能ONでのみ公開。常に5人を表示して見た目・動きを試せるが、配置はページ内だけに保持し、端末保存へ書き込まない。レイアウトの編集とアクセシブルな操作はDOM、部屋と生活はPhaser。

## 新しい仲間・家具の制作

1. 同じ画風・大きさで、全身の歩行・待機・生活コマをそろえる。体の一部分を別生成して関節でつながない。
2. 頭の位置と立ち姿の高さをそろえて同じセルへ入れ、頭身・手に持つ物・左右の足が連続するか一覧と実ループで確認。コマが完全に同じでないだけでは歩行の合格にしない。背面は接地した足が左右で入れ替わり、持ち上げた足が床より高いことを確認する。正面は足を通す姿勢に加え、接地姿勢で腿の前後関係も確認する。数値検査だけで絵の自然さが保証されたとは扱わない。
3. 家具は床を含めず、占有マスと使用位置を定義。座る場所と椅子、作業する手と机、水の落ちる場所と土を実表示で確認する。
4. 320/390pxの小表示で人物を区別できるか、拡大でも輪郭が切れないか確認。原本・生成指示・配信生成を一緒に残す。
