# 旅団ホーム：ドット絵調の小さな暮らし

旧 `/guild-lab` の部位合成・二関節・表情差分の試作を廃止し、5人の全身コマを使う方式へ移行した。冒険・立ち絵・会話用画像は変更しない。

## 素材と寸法

- 原本：`assets/source/home-pixel/`。内蔵 image_gen で5人、家具、床の7枚と、歩行専用の5枚を生成。指示全文は [生成記録](../art-generation/home-pixel.json) と [歩行の生成記録](../art-generation/home-pixel-walk-v2.json)。原本は保存し、配信用だけを生成する。
- 5人は各16コマ。歩行8、待機、手振り、お茶2、作業2、水やり、書類。画面上の待機の高さ60単位・セル80×80は維持し、配信画像はその4倍（高さ240px・セル320×320、4列4行）を使う。細かな原画を60pxへnearest縮小すると輪郭や顔が欠けるため、画像の解像度と表示寸法を分離する。
- 温かいドット絵調。元画像の細かな塗りを含むため、厳密な手打ち48pxピクセルアートではない。
- 論理画面384×312、1マス24、16列13行。家具は足元から描き、歩行判定・席の位置は同じマス座標を使う。家具6種類と固定菜園、6席のテーブル。
- 配信用は `public/home-pixel/` のlossless WebP。`npm run home-art:optimize` で透明境界の測定→共通倍率→固定セル化。キャラはLanczos3縮小、Phaserの人物テクスチャはLINEAR補間。家具・床は既存のnearestを維持する。生成物の一致は `npm run home-art:check`。
- 歩行は1周期24単位の実移動距離に合わせて8コマを送る。停止・挨拶中は歩行距離も止まり、上下動も同じ位相に従う。歩行原本内の横位置を保持し、各コマの腕・マントの張り出しで体の中心を再計算しない。
- バッファは表示寸法×DPR（上限3）。カメラで倍率調整。タップはイベントのCSS座標と現在のCanvas矩形から変換し、パネル内スクロールにも対応する。

## 部屋と生活

`lib/home-actor.ts` は部屋やセーブから独立した人物・動作の定義。今後、冒険・待機・会話の上半分へ使うときは、この全身コマとフレーム規約を再利用できる。今回、それらの画面の表示は置き換えていない。

`lib/home-room-layout.ts`：家具の占有範囲、6席・作業位置、4方向の経路探索。家具の重なり、入口の閉塞、使う位置に到達できない配置を拒否する。`home-room-schema.ts` で保存データにも同じ検査を適用する。

テーブル奥の席は、通路上の到着位置から座面へ32単位寄せて描く。椅子・着席した人物・タップ判定で同じ補正を使い、移動経路は家具の占有範囲の外に保つ。

`lib/home-room-life.ts`：席を予約して歩き、着いたらお茶・手入れ・書類・水やり。目的地で30秒前後過ごす。お茶の仲間同士の小さな反応、タップへの手振りやハート、湯気・水滴・作業の火花。作業中の担当者は作業台に固定。減らす設定とOSのprefers-reduced-motionはコマ・移動・粒子を止める。一時停止と非表示タブでも時計を進めない。

本編では在室判定・菜園担当・作物の進捗を既存データから受け取る。生活時計から報酬や作物を増やさない。配置だけは `guildArrange` で既存セーブの任意項目 `guild.home` に保存。旧セーブには初期配置を表示する。家具編集は下書き→確定で保存、取り消しで復元。テーブル・作業台・事務机は最低1つ残す。配置用の家具は無償、購入経済は追加していない。

`/guild-lab` はテスト機能ONでのみ公開。常に5人を表示して見た目・動きを試せるが、配置はページ内だけに保持し、端末保存へ書き込まない。レイアウトの編集とアクセシブルな操作はDOM、部屋と生活はPhaser。

## 新しい仲間・家具の制作

1. 同じ画風・大きさで、全身の歩行・待機・生活コマをそろえる。体の一部分を別生成して関節でつながない。
2. 足元を基準に同じセルへ入れ、頭身・手に持つ物・左右の足が連続するか一覧と実ループで確認。コマが完全に同じでないだけでは歩行の合格にしない。
3. 家具は床を含めず、占有マスと使用位置を定義。座る場所と椅子、作業する手と机、水の落ちる場所と土を実表示で確認する。
4. 320/390pxの小表示で人物を区別できるか、拡大でも輪郭が切れないか確認。原本・生成指示・配信生成を一緒に残す。
