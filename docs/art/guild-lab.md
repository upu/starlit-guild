# タイルとパーツで動く旅団ホームの試作

入口は `/guild-lab`。テスト機能ONの環境だけで開ける、レオンとアリア2人の描画用試作。セーブ・生産・在室・日常会話の選択には接続しない。正式ホームへの適用や上下移動の向きは次の段階で扱う。

## 描画・入力・カメラ

- `app/phaser/guild-lab-game.ts` / `guild-lab-controller.ts`：生成・破棄、移動、時刻、カメラ、入力。移動は到着すると止まる。
- `guild-lab-resolution.ts`：親要素のCSS寸法×DPR（上限3）へ描画バッファを合わせる。ResizeObserverとwindow resizeに追従し、入力座標を一度だけ変換する。
- `guild-tile-room.ts`：32単位の床タイルと独立した家具。原本 `assets/source/guild/room-tiles-v1.png` を、`node scripts/build-guild-lab-tiles.mjs` で各128pxへ縮小し、端を外側2pxへ延長する。Tilemapはmargin 2、spacing 4。
- `guild-cutout.ts`：キャラIDから素材とrigを選び、Phaser Containerで親子をつなぐ。全身の連番画像は使わない。
- `guild-lab-filter.ts`：冒険の `RoadSpriteFilter` を再利用。部品の表示サイズ・親スケール0.5・現在のカメラ倍率から段階を選び、元フレームを半分ずつ縮小したCanvasTextureをキャッシュする。縮小済み画像を重ねて縮小しない。WebGLの矩形混入を防ぐため、この試作だけ `maxTextures: 1` とする。

CSS幅600px未満の初期倍率は2.1倍（約11.4マス幅）。PCの初期表示は部屋全体の1倍。「部屋全体」／「住人を追う」で切り替える。PCの追従表示は1.8倍。`guild-lab-camera.ts` は2人の足元の中心から顔へ寄せ、180msの指数補間で追う。部屋の外を映さず、一時停止中も切り替えられる。家具の入力と縮小キャッシュも現在の倍率を使う。以前の素材で測ったサイズ表は新しいレオンには流用せず、`work/lab-fifteenth-after/camera-sizes.json` の今回の測定を見る。

## 完成した絵を基準にする

両キャラとも、完成した立ち姿を先に用意してから切り出す。

| キャラ | 完成絵・注釈した座標 | 配信用 | rig |
| --- | --- | --- | --- |
| レオン | `leon-master-v7.png` / `.json` | `leon-parts-v4.webp`（25枠） | `guild-lab-leon-rig.ts` |
| アリア | `aria-master-v5.png` / `.json` | `aria-parts-v1.webp`（38枠） | `guild-lab-aria-rig.ts` |

原画・完成した隠れ部分・表情の編集原本は `assets/source/guild/`。レオンは顔と服を同じ斜め右向き（約45°）にし、ベルトの正面と両足の自然な開きを1枚絵で決めた。切り出しは `guild-lab-leon-master.mjs`、アリアは `guild-lab-master-layers.mjs`。各 `<キャラ>-parts/measurements.json` に、原画内の矩形・関節・見える塗りと描き足した塗りを残す。付け根・口・頭の高さを別の手調整値で合わせない。頭はあごまでで、首は描かない。隙間を防ぐ小さな首の土台は頭と襟の奥に置く。

再生成：

```powershell
node scripts/build-guild-lab-rig.mjs leon
node scripts/build-guild-lab-rig.mjs aria
```

内部では `build-guild-lab-leon.mjs` / `build-guild-lab-aria.mjs` を使う。旧 `build-guild-lab-affection.mjs` も現在のレオンの生成へ委譲する。以前の部品別生成へ戻さない。配信は透明を保つ可逆WebP。採用する部品には原本で8px、アトラスでさらに4pxの余白を置き、原点と測定値にも余白を反映する。

`guild-lab-master.test.mjs` はアリアの未変更領域の輪郭と、胸・上腕の可視率を確認する。髪・スカートの異物除去は原画を修復したため、`material-repairs.json` の明示した矩形だけを元の未修復絵との比較から除外する。完成絵全体を実装から再生成して比較の基準にしない。レオンは独立した完成絵との輪郭差を検査し、`work/lab-fifteenth-comparison/leon-master-vs-rig.png` に並べる。元絵と比較する検査はテストから基準絵を作り直さない。

## 完全な裏を描く・素材の所有

腕の後ろの脇・胴、マントの内側、肩掛けの下、スカートの後ろは、透明にせず周囲と同じ陰影で描く。単色の下塗りを表に出さない。`trim-guild-lab-underpaint` は使わない。隠れていた部分が動作で見えること自体は正常で、布や髪として自然に塗られている必要がある。

アリアの切り出しに混ざった手袋・肌・緑の服は、元の切り出しを参照した編集原画 `aria-cleanup-v7.png` で修復する。`guild-lab-materials.mjs` は、記録した原画内の矩形へ髪だけ・布だけの修復を登録する。旧手袋の輪郭を髪のアルファへ残さない。スカートより下の肌は脚へ割り当てる。色だけでは肌と暖色の布影を区別できないため、色条件には所有領域のマスクを合わせる。髪の緑色の異物と、布の許可領域より下の画素を検査し、手袋など同系色の混入は拡大画像でも確認する。

### 重なり順（奥 → 手前）

マントの裏 → 奥側の腕 → 奥の髪の房 → スカート裏 → 奥側の脚 → 手前側の脚 → スカート表 → 胴 → 手前側の腕 → マントの表（肩掛け）→ 前・後ろの髪の房 → 頭。レオンには髪の房・スカートの独立部品はない。

- マントの裏は背中の本体と描いた裏地。表は肩の付け根を覆い、ひじより上で終わる。腕はその下から出る。
- アリアのスカート裏は脚の後ろに描く、暗いクリーム色の布。表は前の布・腰ベルト・飾り。両方の原点を同じ原画の腰へ置く。両脇を多めに描き足し、表裏の角度差を0.06rad以内にする。
- 表のスカートは腿へ0.5倍追従し、回転最大0.25rad、幅最大1.12倍、縦0.97〜1.03倍。裏は180msで少し遅れて追従する。停止後はばねで減衰し、座位と動き低減時は固定する。
- レオンの脚は腿が手前、アリアの座位はブーツの口が手前。腕は手袋が手前。腕と脚の設定は独立させる。
- 飲茶のカップは持ち上げる間だけ顔の前へ、持つ前腕はさらにその前へ描く。複製した前腕も元のひじ・手の変換を共有する。

## 同じ画素から曲げ差分を作る

アリアは長いブーツと短い腿を1本の脚にして腰から振る。直線脚から遊脚だけ16°曲げた絵へ切り替える。レオンは二関節の脚を使う。アリアの大きく曲がる腕は60°・105°・奥85°の連続した絵を選び、従来の肩と把持点へ登録する。

`guild-lab-pixel-bends.mjs` は、まっすぐな絵の手袋・ブーツの画素を測定した関節で回転する。別々に生成した革や装飾を採用しない。関節の小さな切り出し穴だけ、近くの陰影で埋める。元画像・生RGBAのSHA-256・回転・関節・矩形を `variants.sharedSource` に記録する。関節から40pxより遠い手袋・ブーツの画素が元と完全に一致することを検査する。中央値だけをそろえる色補正は廃止した。両差分は同じアトラス・解像度・フィルターを使い、足の革は歩行中も同じフレームを使う。

## 足首と歩行

`guild-lab-foot-paint.mjs` で、同じ元画素のブーツを筒と足に切る。アリアは従来の上下20px、レオンは測定した足首を中心に上下最大28pxの丸い形で重ねる。レオンは筒を足より手前に置き、足の上端を覆う。足首の中心と靴底の2点を原画から記録する。`guild-lab-feet.ts`（Phaser）は足を脛の親から分け、現在の足首位置だけを受け取る。脛が傾いても足裏を床へ向けられる。

`guild-lab-ankles.ts` は、900ms周期の接地中央で足裏を水平にする。最初の約50msはつま先を10°上げ、最後の約50msは15°下げる。遊脚は最大7°つま先を上げる。元絵の靴底の傾きを相殺する。立ち待機・座位・低減時は元の絵の角度を保つ。着地中央の±5°、足首の重なり、元画素の一致を検査する。靴底までの距離から接地点と影を求め、旧「脛の端＝床」の検査は使わない。

腰・足先は完成絵から測り、足先と付け根の並びをそろえて交差を防ぐ。歩行から待機へ180msで足を3単位持ち上げて踏み直す。腕は歩行・立ち待機で肩とひじの角度を直接使い、お茶・作業・タップの反応では目標から逆算する。短い前歩幅・長い後歩幅と、上半身の前傾（レオン2°・アリア3°）をキャラ別に設定する。移動速度も歩幅と周期から求める。

## 表情と愛着

切り出した頭を編集し、輪郭で登録してから目元・口元の肌だけをマスクにする。元と差分の目の領域を合わせて広げ、閉じ目では元の白目・瞳も覆う。髪・頬・あごの線はパッチに含めない。口の測定点と頭の回転からカップの縁と把持位置を計算する。

`neutral` / `smile` / `surprised` / `tired` / `serious` / `shy` を会話絵とそろえる。笑顔とあくびは追加のまばたきを止める。飲み終わった笑顔と♪、作業の汗・木くず、待機の眠気、見回す・伸び・鼻歌、タップの驚き→笑顔、連打の照れを維持する。「動きを減らす」では跳ね・揺れ・粒子を止め、表情と静止した感情マークを残す。

## キャラを追加する手順

1. 人物資料・会話絵・道中絵を参照し、完成した立ち姿を1枚描く。頭と服の向き・足の開き・手足の太さ・首を見せないことを先に決める。
2. その絵を各部品へ切る。髪はつながった髪を2〜3房へ、マントとスカートは裏と表へ。胴は腰まで。隠れた部分も陰影のある完全な形へ描き足す。
3. 所有マスクと共通の `guild-lab-material-audit.mjs` で、肌・手袋・服が別の部品に混ざっていないことを両キャラで確認する。素材境界の測定値で服の角や肩当てを所属する部品へ戻す。髪は髪だけ、スカートは布とその飾りだけにする。近い色の陰影や輪郭には少数の許容画素があるので、`node scripts/guild-lab-swatchbook.mjs` で配信用の全部品を市松模様の見本帳に並べ、必ず目視する。
4. 単独の腿の描き足しに、両脚の絵を丸ごと登録しない。膝の袖口に隠れる短い延長だけにする。原画の関節・腰・頭・口・靴底を測り、同じ位置関係で組む。足先の並びと膝の伸びも元絵で決める。
5. 顔の差分は元の頭から編集し、位置合わせとマスクで作る。全採用部品に透明余白があり、閉じ目に元の瞳が残らないことを検査する。
6. 長いブーツ・短い腿なら1本脚、ほかは二関節を選ぶ。大きな曲げ差分は同じ画素のブーツ・手袋を回転して作り、関節周辺だけを描き直す。足首は筒と足を別にし、両方を同じ測定点で回す。筒を手前へ重ね、上下28原画pxの丸い重なりで足の上端を覆う。伸びは肩152〜162°・ひじ15°の直接指定へ補間する。近い頭上の目標へのIKは使わない。お茶・作業のIKは維持し、ひじは150°まで、前側へ曲げる。部品の基準角は完成した立ち絵から測る。
7. 基本姿勢を独立した完成絵と比較する。輪郭・胸・上腕の可視率・首の透け・足の交差を検査する。奥の手も個別に比較する。奥の上腕は胴の後ろでも、元絵で見える前腕は別の描画層へ置き、元の関節変換を共有する。修復した絵の領域は明示し、全体を実装から基準化しない。
8. 4〜5倍で、お茶・歩行1周期と切り替えの前後・待機・反応・低減を目視する。表裏の隙間、足裏、部品の色の変化、衣服の透けを見る。原画・切り出し・描き足し・指示全文・比較画像を保存する。

## 今回の比較と検証

16回目の変更前 `9604bd7` の応答とアトラスは `work/lab-sixteenth-baseline/`。390px・DPR3・5倍の変更前後は `work/lab-sixteenth-before/` / `work/lab-sixteenth-after/`、比較一覧は `work/lab-sixteenth-comparison/`。両キャラの歩行12コマ、お茶・立ち待機・伸び、レオンの全部品の見本帳を残す。従来の歩行16コマ・差し替え付近・表情・反応も維持する。数値検査は補助とし、画像を目で見て判断する。

レオンの素材境界は `leon-master-v7.json` の `materialSeams` に原画内の点を記録する。隠れる布・袖・腿は `leon-completed-clothes-v8.png` の閉じた塗りで補完する。原本の6部品は機械的な等分ではなく、不透明部分が隣の行へ伸びた境界も測って登録する。部品の所属を戻したことで、前腕の青い服・上腕の赤いマント・頭の赤い襟が動く部品へ混ざらない。

アリアの奥の手はアルファではなく、描き足した胴との描画順で隠れていた。`guild-lab-forearms.ts` が奥の前腕だけを胴の前へ描き、元の親子関節の変換を共有する。元絵で見える手の画素は、独立した比較項目で可視率と色の一致を検査する。

「伸びを試す」で両キャラを立ち待機にして、肩152〜162°・ひじ15°を直接指定する。お茶・作業は従来のIKを使う。完成絵の自然な待機に含まれる部品の基準角を保ち、その角から前側にだけ曲げ、最大150°までに制限する。動き低減時は待機角へ固定する。

比較画像の目視では、レオンの前腕の青い服の角と頭の赤い襟がなくなり、歩行12コマの蹴り出しに目立つ足首の隙間がないことを確認した。伸びのひじはほぼ伸びた角度になり、アリアの奥の手は待機・歩行・お茶で見える。見本帳には表情差分と足の部品も含めて全フレームを出力する。比較一覧は歩行・待機・伸び・お茶を並べ、元の5倍画像も残す。

`guild-lab-finishing.test.mjs` は両キャラ共通の異物色、全動作のひじ、足首の測定点と重なり、アリアの奥の手を検査する。`guild-lab-ankles.test.mjs` は靴底・重なる革・同一画素、`guild-lab-completed-paint.test.mjs` は衣服の穴と関節・レオンの完成絵、`guild-lab-master.test.mjs` は元絵・胸・上腕・スカートを確認する。既存の表情・反応・距離・低減・停止・読み込み失敗の再試行・端末保存しない検査は維持する。

比較撮影と各画面幅の確認はChromiumによるブラウザー検証。スマホ実機は未確認で、大きさ・体感の確認が別途必要。生成の指示全文は `guild-lab-prompts.json` に保存する。菓子・スプーンの演出を追加・調整していない。
