# 旅団ホーム：ドット絵調の小さな暮らし

旧 `/guild-lab` の部位合成・二関節・表情差分の試作を廃止し、5人の全身コマを使う方式へ移行した。冒険・立ち絵・会話用画像は変更しない。

## 素材と寸法

### お茶と会話の共通見本（5人への展開前）

`/guild-lab/tea-study` は椅子・テーブルと2人の無地モデルを使った制作見本。
`lib/home-tea-study.ts` の16秒・8姿勢を、連続再生・低速・姿勢送り・スライダーで確認する。
腰と足裏を固定し、空いた手はひざ元、もう片手で取っ手を持ってカップの縁を口元へ運ぶ。
2人は8秒ずらし、相手が飲む間に笑顔でうなずく。人物の寸法を変えずに頭だけ小さく傾ける。
向かい側の人物は鏡像のため利き手も反対。5人へ描く段階ではリコだけ左手、ほか4人は右手を維持する。

このページは動きと家具の接点を見るためのSVG見本であり、ゲームのドット絵素材や歩行を変更しない。
テスト機能ONのみ公開。再生は手動開始で、「動きを減らす」・OS設定・タブ非表示で停止し、端末保存へ書き込まない。
見本の確認後に各人物の全身コマへ展開する。まだ5人のお茶素材には反映していない。
検査は `tests/home-tea-study.test.mjs` / `tests/home-tea-study.browser.mjs`。
姿勢一覧と320/390/844/1000pxの画像は `work/pixel-home/tea-study/`。ブラウザー確認とスマホ実機は区別する。

### 配信用素材

- 5人は正面・横向きの16コマに加え、各12コマの生活シート（後ろ歩き6、椅子でお茶2、後ろ向きの金槌2、書類2）を持つ。旧16コマ内のお茶・金槌・書類は現在表示しない。画面上の待機は高さ48単位・セル64×64（以前の80%）。配信画像は高さ96px・セル128×128へそろえ、顔の読みやすさを残しながら画素の粒を見せる。原本の寸法・頭身は変更しない。
- 温かいドット絵調。元画像の細かな塗りを含むため、厳密な手打ち48pxピクセルアートではない。
- 絵柄の正本は10月3日01時台の5人の基本シート `*-v1.png`。頭身・陰影の粒感をこの原画に合わせ、歩行は頬の丸みを控えめにし、腕を体の横で小さく振る前半・後半各4コマの `*-walk-v9-a.png` / `*-walk-v9-b.png`、背面歩行は6コマの `*-rear-walk-v3.png`（リコのみv4）を使う。ミラの待機・手振り・菜園は輪郭を合わせた `mira-v3.png`。リコは後頭部の中央で結び、首の後ろへ下ろすポニーテールへ修正した `lico-v4.png` と `lico-actions-v3.png` を使い、歩行・お茶・机仕事でも髪型をそろえる。ミラの重いまぶたと目の下の影、優しい微笑み、リコの眼鏡を残す。[原画基準へ戻した生成記録](../art-generation/home-pixel-original-style.json)と[頬・ポニーテールの生成記録](../art-generation/home-pixel-face-hair.json)に指示と採否を保存。
- 論理画面384×312、1マス24、16列13行。家具は足元から描き、歩行判定・席の位置は同じマス座標を使う。家具6種類と固定菜園、6席のテーブル。
- 配信用は `public/home-pixel/` のlossless WebP。`npm run home-art:optimize` で透明境界と頭の連結部分の測定→立ち姿96pxへの正規化→頭の中心合わせ→固定セル化。原本から配信画像へはLanczos3で一度縮小し、目や輪郭の欠けを防ぐ。PhaserではNEAREST補間にして、画面拡大で粒がぼやけないようにする。家具・床は既存のnearestを維持する。生成物の一致は `npm run home-art:check`。靴底・感情マーク・湯気・作業の粒子・空椅子は人物の表示寸法へ追従し、タップ範囲の上端も人物の高さに合わせる。
- 歩行は1周期24単位の実移動距離に合わせ、正面・横向き8コマ、奥へ向かう移動は後ろ向き6コマを送る。停止・挨拶中は歩行距離も止まる。足やマントの外接矩形で左右の中心を決めず、原画上部38%の最大連結部分（頭）で位置合わせする。持ち上げた金槌・羽根ペンは頭の測定に含めない。位置ずれとは別に、歩行中は一歩12単位ごとに全身を変形せず、足を通す位相だけ表示0.5単位上へ動かす。接地位相で戻す。正面と後ろ向きで同じ距離の周期を使い、静止・挨拶・動きを減らす設定では止める。測定結果は配信用の anchors.json に保存する。
- シートの段境界は透明な行で検出し、隣のコマの髪などを混入させない。頭は原本だけでなく、縮小後の透明境界・連結部分も測り直して位置を合わせる。原画の粒感を保つことと、顔を低解像度化して欠けさせることは区別する。
- バッファは表示寸法×DPR（上限3）。「拡大する」で2倍、「部屋全体」で元へ戻す。拡大中はスワイプ・ドラッグ・矢印キーで移動し、Homeキーで中央へ戻す。部屋の外へ出ないようカメラ位置を制限する。`HomeRoomView` がドラッグとタップを分け、現在のCanvas矩形とカメラからタップ位置を変換する。倍率・カメラ位置は端末保存へ書き込まない。

## 部屋と生活

`lib/home-actor.ts` は部屋やセーブから独立した人物・動作の定義。今後、冒険・待機・会話の上半分へ使うときは、この全身コマとフレーム規約を再利用できる。今回、それらの画面の表示は置き換えていない。

`lib/home-room-layout.ts`：家具の占有範囲、6席・作業位置、4方向の経路探索。家具の重なり、入口の閉塞、使う位置に到達できない配置を拒否する。`home-room-schema.ts` で保存データにも同じ検査を適用する。

お茶は椅子と人物を一緒に描いた全身コマを使い、着席中の空椅子は非表示にする。膝を直角に曲げ、すねを下ろし、カップは取っ手を片手で持ち、空いた手は膝に置く。座る瞬間に床座りコマへ切り替えない。

テーブルは6人用の大きさを維持し、天板には注ぎ口のあるティーポットだけを置く。人物が持つカップと重複するカップ・皿は置かない。原本は `table-v2.png`、指示は [背面・テーブルの生成記録](../art-generation/home-pixel-rear-table.json)。

テーブル奥の席は、通路上の到着位置から座面へ32単位寄せて描く。椅子・着席した人物・タップ判定で同じ補正を使い、移動経路は家具の占有範囲の外に保つ。

人物の小表示に合わせ、テーブル・事務机・作業台の絵を以前の84%にする。テーブルの6席も同じ床の基準点へ84%で寄せる。`lib/home-room-presentation.ts` が空椅子・着席人物・タップに共通の位置を返す。既存の家具の占有マス、保存済み座標、移動経路は維持し、家具を動かすと絵と椅子も同じ移動量で動く。

`lib/home-room-life.ts`：席を予約して歩き、着いたらお茶・手入れ・書類・水やり。目的地で30秒前後過ごす。お茶の仲間同士の小さな反応、タップへの手振りやハート、湯気・水滴・作業の火花。作業中の担当者は作業台に固定。減らす設定とOSのprefers-reduced-motionはコマ・移動・粒子を止める。一時停止と非表示タブでも時計を進めない。

本編では在室判定・菜園担当・作物の進捗を既存データから受け取る。生活時計から報酬や作物を増やさない。机と作業台は手前の中央マスから奥を向いて使う。作業コマは反転せず、金槌・羽根ペンはリコが左手、ほか4人は右手のまま2コマを切り替える。挨拶中も机仕事の向きを保ち、ハートだけで反応する。過去の横側からしか机に接近できない配置もセーブ検査で読み込めるように保つが、新しい家具配置の確定には手前の通路が必要。

リンデは日当たりのよい花の門・苗棚と薬草、ブレッカは木陰の乾燥小屋・苔むした柵と苔床。ブレッカの栽培所は塔から離れている既存設定に従い、塔は追加しない。両方とも床はタイル、小物は個別画像で、背景小物は北側の非通行帯へ置く。♪・♥・…は透明な感情マーク画像で、文字の背景枠は使わない。

配置だけは `guildArrange` で既存セーブの任意項目 `guild.home` に保存。旧セーブには初期配置を表示する。家具編集は下書き→確定で保存、取り消しで復元。テーブル・作業台・事務机は最低1つ残す。配置用の家具は無償、購入経済は追加していない。

`/guild-lab` はテスト機能ONでのみ公開。常に5人を表示して見た目・動きを試せるが、配置はページ内だけに保持し、端末保存へ書き込まない。レイアウトの編集とアクセシブルな操作はDOM、部屋と生活はPhaser。

## 新しい仲間・家具の制作

1. 同じ画風・大きさで、全身の歩行・待機・生活コマをそろえる。体の一部分を別生成して関節でつながない。
2. 頭の位置と立ち姿の高さをそろえて同じセルへ入れ、頭身・手に持つ物・左右の足が連続するか一覧と実ループで確認。コマが完全に同じでないだけでは歩行の合格にしない。背面は接地した足が左右で入れ替わり、持ち上げた足が床より高いことを確認する。正面は足を通す姿勢に加え、接地姿勢で腿の前後関係も確認する。数値検査だけで絵の自然さが保証されたとは扱わない。
3. 家具は床を含めず、占有マスと使用位置を定義。座る場所と椅子、作業する手と机、水の落ちる場所と土を実表示で確認する。
4. 320/390pxの小表示で人物を区別できるか、拡大でも輪郭が切れないか確認。原本・生成指示・配信生成を一緒に残す。

## 共通の歩行見本
