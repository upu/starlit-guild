# 3-6 裏庭の下見：冒険画面（2026-10-28）

出発前の会話では鍋を料理人へ返し終えているため、その後の冒険では同じ鍋を再び届けない。帰還会話と同じ裏庭を使い、アリアが庭の鉢を運び、ミラが地面の布を整え、レオンが植え込みの通路を確かめる。道中の掛け合いも返却済みの鍋ではなく、鉢と通路に合わせた。場所や道筋の設定は変更していない。

最後は暗転で手伝いを終えた時間を挟み、鉢を持つ庭師、レオンの背負い荷、四人の位置と縮尺を帰還会話の冒頭に合わせる。庭師の鍵はこの時点では表示せず、会話で手袋を脱いでから見える。動きを減らす設定では暗転しない。保存・報酬・敵の構成は変更していない。

両画面幅のシミュレーションで十五工程、鉢の着地位置、表示工程と進行の一致、暗転下の配置切り替え、通常・連続手助け・動きを減らす設定での到着を確認。PC 幅 1243px とスマートフォン幅 390px の見本で冒頭から到着まで再生し、鉢の保持、地面の布、帰還前の庭師と四人をそれぞれ目視した。両幅ともページの警告・エラーなし。見本での確認は本編の達成画面やスマートフォン実機の検証とは区別する。

未完了：本編の達成画面と帰還会話の接続、道中の掛け合いとアニメーションの同時表示、全動作コマの目視、スマートフォン実機の確認。全章の残りの冒険と会話の確認も続ける。
