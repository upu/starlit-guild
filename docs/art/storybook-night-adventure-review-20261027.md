# 第一章1-5 苔灯を携える夜道（2026-10-27）

対象は `moss-night-road`。第一章本文の「アリアは瓶の苔灯を両手で持ち、肩に厚い布、レオンの普段のランタンは袋の留め具」と地図帳の帰路を照合した。地理・会話・一枚絵・進行・戦闘・セーブの変更はない。

## 描画と動作

- 1-4と同じ地面の構図を夜の色へ変更した路面を使用。夜の背景へ追加の青い色を重ねず、人物・小物へ夜の色を適用する。反復画像の端は交互に反転させる。
- アリアの肩の布を、瓶を持つ立位・しゃがみ・立ち上がり・四歩行姿勢・弓の戦闘姿勢に維持。各原画グループは同じ倍率で梱包し、足底176px、歩行の左右の脚、頭・足・弓の余白を保つ。
- 初稿の手が胸寄りで瓶が顔へ重なったため不採用。腕を下げたv2へ交換し、瓶も人物基準幅の0.18倍へ調整。縦横比を元画像から取得し、底が両手へ接するよう計測した。
- 戦闘前に瓶を下ろし、地面の世界座標へ固定。戦闘後はそこへ戻って拾う。ホームワードの描画専用の手荷物処理を共有し、固定足場・回収時のカメラ・手と小物の接点を維持する。置いた瓶の底には小さな接地影を追加した。
- ランタンはレオンの腰の留め具側へ下げる。苔灯は淡い緑、ランタンは暖色の光を控えめに表示。光は小物描画が実際に使った座標から描き、持っている間の床の光は人物の足元、置いた後は瓶底へ投影する。別の道へ切り替えたら光とランタンを消す。
