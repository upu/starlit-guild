# アート・音

[資料案内](../README.md) → アート・音

素材の種類から共通の扱いと個別の制作記録へ進む。制作記録にある採用・確認結果は制作時点の記録であり、現在の表示条件や実装状況は [ゲーム仕様](../gameplay/README.md) とソースを確認する。

| 素材 | 案内 |
| --- | --- |

| [人物画像](character-images.md) | 設定図、立ち絵、表情、動作画像、敵の戦闘画像 |
| [冒険のドット絵調ミニキャラ](adventure-pixel.md) | ホームと共通の5人、歩行・戦闘・採集・運搬のコマと配信基準 |
| [会話のミニキャラ舞台](story-stage.md) | 1-1の待ち合わせ、近景背景、交易品と予備の荷物を積んだ荷車 |

描画のコード構成は [開発・運用](../development/README.md) を参照する。生成プロンプトと制作条件のJSONは `docs/art-generation/` に置き、対応する素材の資料からリンクする。

画像更新を終えるときは、採用画像・配信用生成物・再加工に必要な採用原本とプロンプトをGitに残す。未採用の試作、比較画像、一時スクリプトはGit対象へ追加せず、今回の作業用と確認できるものを整理する。途中版の記録は最終採用版へ集約して資料のリンクを揃える。置き換え済みの旧素材は実行時参照と再生成の依存を確認してから原本・配信用を一緒に削除し、manifest再生成と素材の鮮度検査を行う。
