# 会話中の一枚絵の読み込み（2026-10-29）

一枚絵のある会話では、表示前の行から原寸画像を先読みする。冒頭から一枚絵の会話や直接その行から始める見本では、読み込みとデコードが終わるまで準備表示にし、会話送りを待つ。失敗や8秒のタイムアウトでは待機を解除し、通常の画像表示へ戻す。表示する行と静止画自体は変えていない。
