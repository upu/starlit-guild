# 共通小物15種類の統一（2026-10-31）

残っていた布・荷物・食事・紙・採取道具15種類を絵本調へ揃えた。11種類を built-in image_gen で制作し、用途と状態が一致する4種類は既存素材を使用した。全プロンプト・参照・原本・出力ハッシュは[制作記録](../art-generation/storybook-common-props-20261031.json)。原本は `assets/source/storybook/common-*.png`、配信用画像は `public/storybook-study/common-*.webp`。

## 登録と表示

- 新規制作：平らな包装布、角を上げて引く同じ布、古い包み、一枚の紙、膝の布、半分のパン、パンの包み、薄い石、木べら、羽根ペン、旅行の二つの鞄。
- 既存素材から登録：配達鞄は `honey-bag-v1`、空の器は `sample-bowl-v1`、苔入りの器は `moss-bowl-v1`、敷物は `walnut-cloth-v1`。折った布を広げた布へ、パン一個を半分へ代用する変更はしない。
- `scripts/build-storybook-common-props.mjs` は各小物の旧表示の可視範囲を基準とし、その範囲に縦横比を保って収め、底の接点を合わせる。単純に透明余白を切り詰めて全体を大きくする処理にはしない。登録値は `common-props-v1-metrics.json`。
- `shared-prop-art.ts` の共通表へ14種類を追加。初期・途中・退出の画像を同じ処理へ渡し、持ち主・座標・幅・経路・時刻は保持する。旅行の荷物は `common-props.css` で接地・携行の両方を置換し、アリアが登場する会話では事前に読み込む。
