# 4-3 醸造の町ブレッカ：冒険表示の確認

2026-10-31追記：[通常進行の補足](storybook-reception-brekka-trail-review-20261031.md)で、両幅の冒頭から5回の調査・運搬・戦闘・到着・クリアと帰還会話冒頭を確認した。途中に一時停止を挟む分割記録である。以下に残る「通常速度での冒険全体」の未確認という記述は、この補足範囲について解消した。全歩行コマを一枚ずつ網羅した目視や実機確認とは区別する。

用語集では `brekka-arrival`。出発会話はブレッカの食堂、帰還会話は患者の部屋と隣家で、冒険中は往診の荷の運搬、町外れの魔物、仕入れの控えの確認を繰り返す。地図帳では宿と醸造の仕事場が町内にあり、細かな町内配置は未確定。新しい地理は追加しない。

一時データの `/sprite-lab/storybook/brekka-arrival` を作り、旧冒険表示と試作を比較した。旧表示はベルネの川沿いの背景で、ブレッカの会話場面とはつながらなかった。帰還会話の `brekka-homes-v1` と手描きの人物を使用し、PC幅と390×844のブラウザーで確認した。

- 荷車は野菜や大荷物の交易用から、薬箱・包み・鞄を積んだ往診用へ変更した。旧荷車と同じ420×280のキャンバスに収めた。描画側で荷車を保持し、戦闘中は止め、戦闘後にアリアとレオンが持ち手へ戻ってから再び運ぶ。帳簿の画面では隠し、戻ったときは同じ荷車を使う。描画のみの変更で、実際の戦闘やセーブには触れない。
- 仕入れの帳簿が人物から離れて現れ、調べる位置へ着く前に次の工程へ移る問題に対し、醸造所の机まで歩いて確認する動きを試作に接続した。実進行より先に移動中から始まらないようにし、描画専用の順序待ちで高速進行時も確認を残す。戦闘時は表示を戦闘へ戻し、復帰後に調査を再開する。フィンが行動不能なら動ける仲間が確認し、全員が行動不能でも待ちが解除される。両画幅の自動検査は五つの調査の順序、再開、代役とセーブ不変を確認する。
- 冒険画面に近い390×700の縦長キャンバスでは、同じ醸造所を縦向きに再構成した背景を使う。銅釜・扉・樽の関係を保ち、机とフィンを同じ論理位置へ投影する。縦長見本 `/sprite-lab/storybook/brekka-ledger-portrait` を390×844のブラウザー枠で確認した。幅と向きの変更で人物が作業位置に残ることは `tests/road-brekka-ledger.test.mjs` で検査したが、実機での向き変更は未確認。生成指示と参照は `docs/art-generation/storybook-brekka-ledger-portrait-20261028.json`。
- 町外れの魔物との戦闘を、患者宅前から草の道へ切り替える試作を追加。横長は4-10の帰路でも使う道、縦長はその道を縦向きに描き直した背景を使う。通常の移動中はフェードを挟み、進行が帳簿の確認中に追い越しても静かな場面転換を待つ。戦闘が実際に始まった場合は戦闘の表示を優先するため、帳簿の確認中なら場面が急に切り替わる可能性は残る。終了後は少し戦闘場所を保ち、再び往診側へ戻す。
- 通常速度・高速進行・戦闘復帰を通し、PC幅と縦長で人物・物・セリフの対応を確認する。スマートフォン実機は未確認。

実画面ではPC幅 `work/brekka-flow-pc/` と縦長 `work/brekka-flow-tall/` で調査への切り替えを再生。最後の調査はPC幅 `work/brekka-finish-corrected/` と縦長 `work/brekka-finish-mobile/` で確認した。到着への移行時に人物が画面外へ流れた問題は、カメラと隊列の切り替えを同期し、PC幅・縦長の到着画面で全員が残ることを確認した。縦長の往診側も `brekka-visit-portrait-v1.png` へ切り替え、上下の暗い余白を解消した。この時点は一時データによる見本で、本編との接続は後述。戦闘が発生した瞬間の場面切り替えや五回の調査の繰り返し方は実画面で引き続き確認する。

「戦闘から」「仕入れ調査から」は一時データ用の確認点。見本は一時データを使い、セーブは変更しない。本編への背景適用は後述。

荷車の生成元・参照・指示は `docs/art-generation/storybook-brekka-medical-cart-20261028.json`、梱包は `scripts/build-storybook-brekka-medical-cart.mjs`。`tests/storybook-brekka-medical-cart.test.mjs` は他の荷車との選択分岐、透過キャンバス、両方の持ち手と車輪が収まることを確認する。これは手との接触を実画面で検証したことにはならない。

縦長の往診背景の生成指示と参照は `docs/art-generation/storybook-brekka-visit-portrait-20261028.json`。`tests/road-brekka-sequence.test.mjs`、`tests/road-brekka-journey.test.mjs`、`tests/road-brekka-ledger.test.mjs` は描画の順序・到着・背景切り替えと途中再開を扱う。

町外れの背景は、PC横長と390×844ブラウザー枠の「戦闘から」で確認した（`work/brekka-outskirts-review/`）。停止中の確認地点でも正しい背景を表示する。確認地点から直接始める場合は初期配置で荷車を避け、実画面でレオンが荷車の裏に隠れないことを両画幅で確認した。縦長の再生は `work/brekka-cart-mobile/` の約9秒で戦闘から往診先、帳簿へ戻るまで、横長は `work/brekka-cart-pc/` の約10秒で往診先と帳簿への往復を確認した。連続画像では細かな手の接点と全歩行コマまでは確認できず、五回の調査の繰り返し方、スマートフォン実機も残る。生成指示は `docs/art-generation/storybook-brekka-outskirts-portrait-20261028.json`。`tests/road-brekka-battle-place.test.mjs` と `tests/road-scenery.test.mjs` は場面の選択、停止・省動作と切り替えの順序を検査する。`tests/road-brekka-journey.test.mjs` は両画幅で初期の重なり、戦闘中の停止、戦闘後に二人が持ち手へ戻ってから動き出すこと、セーブ不変を検査する。

実進行が次の帳簿確認へ移っても描画上の運搬が続く場合、持ち手の姿勢を維持する。荷車が進んだときだけ歩行を進め、停止時の足踏みを防ぐ。PC幅の `work/brekka-hands-after/` と縦長の `work/brekka-hands-mobile/` で戦闘後から運搬への遷移を連続確認した。拡大するとレオンの手は引き手付近にあり、アリアの手と車体の接触は解像度上まだ判定しきれない。往診先は背景の移動が小さいため、運搬中にその場で足踏みして見える可能性も残る。全歩行コマの接点、背景の移動と五回の調査は引き続き確認する。`tests/road-journey-cart.test.mjs` と `tests/road-poses.test.mjs` は次の作業に進んだときの姿勢と、荷車の停止・移動に応じた歩行を検査する。

往診の庭では、荷車が画面の中を先に進み、端へ近づいたらカメラが追うようにした。場面を移る暗転中に基準を戻し、移動距離と石畳の関係が分かるようにする。戦闘中は敵・仲間・荷車が画面に収まる範囲で画角を調整する。PC幅 `work/brekka-camera-pc/` と390×844のブラウザー枠 `work/brekka-camera-battle-mobile/` を連続確認し、庭の横断と二体の敵を確認した。全五往復と全戦闘の画面確認ではなく、敵と仲間が画幅に収まらないほど離れる場合は全員を必ず収められない。`tests/road-brekka-cart-camera.test.mjs` が横断・追従・戦闘時の範囲を検査する。

高速進行のPC通し再生（`work/brekka-full-review/`）で、到着後にフィンとミラが左端へ離れる問題を確認。最後は荷車の周囲に四人を配置し直し、暗転中に切り替えてから到着とする。PC幅 `work/brekka-arrival-fade-pc/` と390×844のブラウザー枠 `work/brekka-arrival-fade-mobile/` で最後の帳簿から到着まで再生した。`tests/road-brekka-arrival-transition.test.mjs` は停止・省動作・描画遅延でも切り替え前に暗転が表示されること、`tests/road-brekka-journey.test.mjs` は到着後の隊列維持と荷車の表示を検査する。この時点では本編の帰還画面への接続が残っていた。

五回同じ醸造所へ往復していた調査は、最初の四回を往診の庭で控えを見る動きに変更し、最後だけ醸造所へ移る。庭では仲間と荷車を残し、フィンが手元で控えを読む。最後の醸造所では机の向こうに町の作業者を配置し、仕入れを聞いた帰還会話につなげる。縦長画面で作業者が背景の後ろへ隠れたため、醸造所では画面上の足元の位置から人物と机の描画順を決めるよう修正した。

連続手助けによるPC幅 `work/brekka-full-notes-pc/` と390×844ブラウザー枠 `work/brekka-full-notes-mobile/` で最初から到着までを再生した。醸造所の表示と到着への切り替えは `work/brekka-worker-depth-pc/` と `work/brekka-worker-depth-mobile/` でも確認した。荷車に触れる手元の全歩行コマ、通常速度の全工程とスマートフォン実機は未確認。`tests/road-brekka-notes.test.mjs` と `tests/road-brekka-ledger.test.mjs` は控えの手元、仲間の位置、縦長の背景・机と作業者の前後関係を検査する。

見本を本編の冒険表示へ既定接続し、クリア後は保存を変えずに最後の描画だけを保持して、到着を表示してからクリア画面へ移す。画面移動・描画エラー・スキップでは待ちを解除し、クリア済みを開き直した場合は調査を再演しない。本編と同じ画面構成の一時データ `/sprite-lab/storybook/brekka-arrival-phone` を使い、PC幅 `work/brekka-phone-spacing-pc/` と390×844ブラウザー枠 `work/brekka-phone-spacing-mobile/` で最後の調査、荷車への合流、到着、クリア画面を通常進行で確認し、縦長では帰還会話の冒頭まで進めた。醸造所から戻るときにミラが荷車と重なったため同行位置を荷車の後ろへ調整し、不要な行き先標識も消した。`tests/road-brekka-handoff.test.mjs` は両幅の五回の調査・終了待ち・再表示・スキップ・保存不変と、醸造所から戻るミラの荷車との間隔を検査する。通常速度での冒険全体と全歩行コマの接点は引き続き必要。

## 2026-10-29 往診荷車の車輪

往診の荷を積んだ車体から車輪を分け、共通の車輪素材を移動距離に応じて回す。奥の車輪は元の絵の遠近に合わせて手前より高く配置し、停止・戦闘・動きを減らす設定では余分に回さない。元の420×280キャンバスと持ち手の位置を維持し、セーブや移動速度は変えない。原画・指示・梱包は [制作記録](../art-generation/storybook-brekka-medical-cart-wheel-20261029.json)。

本編構成の一時データをPC幅と390×844 CSS pxで開き、荷車と人物の配置を部分確認した。車輪が小さいため、全歩行コマの手元と実サイズの回転の見やすさ、スマートフォン実機は未確認。車体と車輪の拡大合成でも奥行きと接地位置を確認した。車輪の登録・停止・画幅変更、荷車の戦闘後の復帰に関する関連検査と型検査・対象lintを実施した。
