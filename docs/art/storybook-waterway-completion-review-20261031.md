# 1-9達成後・閉鎖から塔の表へ（2026-10-31）

## 本文と動作

用語集1-9 `tower-moss-removal` / `tower-moss-removal-return`、第一章台本の冒頭6表示、地図帳の塔の裏手の排水路を照合した。位置関係や行路の設定は追加していない。本文・表情指定・セーブ・進行・戦闘計算・既存の一枚絵は変更しない。

冒頭は苔を取り終えた夕暮れの同じ石組み。最後の籠は作業者の手元に追従して退出する。管理人は灯りで奥を確認し、灯りを乾いた足場へ置く。前の場面から脇に残した同じ石蓋をかがんで把持し、持ち上げ、逆向きの4歩行で開口部へ運び、かがんで閉じてから手を離す。二人と管理人は接触しない間隔で手前へ戻り、左へ退出してから塔の表へ切り替える。

表では、アリアが木べらを下ろして手を離し、二人が低い石へ近づいて腰を下ろす。道具の接点を保ち、しゃがみ・着席をセルいっぱいに拡大しない。管理人は同時に階段を通って開いた入口へ入り、到着後に扉を閉じる。6表示目では扉が開く→管理人が入口から現れる→階段を下りる→見上げる→上を指す。従来の下向きに指すポーズを流用せず、専用の2姿勢を追加した。7表示目から45表示目までは従来の `/stories/tower-light-restored.webp` を静止したまま共通の会話表示で使う。

`waterway-hatch-closing.ts` が裏手の接点と退出、`waterway-completion.ts` が道具の置き下ろしと着座、`waterway-front-door.ts` が表の出入りを担当する。動作途中の会話送りは完了を待つ。`StageMoment.scenery` は同じカメラ内の扉差分を時刻に合わせる指定で、通常場面の背景選択は変えない。`StageExtra.insideCamera` は引いたカメラ内の入口座標を画面外の退場座標へ拡張しないための指定。
