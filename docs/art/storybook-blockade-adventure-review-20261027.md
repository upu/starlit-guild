# 2-7 お菓子の通せんぼ：作業場と人形

用語集の2-7 `sweet-blockade`、第二章プロット、出発・達成後の会話、地図の `old-workshop` を照合した。蜜は作業台、薬箱はミラの側、レオンは大きな人形を引きつけ、アリアは弓を構える配置を使う。台詞・一枚絵・地理・戦闘計算・保存内容を変えず、既存の作業場背景と人形・家具・荷物を再利用する。

## 共通の空間と動作

`road-blockade-layout.ts` は1536×1024の `workshop-yard-v1.png` に人物・台・蜜・他人の菓子・薬の袋・薬箱を置き、`fixedRoadLayout` へ投影する。台上の物は、台の天板に合わせた接点と台より手前の描画順を使う。物は五つのまま位置を保持し、戦闘途中に別の荷物へ切り替えない。

`road-blockade.ts` が敵の接近、味方、効果を同じ投影へ合わせる。アリアとミラは射撃と治療の場所を保ち、レオンが前へ出る。通常の三人編成を使い、工程間の進行やダメージには介入しない。固定舞台の選択は `road-fixed-presentation.ts` にまとめた。これまでの水路・荷造り・道標・防衛の呼び出し順は維持する。

`road-blockade-path.ts` は人形を台の脇から奥へ退かせ、次の登場は種類ごとに遅らせる。扉の同一点で重なって現れないよう、透過率も個別の進行度へ合わせる。最後は人形を操り手のそばへ引き寄せ、達成後の会話の謝罪より先に全員がいなくならないよう待機させる。保存上の `escape` の長さ・報酬・終了処理は変えない。旧表示の比較は既存の退場のまま。

## 実表示で直したこと

- 仲間を避けたアリアやレオンがスマホの下端へ寄ったため、射撃・治療の位置と前衛の間隔を調整した。全工程で全員の足元に余白があることを検査する。
- 二体目の小人形と操り手がスマホの右端へ近かったため、接近距離の表示上限と待機位置を調整した。移動途中の意図した登場以外は、身体の幅も含めて余白を取る。
- レオンが力尽きた後に薄い立ち姿が残ったため、`road-injury-pose.ts` と `road-hero-pose.ts` で三人の既存の低い休息姿勢を使う。元の頭身と倍率を保ち、作業・運搬・攻撃の描画より優先する。倒れた地点をワールド座標で保持し、カメラが変わっても足元を滑らせない。回復時は通常の描画へ戻る。到着時に位置を戻す間も歩行姿勢を使う。フィンとリコは既存の被弾姿勢を使い、専用の低い休息姿勢は全体の残件。
- 操り糸は `road-puppet-strings.ts` の手と肩の接点、人物の体格と左右反転に合わせる。描線は背景から読める濃さの細い茶色にした。
- 敵から待機する人形へ切り替わった時の線の硬さを揃えるため、正方形のNPC姿勢にも `RoadSpriteFilter` を適用した。大きさと足元は変えない。
