# 音楽と効果音

案内：[アート・音](README.md)

現行実装のBGM・効果音の挙動と、開発時に必要な実装情報をまとめる。

## 設定UI

BGMと効果音は別々にオン・オフできる。状態は横長のスイッチとON/OFFの文字で表示する。

## BGM

拠点では「星灯りの焚き火」（48秒）、探索では「木漏れ日の小径」（40秒）を繰り返す。どちらもこのゲーム用に作曲し、柔らかいシンセ音で合成したオリジナル曲。外部サービスの登録やAPI料金は不要。

最初のタップ、Enter、スペースなどのユーザー操作後に再生可能になる。拠点画面では穏やかな曲、冒険中は探索曲へ徐々に切り替える。

「セーブ・設定 → 音・テスト」からBGMをオン・オフでき、効果音とは別に音量を調整できる。初期音量は25%。

BGM設定は端末の `starlit-guild-music-v1` に保存し、冒険のセーブ形式とは分離する。

ページが非表示の間、別タブが操作中の間、画面終了時はBGMを停止する。復帰時は、再生できる状態なら再開する。

## 実装

楽譜と音源生成は `scripts/compose-bgm.mjs`、再生は `lib/music.ts`。

`npm run music:compose` で `assets/source/music/` に元 PCM WAV を合成し、48 kHz・モノラル・96 kbps の AAC (`public/music/*.m4a`) を生成する。既存の元 WAV を再圧縮するだけなら `npm run music:optimize` を使う。入力・出力のハッシュと容量は `assets/bgm.manifest.json` に記録し、`npm run music:check` と CI で整合性を確認する。dev / build の開始時にも不足・変更のあった配信用音源だけを生成する。このとき FFmpeg が必要。変更がなければ FFmpeg は不要。

端末では復号した2曲までを再利用する。48 kHz では40秒と48秒が AAC フレームの整数倍になり、エンコード時の末尾パディングを避けられる。新しい曲の読み込み中に画面を離れた場合は、読み込み完了後に遅れて再生しない。

自動検証では、元音源の音量上限とループ境界、圧縮音源の存在、消音、再開、読込失敗後の再試行を確認する。圧縮音源の復号後の長さと境界も FFmpeg で確認する。実機での聴感と長時間再生は別途確認する。

## 効果音

通常攻撃・特技に、斬撃、矢の軌跡、回復の光などの演出と対応する効果音を付ける。連携はペアのカットインに合わせて音を鳴らす。

武器や技ごとに音を変え、連打時は過度に重ならないようにする。設定で効果音をオフにした場合は、以降の再生だけでなく、再生中の効果音にも反映する。

端末の「動きを減らす」設定では強い動きを省く。キャラクターボイスは現時点では追加していない。

画像・演出側の制作記録は [演出素材](presentation-assets.md) を参照する。
