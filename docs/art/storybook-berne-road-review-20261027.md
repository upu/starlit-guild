# 3-1 ベルネへの街道：冒険表示の確認

「隣の席の聞き上手」の往診荷物を、四人が手で運ぶ街道として描く。道は斜め上からの連続背景、ベルネの門は道の終点に一度だけ現れる独立素材とした。フィンの持ち歩きは立ち姿と同じ身体倍率・足底で四歩を登録し、かがみは低くする。ミラは薬箱、フィンとレオンは包みを持つ。戦闘前にそれぞれ足元へ置き、終わると元の位置へ戻って回収する。回収中はほかの荷物の持ち主も待つ。

道の背景と足元の関係を合わせ、移動の回避経路を道路内へ制限した。隠れた作業点は歩行を妨げない。荷物へ戻る間は接点の位置を保ち、戦闘後の回収が止まらないようにした。倒れた人物の足元に置いた荷物も表示を維持する。到着時、荷物を持たないアリアだけ完了後の初期位置へ歩き戻る不具合を発見し、到着直前の位置を引き継ぐよう修正した。演出は描画側で扱い、セーブ・戦闘計算・台詞は変更しない。

本編の既定表示に登録し、見本専用の背景上書きを外した状態で `localhost:5174/sprite-lab/storybook/berne-road` を再生した。PC幅1243×1244、ブラウザーのスマホ幅390×844で、それぞれ冒頭から到着まで通し、歩行・戦闘・荷物回収・門への接近・到着後を確認した。撮影は `work/berne-final-pc.json` の1500枚と `work/berne-final-mobile.json` の2450枚、各55秒ずつの2区間で一時停止を挟む。先行記録から24場面を抜粋して見直し、到着位置は修正後に両幅で再確認した。確認タブのコンソールエラーは0件。スマホ実機ではない。

`tests/road-berne-journey.test.mjs` は二幅で実際の進行をたどり、五回の戦闘後に三人が荷物を回収すること、足元が道の範囲内にあること、フィンの四歩と画像の余白、到着後のアリアの位置を検査する。関連する荷物・ピクニック・隊列の30検査、および既定表示・負傷姿勢を含む16検査が成功した。既定登録で冒険37ステージ中20ステージに手描き表示を接続したが、全章の通し確認、残りの冒険、演出やサイズの最終調整は未完了。
