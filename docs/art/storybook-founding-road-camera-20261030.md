# 4-10 帰路の会話・画面端の確認

「持っていく記録」の街道で、スマートフォン幅の拡大表示により、石を調べるリコと荷物が右端にはみ出していた。街道の画面だけ拡大位置を左へずらし、リコとアリア、荷車を含む五人が収まるようにした。塔での会話の倍率は変えていない。

見本帳の1243×1244 CSS pxで立ち姿と街道の配置、390×844 CSS pxで塔の冒頭、街道への切替、二人が石を見る場面、最後の台詞を確認した。スマートフォン実機と全会話の連続再生は未確認。関連する13検査とCSSの書式検査は成功。

## 出発会話と冒険の積み荷

出発会話には籠と手紙が一つずつしか表示されず、直後の冒険画面ではそれぞれ五つに増えていた。会話中も冒険開始時と同じ籠・手紙の素材、個数、荷車に対する大きさと配置を使い、移動する荷車に追従させた。街道への切り替えで必要な荷車・籠・手紙の画像は先に読み込む。

見本帳の1243×1244と390×844 CSS pxで出発会話の積み荷を確認し、本編構成の一時データでPC幅と390×844 CSS pxの冒険開始付近を見比べた。積み荷の個数・位置と受け渡しを含む42検査、型検査、対象lintと整形検査が成功。冒険への切り替えを一続きに再生した確認、全荷物の受け渡し、スマートフォン実機は未確認。

## 寄り道から出発

最後の台詞を読んでいる間は、アリアとリコが石のそばに残る。最後のタップ後に二人が立って仲間へ戻り、その後フィンと荷車を含む五人が再び動き出す。途中で会話が閉じないこと、二人の移動経路の間隔、荷物の所有先と再出発の順序を検査した。

見本帳の1243×1244と390×844 CSS pxで、最後の台詞からタップ後の合流・出発を部分再生した。関連47検査、型検査、対象lintが成功。実際の冒険への切り替えまで通した画面確認と、全フレーム、スマートフォン実機は未確認。

## 冒険への切り替えの通し確認

本編の画面枠と出発アクションを使い、保存しない一時データで最後の台詞から冒険開始まで試す見本を追加した。冒険側では最初の手紙の受け渡しに移り、人物の並びも変わるため、合流後に短く暗転して場面を切り替える。動きを減らす設定では暗転を待たない。出発処理が拒否された場合は会話へ戻り、再試行できる。

PC幅1243×1244と390×844 CSS pxで最後の会話、合流、暗転、冒険開始を通して確認した。関連40検査、型検査、対象lintと整形検査が成功。ただしPC幅では会話舞台に比べて冒険画面の人物が小さく、背景に対する比率の差が残る。冒険中の全受け渡し、各フレームとスマートフォン実機も未確認。

## 街道の縮尺を揃える

街道に切り替わった後は、人物だけでなく荷車と積み荷を含む舞台を同じ倍率で調整し、冒険画面の同じ背景に対する大きさへ近づけた。石の位置を保つため舞台内の座標を移し、アリアとリコの手元と荷車の持ち手を維持する。スマートフォン幅では読みやすさに合わせて倍率と名前の表示を調整した。

PC幅1243×1244と390×844 CSS pxの一時データで、最後の会話から合流、暗転、冒険開始を部分確認し、人物と荷車の大きさを見比べた。見本帳では石を調べる場面と出発の途中も確認した。関連54検査、型検査、対象lintを実行。冒険開始直後には、会話で荷車を引いていたフィンが冒険側では一度荷車から離れた位置に現れるため、つながりの修正がまだ必要。全フレームとスマートフォン実機は未確認。

## 荷車の持ち手から冒険を始める

新規出発直後はフィンを会話と同じ持ち手に置き、停止した引き姿勢を短く保ってから待機位置へ移す。アリアはその間、荷車の引き棒を避ける。途中からの再表示、戦闘、休憩、行動不能や動きを減らす設定では、この開始姿勢を強制しない。表示上の配置だけを変え、セーブや進行の計算は変えていない。

高速進行では後続の受け渡しが遅くなる場合があったため、ゲーム完了後に残った荷車移動だけを少し速くした。PC幅1243×1244と390×844 CSS pxの一時データで、最後の会話から冒険開始直後の持ち手を確認し、390px幅では帰着手前からクリア画面まで部分再生した。関連する159検査、型検査を実行。高速進行中の全フレーム、スマートフォン実機は未確認。
