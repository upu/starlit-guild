# 2-1 昼食を持つ坂道：運搬と接敵前後の回収

2-1 `hilltop-picnic` は本編へ既定適用済み。全体の既定対応は15/37。見本は `/sprite-lab/storybook/picnic`。用語集、第二章の出発・帰着本文、地図の `picnic-hill` を照合した。昼食の丘と塔の丘の厳密な位置関係は未設定なので、新しい方角や塔の配置は追加しない。既存の昼の丘の周回背景を使い、塔の目印は表示しない。以下は試作時点からの経緯で、最終の根拠は末尾を参照。

出発後は一つをアリアの袋へ入れた設定に合わせ、アリアは既存の汎用茶色鞄、レオンは既存の無地の紙包みを持つ。素材は `visiting-satchel-v1.webp` と `lunch-cake-parcel-v1.webp`。描かれている物としては無地の鞄・紙包みで、薬瓶や菓子そのものは表示しない。新しい原画の生成はしていない。

`lib/road-picnic.ts` にレオンの運搬・歩行・屈みの姿勢と掌を登録し、2-3と同じ素材・倍率を使う。アリアは既存の両手持ち・しゃがみと肩の布がある戦闘姿勢を使い、荷物を置いた瞬間に肩の布だけ消えないようにした。手荷物の描画は場面変更時にも現在の種類のテクスチャを選び直す。到着時は描画の識別子を保ち、最後の拾い直しを初期化しない。

冒頭から敵がいる場合、生の初期位置で荷物の地面位置を決めると、二人の表示間隔を整えた後の掌とずれる問題を検出した。`road-handheld.ts` は最初の描画済みの足元を得てから降ろす。両幅で固定した地面位置としゃがんだ掌、最後の拾い直し、保存不変を検査した。

PC1243×1244は514枚（最初1.299秒、最後71.114秒）、ブラウザー390×844は732枚（最初1.224秒、最後85.764秒）を保存。`work/picnic-final-{pc,mobile}.json` と両方の `-filmstrip.png` を目視した。二回の記録操作の間には空きがあり、毎フレーム連続の動画ではない。スマホ実機の確認は未実施。人物の頭・足先、戦闘と待機、最終的に二つの荷物を手に戻す表示を確認した。以前の `picnic-{pc,mobile}` は冒頭からの記録ではないため、全行程の根拠にしない。

**試作時の未解決事項：連続する敵の合間に荷物を拾わない。** 2-1は全地点が戦闘なので、敵が途切れないまま次へ進む。試作時の共通手荷物処理は戦闘中に地面の荷物を維持するため、最初に置いた昼食が後方に残り、最後にまとめて拾った。接点・所有者・最終回収の検査が通っても、この移動の不自然さは残ったため、この時点では本編適用を見送った。

試作時の `tests/road-picnic.test.mjs` は素材・未適用・OFF/個別指定、両幅の地面位置・掌・最後の回収・保存不変を検査する範囲に留まっていた。「戦闘ごとの回収が完了した」ことは証明しなかったため、下記の回収の繰り返しと到着位置の検査へ拡張した。

## 連続する接敵の間の回収と本編適用

`picnicEncounterNear` は描画済みの足元と生きた敵の距離を見る。敵が生成されていても170世界座標より遠ければ、先ほどの荷物を拾って運び、接敵前に再び置く。進行・報酬・セーブの判定は変更しない。実進行より描画が短く遅れる間、荷物で手がふさがった人物の矢・斬撃・魔法は出さず、回復・被弾の表示を維持する。

二人の回収が完了するまで、先に拾った側はその場で待つ。回収中に新たな敵が現れても途中で回収を中断しない。回収カメラを二袋の中間に置くと、スマホ幅では後方の袋の位置が表示範囲から外れて足元が届かなくなったため、後方の荷物を基準にする。最終回収後は人物とカメラの現在位置を保持する。以前の表示は到着後に道の入口へ戻っていたため、この復帰も除いた。

最終のPC1243×1244は508枚（最初1.275秒、最後70.790秒）、ブラウザー390×844は853枚（最初1.253秒、最後75.193秒）。`work/picnic-cycle-{pc,mobile}.json`、両幅の `-filmstrip.png`、最終ページ画像を目視し、複数回のしゃがみ・回収・手荷物歩行・再設置と、最後に両方を持ったまま立つ表示を確認した。二回の取得操作間には短い空きがあり、毎フレームの連続動画の検査ではない。スマホ実機の確認は未実施。

関連27検査が成功。両幅で15回の回収、地面位置の固定と掌、最終接敵まで荷物を運ぶこと、実移動距離による4コマ歩行、到着後10秒以上の位置維持、保存不変、手がふさがった間の攻撃効果の除外を検査。帰路・苔灯・2-3の回帰を含む。型検査、対象lint、ソースビルドも成功。本編の既定背景へ登録し、見本専用の上書きを外した。OFFと個別背景指定は維持する。

全体の残る22冒険、全会話の通し確認、敵・効果・車輪、GitHub同期と公開は引き続き未完。この場面の適用を全体ゴールの完了とは扱わない。
