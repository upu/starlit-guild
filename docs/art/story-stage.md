# 会話のミニキャラ舞台

1-1〜1-3の会話演出。1-1達成話は既存の一枚絵を保ち、会話の表示と操作を共用する。演出は [1-1の定義と動作](../../lib/story-stage.ts)・[1-2の定義](../../lib/story-stage-evening.ts)・[1-3の定義](../../lib/story-stage-town.ts)、画面は [StoryStage](../../app/story-stage.tsx) を参照する。

## 採用素材

`assets/source/story-stage/` のPNG原本を [配信生成](../../scripts/build-story-stage-art.mjs) で `public/story-stage/` のWebPへ変換する。`npm run story-stage-art:optimize` / `story-stage-art:check` で生成・鮮度確認する。原本は無加工で保存し、配信時だけ縮小する。透明な荷車と手荷物はアルファを維持する。背景・荷車・人物を共通の3:2座標に配置し、画面幅によってそれぞれ別の倍率にならないようにする。

- `meeting-path-v1.png`: 二つの村の道が合わさる場所。広域マップの俯瞰から、人物と同じ高さの近景へ変更。新しい地点や方角は追加しない。
- `loaded-cart-v1.png`: 村の交易品の木箱・大袋・籠に、二枚の雨布・替えの紐・薬草用の小袋・予備の包みを加えた荷車。
- `travel-bundle-v1.png`: アリアの布包みと肩掛け袋。
- `town-exit-v1.png`: 1-2出発時の夕方の街の出口。リンデの既存の街道沿いの家並みを近景で描く。
- `meeting-dusk-v1.png`: 1-2達成時の村々への分かれ道。昼の待ち合わせ場所の構図を保った夕景。
- `return-cart-v1.png`: 同じ荷車に、帰りの買い物を包んだ二つの包み・膨らんだ袋・木箱と予備の雨布を積む。出発時の農産物の籠は載せない。
- `aria-poses-v1.png` / `leon-poses-v1.png`: 待機・挨拶・驚き・考える・差し出す／説明・得意げ／笑顔の6ポーズ。歩行原本を参照し、頭身・服装・頭の大きさを維持する。原本は3列×2行。[ポーズの生成条件](../art-generation/story-stage-poses-20261009.json)を参照。
- `town-shop-clear-v1.png`: 1-3の取引先。旧 `town-shop-v1.png` / `town-shop-return-v1.png` は制作原本として残し、現在の配信背景は奥の台を取り除いた共通原本から生成する。屋根越しの遠い丘に既存の塔が見える。
- `packing-table-v1.png`: 二人のすぐ前に置く透明な作業台。配達前は下に残りの小箱を置き、達成後は空にする。
- `merchant-poses-v1.png`: 既存の1-1受け渡しの一枚絵を参照した、取引先の人の待機・説明・下の荷を指す・見送りの4ポーズ。原本は2列×2行、配信は128pxセルの4列×1行。二人と同じ96pxの立ち姿・足裏120pxへ揃える。名前や新しい人物設定は追加しない。[取引先の制作記録](../art-generation/story-stage-merchant-20261010.json)に組み込み `image_gen` の参照画像と全文プロンプトを保存する。
- `delivery-box-v1.png`: 左右の持ち手と荷札のある配達用の小箱。台・アリアの手元・二人の間を台詞ごとに切り替える。
- `carry-poses-v1.png`: 箱の持ち手へ腕を伸ばす二人の歩行2コマずつ。透明な2列×2行原本。箱は別素材として持ち手の間へ置く。[1-3の制作記録](../art-generation/story-stage-town-20261010.json)に背景・箱・ポーズの全文プロンプトを保存する。

生成は組み込み `image_gen`。全文プロンプトは [制作記録](../art-generation/story-stage-20261009.json)、原本と配信のSHA-256は `public/story-stage/manifest.json`。

夕景と帰りの荷車は [1-2の制作記録](../art-generation/story-stage-evening-20261009.json) に元画像・参照画像・全文プロンプトを保存する。二人の村とリンデを結ぶ既存の行路を使用し、地理は追加変更しない。

荷車の引き手（20–21コマ）は冒険の共通素材、歩行はホーム素材を使う。共通の会話アトラスは4列×3行で、0〜5が会話姿勢、6〜7が荷の点検、8〜9が箱運び。点検の原本は冒険の22〜23コマを使うが、[作業姿勢の変換](../../scripts/story-stage-pose-frames.mjs)で歩行と頭の幅を揃え、足裏を120pxへ接地する。アリアの座った姿の頭が立ち姿より約26％大きく見える問題を、この変換で修正した。座った全身を96pxへ引き伸ばさない。

立ち姿と歩行は128pxセル・頭頂から足裏まで96px・足裏120pxを共用する。会話ポーズは手を頭の位置合わせに含めないよう上部25%で頭を検出し、頭の幅と中心も歩行に合わせる。箱運びも頭の幅で縮尺を揃え、二人で持つときは箱を二人の中点へ追従させ、右側のレオンは左向きを維持して後ろ歩きする。

冒頭はレオンだけが点検する。アリアは荷物を後ろ手に持って登場し、到着するまで地面の荷物を表示しない。早送りで挨拶へ進んでも、到着前は持ったまま。到着後に地面へ置き、「待った？」の間は手を上げたポーズを保つ。出発時は再び荷を持ち、レオンが荷車を引いて移動する。

布の受け渡し専用ポーズは未制作。本文で受け渡しを伝え、画面は接近と荷の点検を表示する。

1-2では二人が揃った状態から始め、出発前に荷を結び直す。達成後は布の受け渡し、互いの荷の直し合い、別れの挨拶に合わせて姿勢と表情を切り替える。最後のタップでアリアは荷を持って左へ、レオンは荷車を引いて右へ進み、それぞれの村へ別れる。

## 会話と出発の操作

1-1〜1-3の六場面は、最新の一言を画面下部のコンパクトな枠に表示し、その直上に舞台または一枚絵を寄せる。下半分を固定で予約しない。「会話履歴」は同じ枠の下部に置き、表示済みの全文を読み返せる。「会話に戻る」で同じ台詞へ戻る。履歴表示中は画面外タップ・キーボードでも話を進めない。1-1達成話の一枚絵は従来の行で表示し、拡大表示を維持する。最後のタップでは移動演出を挟まず読了する。

1-3は、アリアが箱を抱えて残りの荷に驚き、台へ戻して荷札を確認し、二人で持ち直す。達成後は荷のない店先で礼を言い、通りや丘の塔を見て、次の訪問を約束する。新しい場所・行路・方角は追加しない。

取引先の人は台の向こうに立ち、自分の台詞で説明する姿勢と名前の強調を切り替え、最後は店先から見送る。箱は配信時に透明余白だけを切り詰め、台上・手持ち・共同運搬を通じて舞台幅の13%を保つ。二人で持つときは間隔を20%に狭め、両側の手を合わせる。箱の移動は `lib/story-stage-props.ts`、表示中の位置の保持は `app/story-stage-box-motion.ts` が担当する。台へ戻す際は650msで手元から台上へ移し、その間は腕を伸ばした姿勢を保つ。途中で次の台詞へ進めても現在位置からつなぐ。

最後の台詞を表示した時点では二人と荷車をその場に留める。次のタップで出発の動作を始め、動作が終わってから読了・冒険開始を確定する。動作中の連打は受け付けず、非表示時は止める。「動きを減らす」設定では最後のタップ時に移動を省略して完了する。思い出での再読も同じ順序で閉じる。
