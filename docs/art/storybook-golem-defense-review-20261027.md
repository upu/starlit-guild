# 2-6 もう一人の山賊：荷物の防衛

用語集の2-6 `begging-golem`、第二章プロットと出発・帰着会話、地図の「古い作業場の手前」を照合した。出発時にアリアが包みを後ろへ寄せ、ミラが薬箱を置いた状態を冒険へ引き継ぐ。蜜を奪う動きは達成後の会話に残し、冒険中に袋を消さない。一枚絵、台詞、進行や戦闘計算、セーブは変更しない。

## 表示

`lib/road-golem-defense.ts` は既存の `mountain-road-v1.png` を `fixedRoadLayout` へ投影し、人物と背景の縮尺を揃える。小型だけ・大型だけ・大小同時の三戦を同じ道で防衛する。ゴーレムは奥、小さな人形は手前に分ける。敵の横移動は保存された相対距離を使い、矢や打撃は再配置後の足元へ投影する。薬の袋、蜜の袋、ミラの薬箱は後方の固定位置に置く。原画の追加生成はなく、既存の閉じた袋・薬箱と人形の採用アトラスを再利用する。

`road-puppet-attack.ts` はゴーレムの実際の次回攻撃時刻の直前に構え、同じ敵・同じ戦闘の実ダメージイベントがあった時だけ打撃姿勢にする。予定時刻が過ぎただけでは打撃を捏造しない。セルと足元の倍率は変えず、動きを減らす設定では静止姿勢を使う。共有表示のため2-7の大型にも同じ規則を適用する。

## 実表示で見つけた修正

- 最初のスマホ確認で蜜の袋が下端から切れたため、二袋の底を奥へ寄せた。
- 小人形を追うレオンも、その手前の列が低すぎて下端へ寄った。大小の敵の列を奥へ移し、三戦すべての足元を検査するよう追加した。
- 五人の待機表示を渡した場合にリコが下端に近すぎたため、追加二人を奥へ配置。共通投影で同じ問題があった2-5の待機時のリコも左奥へ移した。実際の開始処理は進行後の再挑戦でもアリア・レオン・ミラの三人に編成し直す。これは開始処理の検査で確認しており、五人の戦闘を確認済みとは扱わない。使われない五人の試走ページは外した。
- 「最初から」の読み込み表示が長く残る事象は2-5から継続。エラーなしで後から再生へ進むため、タイムアウトを失敗・終了とは扱わない。見本に「冒頭で停止」を追加し、読み込み後に開始状態から再生できるようにした。原因の特定や解消とは区別する。
