# 第一章の顔アイコンと受け渡しスチル

組み込みの画像生成ツールを使用し、`public/stories/first-map.png` と `public/sprites.png` を人物・画風の参照にした。採用素材の表示条件と再生成に必要な情報をまとめる。

- `public/portraits/aria.png`：アリアの顔アイコン。
- `public/portraits/leon.png`：レオンの顔アイコン。
- `assets/source/stories/village-trade-handover.png`：街の店主へ薬草と村の交易品を渡すスチル。

ゲーム内の各台詞・会話冒頭・下部のチャット欄に `Portrait` を使用する。小表示用の顔は、後述の専用アトラスを使う。アリアとレオンの個別画像は制作参照に使い、マップや編成画面では全身絵を使う。

スチルは `village-trade-return` の最初のページから表示し、画像をタップすると拡大できる。冒頭から取引が始まる会話に合わせた。受け渡し先は既存シナリオの「街の取引先の店」に合わせた。

イベント会話には×ボタンを置かず、画面外タップ・Escも途中終了させない。最終ページの「冒険を始める」または「閉じる」でのみ終了する。ブラウザー自体を閉じることを妨げず、未読の到着話は保存されたまま残る。

最終プロンプト一式と保存先は [生成記録](../art-generation/prologue-dialogue-art-generation.json) に記載。

## 小表示用の顔アイコン

現在はアリア・レオン・ミラ・プティの4人を[リファレンスシートに合わせた表情画像](dialogue-expressions.md)へ置き換え、台詞ごとに表情を指定している。下記は初期アトラスの制作記録。アトラスの他のセルの人物は実装から削除済みで、画像だけが残る。

組み込みの画像生成ツールで `public/portraits/dialogue-atlas.png` を制作。太い輪郭、少ない陰影、大きな目と髪の色面を使い、11人を同じ絵柄で描き分ける。フード、帽子、髪飾り、プティの八重歯などの目印を保つ。人物設定・会話本文・クエスト・セーブ仕様の変更はない。

4列×3行。上段はアリア、レオン、ミラ、フィン。中段はガル、ルナ、ポピー、ノエル。下段はメリル、プティ、チャチャ、空き。`Portrait` のスプライト番号をこのセル順へ対応付け、会話画面とチャット履歴で共用する。

チャットは各セリフの左に64px、幅900px以上では72pxの顔を添える。名前を本文の上に置き、本文は16px。顔を縦に二つ並べた高さに、発言間2px・上下余白各4px・境界線1pxを加え、欄は139px（幅900px以上では155px）とする。顔は文字サイズ設定に追従するrem指定。長文は省略せず折り返し、過去の発言はスクロールで読む。会話画面の顔は72px、狭幅では64pxとする。

同じ11人・同じセル順で、太い輪郭と大きな目・口、まとまった髪の色面を優先する。通常用は288×216px（1人72px角）、高密度画面用は576×432px（1人144px角）。`Portrait` は `image-set` で `dialogue-atlas.png` と `dialogue-atlas@2x.png` を選ぶ。

64px角／人の比較画像を作成し、全11人の目・口、髪・帽子の目印とセル対応を確認した。高密度用は輪郭がぼやけにくいよう2倍の画素数を持たせる。チャット枠・顔の表示寸法・会話内容はサイズ調整時の状態を維持する。

全員のプロンプトと書き出し仕様は [小表示向けの生成記録](../art-generation/dialogue-portraits-small-generation.json) に記載。

### アリアとレオンの年齢感

二人の顔つきは既存の肖像・受け渡しスチルに合わせ、青年らしい比率と簡潔な描画を両立する。レオンは目の縦幅と頬の丸みを抑え、顎、鼻筋、首元を少ない線で描く。アリアは髪色・服の目印と青年らしさを保ちながら、やさしい目元、少し丸い頬と顎、小さな鼻と口でやわらかさを出す。

通常用・高密度用アトラスの先頭2セルがアリアとレオン。残る9人と空きセルの並びは変えない。二人の基礎プロンプトは [年齢感の生成記録](../art-generation/dialogue-portraits-age-generation.json)、アリアの最終条件は [アリアの生成記録](../art-generation/dialogue-portraits-aria-soft-generation.json) に記載。
