# 3-8 夜道の五つの運搬区間（2026-10-31）

同日、前36・後13表示の順次再生と冒険開始・終了を両幅で追加確認した。[前後の会話と接続の記録](storybook-night-dialogue-review-20261031.md)を併用する。以下は五つの運搬区間を確認した時点の範囲を残す。

対象は3-8「間違った荷物を戻す夜」（`keystone-night-road`）。`night-bridge-phone` の保存しないLv40の一時データを使い、連続手助け・敵HPの変更・途中の工程への移動を使わず、冒険開始から橋への到着と完了画面を経て、帰還会話の1表示目まで進めた。PCは1280×900、スマートフォン幅は390×844 CSS px。実機確認ではない。

## 修正と結果

PCの初回記録では、約3:2の冒険領域でミラが会話欄の裏に立っていた。以前の横長向けの配置補正は、領域の幅／高さが1.5を超えた場合だけ効いていた。`lib/road-night-bridge.ts` の補正を1〜1.5の間で段階的に適用し、3:2でもミラが荷車の奥に立つようにした。縦長の配置・人物と背景の縮尺・ゲーム進行・セーブは変えない。

修正後のPCと、同じ配置のままのスマートフォン幅について、通常進行の五つの運搬区間（工程1・4・7・10・13）を連続画像から抜き出して照合した。各区間で荷車が進み、フィンの足が踏み替わり、持ち手付近に両手が残る。戦闘では荷車を残して短剣の姿勢へ移り、敵がいなくなると持ち手へ戻る。姿勢を切り替えた抜粋で、頭部や身長の大きな跳ねは見られなかった。PCのミラは会話欄の上に収まっている。

夜道から橋の手前への暗転、レオンが車輪の横へ回る動き、最後の戦闘後の運搬、橋の画面への暗転と完了画面、次の操作から帰還会話1表示目への切り替えも記録した。道中の過去の台詞は履歴として残るため、画面に「荷車を止めよう」が残っていることだけを現在の動作の指示とは扱わない。
