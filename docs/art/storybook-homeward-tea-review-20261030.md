# 2-9 帰路と三人分のお茶（2026-10-30）

帰路の運び手、荷車と積み荷、ミラの携行姿勢を往路と同じ素材・接点へ揃えた。仕事場では薬箱、空き瓶、控え、急須とカップも手描きの舞台に合わせた素材を使う。

アリアは机へ近づいてから右向きの急須で三つのカップに順番に注ぐ。カップを移るたびに最初の迂回経路を繰り返す問題と、次の台詞でもその経路が残る問題を修正した。ミラは注いでいる間はアリアと重ならない位置で待ち、その後棚へ向かう。動作終了前に次の台詞へ進んだ場合も完了まで待つ。
