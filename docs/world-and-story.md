## 合意した核

- アリアとレオンは近くの別々の村に住む。子どもの頃、村どうしの取引の場で繰り返し顔を合わせ、仲良くなって一緒に遊ぶようになった。
- 青年になった現在は、それぞれの村の仕事で少し遠い街へ取引に行くとき、一緒に道を行く仲。家や村が同じだから常に一緒なのではなく、会う場所と次に会う予定がある。
- 導入は村の仕事としての街への交易。道中で薬草を採るなど、暮らしに必要な仕事と小さな寄り道を重ねる。
- 最初の塔は交易先の街の周辺にある。その力が弱まり、街と近隣の村の行き来がしにくくなっている。
- 街で塔の不調の話を聞き、仕事のついでに「少し見に行こう」と寄り道する。最初から塔の修理や世界の救済が目的ではない。
- 第一部の冒険を進めるのはふたりだけ。他の仲間の加入や、既存キャラが解法を教える場面を置かない。仕事相手や塔の管理人など、地域の人との交流・協力は描く。
- 最初の苔は珍しくて便利な発見。持ち帰る苔灯が弱まり、アリアが森で見た苔に似ていると気づくことから、塔との関係を疑い始める。
- 塔が力を失う理由は塔ごとに違う。同じ討伐や素材集めだけで解決しない。
- 第一部は一般の冒険者にも対処できそうな規模。竜討伐、伝説の武器、覚醒した力を解法にしない。
- 第一部は近隣の塔の灯りと往来が戻った喜びで完結する。隣の土地の困りごとや次の事件の予告は不要。第二部は内容自体が未定で、その導入は第二部を作るときに考える。
- ふたりだから気づける違和感は、観察する対象と日々の経験の違いから生む。住民の知識と合わせて調べ、村人を無能にして主人公を持ち上げない。
- 塔に害を与える素材にも価値や用途がある。後の話では、撤去したい人、利用したい人、利益のために増やす人の違いを扱える。
- メリルは珍しいものの噂を聞くと食べられるか確かめに行く。この絡みは第一部以後へ置く。
- 幼なじみふたりの親しさと言い切れない好意は現在の制作の核。細部の設定は、これから物語に合わせて見直せる。

## ふたりの暮らしと地理

### 村、街、塔の関係

アリアの村とレオンの村は近隣にある。村どうしの取引の場が幼少期の接点で、現在の街への取引はそこから少し行動範囲が広がった仕事。二つの村の取引先は共通の街で、道の途中で合流して一緒に向かえる。街の周辺の塔が弱まると、両方の村の交易にも影響する。

制作案では、街道の分かれ道近くに合流する目印を置く。行きは待ち合わせ、帰りはここから別々の村へ帰る。目印の形、村名、街名、所要時間は未設定。「明日またここで」が実際の待ち合わせを意味する関係にする。

最初の塔は街の外れの丘にある案。塔の周辺の排水路が湿った場所を作っている。村外れの塔を目指して新たな観光旅行へ出る第1稿の地理は置き換える。

### 青年になったふたり

- 交易では村の品を届け、代金や頼まれた物を持ち帰る。担当する品物・家族の職業・初めて任された年齢はまだ固定しない。
- アリアは道中の薬草や植生を見るのが得意。採取は仕事のついでにできる範囲で行い、預かった荷物を放り出す行動にしない。
- レオンは荷物、道順、足場、帰路の段取りに目が向く。彼にも街で見たい物や寄りたい場所がある。
- 性格を具体化する制作案として、アリアは考え終わる前に感想や思いつきが口・行動に出やすい。レオンはそのフォローに慣れ、元からの慎重さが強まり、準備しすぎることがある。長所と失敗、互いへの甘え、成長の扱いは [人物資料](characters.md) の「ふたりの性格を動かす仕組み」を正とする。
- 子どもの頃の遊び仲間が、今は仕事を互いに頼れる相手になっている。恋愛については、会う理由がいつも仕事なのか、仕事がなくても会いたいのかという余白を使える。
- 宿泊が必要な距離かどうか、旅団として独立する時期、共通の拠点を作る経緯は今後決める。第一部冒頭から同居や共同生活を前提にしない。

### 種族などの制作案

アリアはエルフ、レオンは人間として構成する案を継続する。現行プロフィールでは種族は明記されていない。他の人物の種族まで一括して推定しない。

エルフは成人する頃までは人間に近い速さで育ち、その後ゆっくり年を取る案。具体的な年齢・寿命は未設定。近隣の別の村に住む理由を、種族間の敵対や隔離と即断しない。各村の住民構成も未設定。

子どもの頃に塔へ行く約束をしたという第1稿の案は、導入の必須設定から外す。髪紐を贈った日や初めて遊んだ日の詳細も未設定。

## 星灯りの塔（制作案）

塔は周辺の街道を照らし、魔物が寄りつきにくくなる力を持つ。完全な防壁ではなく、明るい街道でも護衛は必要。弱まると迂回や早めの出発が必要になり、荷物の輸送や日々の往来に負担が出る。

塔は夜の光を取り込み、内部の石に蓄え、少しずつ周囲へ放つ案。曇天一晩で止まるものにはしない。強い魔力が流れる部分は足元の石組みにも続いている。第一部はこの力と周辺環境の関係までを扱い、古代技術の全容を説明しない。

管理人は通常の掃除や点検を行い、専門家への相談もしている。光る苔の存在を見ただけでは、塔の不調の原因と分からない。苔は石組みの奥で広がり、外に見えているのは一部という案。普段は問題を起こさない生物と環境の組み合わせが、通常の点検範囲から外れていた。

一塔の復旧は、その周辺の街道を改善する。全世界の塔が同時に直る仕組みにはしない。後の物語で範囲を広げる際には、仕事相手の紹介や商人の評判を使えるが、第一部の末尾にその予告は置かない。

## 淡光苔（制作上の仮称）

### 通常の姿と、塔のそばの姿

正式な呼び名や分類は未定。第1稿の「灯吸い苔」は性質を先に明かすため、プレイヤー向けの呼称として使わない。発見時は「光る苔」、持ち運ぶ使い方は「苔灯」と呼ぶ程度に留める。

現行の制作案では、森でまれに見かける苔と同じ種類が、塔のそばの条件で変化したものとする。新種の発見とは確定しない。アリアも最初は「似ている」としか言えず、見比べて同じ種類ではないかと考える。

| 項目 | 通常の森 | 最初の塔のそば |
| --- | --- | --- |
| 生える場所 | 湿った場所にまばらに見られる | 排水不良で湿り気が長く続く石組みの周辺 |
| 魔力の取り込み | ごく弱く、周囲へ目立った影響はない | 強い魔力が近くにあり、取り込む働きが活発になる |
| 成長 | 小さな群落で、めったに見かけない | 水分と豊富な魔力が重なって繁殖が進む |
| 見た目 | 普段の明るさでは発光を見分けられない。アリアの記憶では「光らない苔」 | 日陰でも気づく柔らかな光。採った少量を寄せると手元の灯りになる |
| 塔への影響 | 通常は問題にならない | 石組みの奥まで増えた群落が力を取り込み、塔を弱める |

「光らない」と「ごく弱く光る」は視認条件の違いとして扱い、種族だけに見える特殊な光にはしない。強い魔力のもとで取り込みが活発になるのは環境への反応という案で、突然別種へ進化したとは決めない。

### 持ち帰って分かる性質

- 吸った魔力をしばらく保持するため、採ってもすぐには光が消えない。灯りに使ううちに蓄えが減り、帰村する頃には見た目の印象も変わる。
- 光が落ち着くと、葉の並び、色、枝分かれなどが見えやすくなる。ここでアリアが森の苔との似かよりに気づく。特徴の具体的な造形は台本・絵で揃える。
- 暗くなっただけでは「魔力を吸う」証拠にならない。枯れた、乾いた、採ったため変化したという別の説明もあり得るため、再訪して条件を比べる。
- 水分だけ戻しても強い光は戻らない。同じ湿り気で塔に近づけた標本と離した標本を比べると、近くのものに光が戻る。そこで塔から何かを取り込んでいるという仮説が強まる。
- 少量を採っただけでは塔の明るさは大きく変わらない。石組みの奥の群落を調べ、排水と除去を進めた後に塔が回復することで、影響を確かめる。
- 取り込める量と保持する時間には限界がある。遠方から無制限に魔力を奪ったり、無から力を作ったりしない。具体的な数値は未設定。
- 苔灯は手元を照らす道具。塔の魔物除けまで小型化して持ち歩けると決めない。

### 最初の塔での原因と対処

制作案の因果は、嵐の倒木による排水路の閉塞 → 湿潤化 → 塔の強い魔力との組み合わせで繁殖と吸収が活発化 → 塔の力の低下。最初の事故は自然発生であり、後の業者の仕業へ遡及変更しない。

対処は、水の行き先を確かめて排水を戻し、石組みの奥の群落を除き、管理人へ点検を引き継ぐ。苔を剥がすだけでは再発する。通常の森の群落まで全滅させる必要はない。

### 第一部以後の用途と利害（将来の種）

素材そのものが悪いのではなく、増やす場所と量、被害を知った後の行動で利害が分かれる。

| 人物・立場 | 関心と使える場面 |
| --- | --- |
| 地域の人・管理人 | 街道の回復と再発防止を優先する。灯りに使うなら管理方法を相談したい |
| ポピー | 調合・栽培に熱中する。増やしすぎて隣のランタンが暗くなり、自分で後始末と研究をする案 |
| ルナ | ふたりの記録を起点に、取り込みと光の仕組みを観測する案 |
| ミラ | 往診用の灯りなど暮らしへの用途を考える案。未知の苔をすぐ患者へ投与しない |
| メリル | 珍しいものの噂を聞いて食べに来る。比較用の標本まで狙い、周囲を困らせる |
| 利益優先の業者 | 栽培費を浮かせるため、塔の力を無断で使って群落を育てる。被害を承知で利益を取る |

第二部以後の案であり、第一部の任意イベントとしても登場させない。誰がいつ加入するか、研究を始める前からの知り合いかなどは未定。既存の加入動機や関係も新しい物語に合わせて変更できる。

「第二部以後」は第一部に入れないという範囲の指定であり、第二部に採用するという決定ではない。第二部では苔や人工栽培とは別の問題を扱ってもよい。

### 人工栽培問題を採用する場合の時間関係

第一部で苔と塔の関係が判明し、一件が解決する。その発見が噂として他の街へ伝わった後、利用に目をつけた人が栽培を始め、問題が発生する。この順序を守る。

人工栽培問題を第一部より前から続く事件や、第一部の事故を起こした陰謀にはしない。噂の伝播、栽培の開始、問題の発生を第一部の終幕で予告する必要もない。採用する部・街・人物は未定であり、必要になった後の物語の導入で描く。

## 第一部以後へ残す種

書き手が保管する候補。第二部のプロットや第一部の予告として確定したものではない。

- **暗い苔と観察メモ**：交易荷物と一緒に持ち帰った素材が、後に研究や暮らしの道具につながる。
- **比較用の皿**：ポピーの苔をメリルが両方食べようとする。珍しい苔の噂を来訪の理由にする。
- **整列した苔**：第一部の発見が他の街へ噂として伝わった後に発生し得る案。別の土地で等間隔の群落と掘り直された水路を見つけ、人為的な栽培を疑う。第一部の自然発生との差が手がかりになる。
- **味への不満**：メリルが「前の苔より油くさい」とこぼす案。薬剤や故意の被害の断定には別の証拠を置き、味見だけで事件を解かない。食用かどうかは種族をまたいで一般化しない。
- **違う原因の塔**：苔の生えていない塔、動物が構造物を塞いだ塔、補修や土地利用の事情で止まった塔。全塔を苔や同一組織のせいにしない。
- **取引先の先**：利益優先の一業者との対立が、別の取引や土地へつながる。組織名・首領・最終目的は未定。マッドハロウィンとの関係も必要に応じて検討し、自動的に同一組織としない。

塔の総数、世界地図、最終敵、全体の結末は未設定。範囲が世界へ広がっても、各地の暮らしを知り、観察して調べる姿勢を残す。

## 更新のしかた

世界・素材は本書、人物の判断と関係は [人物資料](characters.md)、事件の順序は [第一部プロット](story-part-1.md) を更新する。合意と制作案を区別するのは承認待ちにするためではなく、前の案へ無自覚に戻るのを防ぐため。

実装する際には新しい物語に合わせてプロフィール、加入、進行も見直し、現在のデータとの違いを記録する。資料を改稿しただけでゲーム側も変更されたとは扱わない。
