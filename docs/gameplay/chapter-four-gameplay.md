## 実装状況

幕間「約束の胡桃」、4-1〜4-9、リコの共闘、採用済みスチル4枚を本編へ接続した。セーブ形式はv4を維持し、既存の記録は初期化しない。

| 範囲 | 現行の動き |
| --- | --- |
| 幕間 | 3-9の達成話読了で第四章の依頼一覧に解放。会話だけで戦闘・報酬・クリア数はない。初回読了で4-1が開く |
| 4-1〜4-9 | 各15地点。初回は達成会話を読んで次の行先へ進む。既読の道は周回できる |
| リコ | 4-7の出発から五人目として共闘できる。物語上は4-9で旅団への同行を決める。4-6以前の場面、過去章の固定編成には加えない。経験値は共闘時の四人の最低値を引き継ぎ、再出発で重複付与しない |
| 会話・画像 | 詳細台本の幕間と各出発・帰還を19シーンで読む。4-4は徹夜明けと青い布を出発・帰還に分けて表示。4-7の苗、4-9の署名にもスチルを表示する |
| 描画 | リコの赤・黒の立ち絵を移動・作業・戦闘で表示。専用の動作アニメーションは未制作で、現行は静止立ち絵を使う。メリル戦と人物表示は採用リファレンスシートから作り直した立ち絵を使う。両者の道中での見かけの高さは主人公たちの表示基準に揃える |

## 冒険の構成

4-1は依頼の配達、4-2は灯籠の確認、4-3は往診と仕入れ調査、4-4は二日がかりの追跡、4-5は苔床の調査。4-6は記録を照合し、最後の地点でリコの光と煙の仕掛けを止める。4-7は苗を運び、途中でメリルから守る。4-8は苗の移植と周囲の魔物退治、4-9はリンデへの帰路と旅団の登録にする。リコ・メリルとの対立は道中の進行として処理し、物語で負傷や服従として描かない。

4-7からリコの戦闘参加を編成上で許可する。現行の `owned` は共闘可能な仲間を表し、旅団への正式加入フラグは追加しない。同行の約束は4-9の会話で示す。新しい調薬・拠点・消耗品機能はこの章では導入しない。

## 数値と確認

基本値と地点の仕事は `lib/chapter-four.ts`、戦闘ランクは `lib/combat.ts`、仲間は `lib/story-party.ts` と `lib/roster.ts`、画像は `lib/story-art.ts`。リコは採取の得意な遠距離支援役で、発光試料の目くらましを演出に使う。採取道具を専用武器として確定せず、装備の追加は行わない。

`node scripts/check-chapter-four-balance.mjs` は第三章の通し試走が返した状態全体を使う。3分以内に終わらない場合だけ、既読の4-1（初回の4-1以前は3-1）を5分単位で周回して再挑戦する。結果は[章ごとの戦力と到達時間](progression-balance.md#第三章から第四章への通し測定)へ記録する。これは自動シミュレーションであり、人や実機での所要時間ではない。

`tests/chapter-four.test.mjs` は幕間、解放、会話、共闘、保存を確認する。章の通し試走は `node --test tests/chapter-runs.balance.mjs` でローカル実行し、CIの毎回の単体テストへ追加しない。
