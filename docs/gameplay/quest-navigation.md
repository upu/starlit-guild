# クエストの選択と進行

[資料案内](../README.md) → [ゲーム仕様](README.md) → クエストの選択と進行

行先の操作とAuto-Next（クリア後の自動行先・出発）の仕様をまとめる。画面全体は [ゲームプレイ仕様](gameplay.md)、背景素材は [背景画像](../art/background-images.md) を参照する。

## 操作と保存

- 「第一章」「第二章」で一覧を切り替える。章以外の解放済み依頼がある場合は「その他の依頼」を表示する。未解放の章には鍵を表示する。
- 一覧は1回目のタップで候補を選び、同じ候補の再タップか詳細カードのタップで行先を決定する。冒険中の行先変更も既存と同じ動作。詳細のスクロール・ドラッグでは決定しない。
- 「Auto-Next」（クリア後、次のステージへ自動で出発する設定）はクエスト一覧と旅の手帳の「セーブ・設定 → 設定」で共有する。冒険の記録ごとに保存し、既存記録を含め初期値は無効。何度でも切り替えられる。
- 有効時は、ストーリーの並び（`storyStages`）で次の解放済みステージを行先にし、そのまま出発する。第一章から第二章、幕間を挟んだ第三章への移行も含む。
  - 初回クリアでは、クリア後の物語を読み終えた時点で行先を変えて出発する。幕間は読み終えた時点で3-1へ進む。
  - クリア済みステージを再びクリアした場合も、次のステージがクリア済みかどうかに関係なく進む。例えば3-9までクリア済みで1-1をクリアすると1-2へ出発し、以降も順に進む。放置中の進行でも同じ。
  - 次のステージの出発前の会話、または幕間が未読なら、行先の変更までで止まる。物語を読み終えた直後はその会話を続けて開き、「冒険を始める」で出発する。周回中に止まった場合は、出発ボタンから会話を始める。
  - 物語の読み返し、ステージ以外の依頼、次ステージが未実装の場合は行先を変更しない。
- セーブ形式の世代は変更せず、任意の `State.autoNextQuest` と既存の `Squad.lastQuest` を保存する。設定と次の行先は再読込・バックアップでも保たれる。

## 検証

`node --test tests/quest-navigation.test.mjs tests/quest-picker.test.mjs tests/departure-flow.test.mjs` で進行・操作・出発前の会話の整合性を確認する。

`npm run build` 後、PlaywrightとChromiumを用意し、`node tests/quest-picker.browser.mjs` で360・390・768px幅を検証できる。必要なら `PLAYWRIGHT_MODULE` にパッケージの絶対パス、`CHROME_PATH` にブラウザー実行ファイルを指定する。既存セーブへ接続しない独立したコンポーネント画面を使い、スクリーンショットと通信記録を `work/quest-picker-browser/` に保存する。
