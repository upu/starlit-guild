# 旅団の拠点機能（設計案）

[資料案内](../README.md) → [ゲーム仕様](README.md) → 旅団の拠点機能

第五章で導入する予定の、旅団としての仕組みの設計案。**アイテム1枠・ショップの消耗品・冒険中の自動使用は実装済み**で、第一章から利用できる。それ以外の旅団の拠点機能は未実装。現行の消耗品仕様は [ゲームプレイ仕様](gameplay.md#アイテム枠と消耗品) を正本とし、今後の第五章の実装進捗は第五章のゲーム実装資料で管理する。物語は [第五章計画](../story/story-part-5.md)、等級を付ける組織は [紋章院](../factions/heraldry-office.md) を参照する。

数値は未設定。時間の目安は相談で出た規模感で、確定値ではない。

## 全体の流れ

1. 菜園で作物を育てる。閉じている間も育つ。
2. 世話係が収穫し、種の在庫がある限り植え直す。
3. 作業台で、収穫物とショップの材料から消耗品を作る。これも閉じている間に進む。
4. 消耗品を各キャラクターのアイテム枠に登録する。冒険の出発時やピンチの時に自動で使う。

## 旅団タブ

- 下部ナビに「旅団」を加え、「冒険・キャラクター」と合わせて3つにする。拠点は倉庫の二階。
- 菜園・作業台・旅団の等級・掛け合いをここから開く。
- 掛け合いは、第四章の [旅団結成後の日常](../story/chapter-four-banter.md#旅団結成後の日常7本) を読めるようにし、第五章の進行や初めての収穫などで新しい会話を足す。既読の扱いは実装時に決める。
- アイコンは既存のナビと同じく、特定の人物の顔を使わない画像にする。

## 菜園

| 畑 | 場所 | 育てるもの | 世話係 |
| --- | --- | --- | --- |
| リンデのプランター | 倉庫の裏 | 普通の薬草・野菜など | 1人 |
| ブレッカの苔床 | ブレッカの塔から離れた栽培所（[第四章計画](../story/story-part-4.md#4-10-同じ宛先へ)） | 塔から離して育てた苔 | 1人 |

- リンデでは光る苔を育てない。塔のそばで苔を増やすのは第四章の事件そのもの。
- ブレッカの日々の水やりは、物語どおり現地の管理人と作業地の人がしている。旅団の世話係は、記録と乾燥の段取りを受け持つ扱いにする。
- リンデのプランターは初めは2枠。等級が上がると増える案。第五章は等級がE級で固定なので、2枠のまま。

### 育ち方

- 時計の時刻で育ち、画面を閉じている間も進む。その分、時間は長めにする。最初の作物でも1時間ほど。
- 世話係がいなくても育つが、**収穫されない**。実ったまま待ち、傷まない。
- 世話係がいると、少し早く育ち、収穫量が増える。得意な人（リコ・アリア）だと効果が大きい。
- 世話係は収穫した後、種の在庫がある限り同じ作物を植え直す。
- 苔は、収穫と同時に乾燥まで行い、「乾燥苔」として在庫に入る。乾燥までが世話係の仕事。「光が抜ける前に加工すれば薬効が残る」設定（[世界観](../story/world-and-story.md#光をためた植物の苦味と加工制作案)）に合わせる。
- 実際の夜にログインしないと採れない作物は作らない（[月光を蓄える薬草](../story/world-and-story.md#月光を蓄える薬草)）。

## 作業台

- 担当者がいないと作れない。将来、別の仕組みで自動にする余地は残す。
- 担当者は誰でもよく、得意な人だと時間が短くなる。

| 得意な人 | 加工品の例 |
| --- | --- |
| レオン | 胡桃のパン・お弁当（焼く） |
| ミラ | お茶。蒸らし時間だけは得意な人でも短くならない |
| リコ | 薬草ソーダ・苔の加工 |

- 作り方は二つから選ぶ。
  - **個数を決める**：決めた回数だけ作って止まる。
  - **くり返す**：材料がある限り作り続ける。
- 材料は1回作り始めるごとに引く。途中でやめても、始めていない分の材料は減らない。
- 閉じている間も進む。寝る前に仕込めば、朝にできている。
- 作業台の数は未設定。

## 役割の割り当て

- 世話係と加工担当は、冒険の周回に参加したままでよい。編成を外す仕組みは作らない。
- 同じ人が、世話係と加工担当を兼ねることはできない。畑の世話係どうし（リンデとブレッカ）も兼ねない。

## 栽培と加工のレベル

- 栽培と加工をするたびに、それぞれのレベルが上がる。レベルが上がると、1回に作れる数が増え、時間が短くなる。
- レベルの上限は旅団の等級で決める。第五章はE級で固定なので上限も低く、在庫をやりくりする状態が続く。等級が上がる後の章で、安いアイテムの在庫を気にしなくてよくなる。

## アイテム枠と消耗品（実装済み・現行仕様）

1人1枠への種類登録、バッグの共有在庫、被弾時・出発時の自動使用、専用戦闘への適用は実装済み。第一章1-3の達成話読了から利用できる。品名・価格・効果・登録変更・保存は [現行仕様](gameplay.md#アイテム枠と消耗品) を参照する。

2枠目と、作業台で作るお弁当・お茶・ソーダは将来案。現在の出発時品はショップの旅のビスケット。資源の薬草は回復品として直接使わない。

## ショップ

すぐ使える消耗品の購入は実装済み（[お店の現行仕様](gameplay.md#お店)）。貯まったコインの使い道とし、第一章から安い傷薬を購入できる。

菜園でまだ育てられない材料（小麦粉・胡桃・蜂蜜・バターなど）の販売は、作業台と合わせて今後検討する。

## 旅団の等級

- [紋章院](../factions/heraldry-office.md)が付ける。画面には「E級」とだけ表示し、苦情の件数は出さない。
- 第五章ではE級で固定する。等級が上がったときに増えるもの（プランター・アイテム枠・レベルの上限・遠方の依頼など）を一度に開かないよう、後の章で段階的に開く。

## バランスとセーブ

- 章の通し試走（自動シミュレーション）は、アイテムを使わない状態で測る。現時点ではアイテムを「あると楽になる」位置付けにする。将来はアイテムありを前提にする方針だが、移行時の品・使用量・到達目標は別途決め、現行の目標は緩めない（[章ごとの戦力と到達時間](progression-balance.md)）。
- 冒険は画面を開いている間だけ進む（[セーブシステム](save-system.md)）。菜園と作業台は、閉じている間も進む初めての仕組みになる。冒険の時計とは分け、植えた時刻や作り始めた時刻を保存する。
- 消耗品はv4へ任意項目を追加済み（[保存仕様](save-system.md#消耗品の保存互換)）。菜園・作業台の保存形式は実装時に決め、既存の記録は初期化しない。

## 未設定

- 作物・加工品の種類と数値（時間、収穫量、効果、価格）。
- 種の入手方法。貯まっている薬草・鉱石を種や肥料、プランターの増設などに使う案がある。
- 作業台の数、各機能を開く物語の場面。
- 端末の時計を変えた場合の扱い。
