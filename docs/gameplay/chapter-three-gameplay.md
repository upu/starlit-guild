## 会話をレビューする手順

1. [第三章の生成台本](../generated/chapter-three.md)をMarkdownとして読む。幕間と3-1〜3-9を物語順に収録している。
2. 台詞・表情を直すときは、対応する `lib/chapter-three-*-stories.ts` の会話データを編集する。生成Markdownは直接編集しない。
3. `npm run script:export` で再出力し、`npm run script:check` と会話の構造・話者・表情の検査を行う。

専用の試読ページ、ダミー戦闘、第三章末のテストセーブは作らない。今回の会話データは通常の `stories`・`storyStages`・仲間一覧へ追加しないため、ゲームの表示・進行・既読・保存は変わらない。バージョンは据え置く。

## データの置き場

- `lib/chapter-three-stories.ts`：目次と会話の集約。
- `lib/chapter-three-opening-stories.ts`：幕間と3-1〜3-3。
- `lib/chapter-three-preparation-stories.ts`：3-4〜3-6。
- `lib/chapter-three-finale-stories.ts`：3-7〜3-9。
- `lib/chapter-three-dialogue.ts`：既存のStory形式に沿った生成補助と話者名。先行会話IDは保存に使わない。

後から本編へ接続するときも、本文を別コピーして二重管理しない。確定したクエストIDと進行条件へつなぎ、先行会話用のIDを保存データへ流用しない。

## 冒険実装の前に決めること

1. 各場面の冒険範囲と、3-8のすり替え・帰路戦闘を表示するタイミング。
2. クエストID・解放条件・フィンの操作上の加入時期。物語上は3-1で同行、3-9で継続同行を約束する。
3. 幕間の解放・読了・思い出との接続と保存互換。
4. フィンの戦闘・採取・装備と必要な画像。
5. [章ごとの戦力と到達時間](progression-balance.md)に第三章の目標を置き、第二章終了データから検証する。

会話の先行作成を、第三章がゲーム内で読める状態や冒険できる状態とは扱わない。
