# 関係性と掛け合い

[キャラクター一覧](../characters/README.md) · [執筆指針](../story/story-writing.md)

個人の口調・性格は個別ファイル、複数人にまたがる関係性はここで管理する。詳しい共通設定がある [アリアとレオン](aria-leon.md) は専用ファイルを正本とする。ほかの組も内容が増えたときだけ個別ファイルへ分ける。

## 関係性の一覧

| 組み合わせ | 採用済みの関係 | 今後深める方向（人物を深める軸） |
| --- | --- | --- |
| アリア × レオン | 幼なじみの約束。相互の好意と、言い切れない気持ち | 頼る側・支える側を行き来し、日常の約束を増やす |
| ミラ × フィン | お目付け役と悪戯っ子 | フィンがミラの疲れに気づき、立場が少し逆になる |
| ガル × ミラ | やさしい守り手 | 互いに、世話を焼かれることも受け入れる |
| ルナ × ノエル | 星と詩の物語 | 研究と言葉・歌を通じて、本人の感情にも触れる |
| アリア × ポピー（旧設定） | 森のおすそわけ | 旧ポピーの記録。[リコ](../characters/lico.md)との関係は人物資料の制作案を参照する |

この5組は連携技のある組み合わせ。ほかの仲間同士の会話を作らないという制限ではない。恋愛として設定済みなのはアリアとレオン。

## 第三章後の四人の会い方（制作案）

アリア・レオン・ミラ・フィンは、第三章後も常に四人で暮らしたり旅したりするわけではない。二人は各村の交易、ミラは往診、フィンは仲介や知り合いへの用事があり、それぞれの普段の仕事を続ける。

二人の交易先であるリンデに来る日を伝え合い、予定が合うと食堂で昼を食べる仲になった。ミラは往診の合間に寄り、フィンは仕事の話や噂を持ち込む。待ち合わせの伝言を預かる店主にも手間がかかるため、第四章で依頼の宛先をまとめる理由につながる。

四人の同行は、同じ町へ行く二つの依頼と、それぞれの予定を合わせて決める。具体的な会話は [第四章4-1](../story/chapter-four-script.md#4-1-塔を直した人たちへ) を参照する。旅団を結成してからも、村の仕事と往診を続け、遠出の予定に合わせて引き継ぎをする。リンデは各地への旅の合間に戻る連絡先で、常駐や共同生活の場ではない。全員が留守の手紙は貸し手に預かってもらう。ミラ個人の往診の返事と、旅団全体の依頼は宛先を分ける。リコのブレッカの苔床を含む留守中の管理は [第四章計画](../story/story-part-4.md#拠点) と [リコ](../characters/lico.md#第四章での役割制作案) を参照する。

## 既存の仲間との掛け合い（採用済み）

- メリル × ポピー「試飲役には向かない」（旧設定ポピーの場面。[リコ](../characters/lico.md#旧設定ポピーの記録)へ置き換え済みで、描き直す場合は反応を変える）：メリルが苦みを抜く前の胃薬を飲み、涙目で「まっず……！」。ポピーは「それ、大丈夫なの！？」と慌てる。魔物の胆より苦いと褒め、パンにつけようとする悪食にツッコミが追いつかない。スチルでは籠手を外している。
- プティ × フィン「返さない宝物」：鍵を使ったいたずら合戦。フィンが大切にしている木のボタンだけは遊びに使わない約束をする。彼の宝物の価値を金額に戻さない。
- チャチャ × ミラ「三分を数える手」：筋トレの回数を蒸らし時間にしていたチャチャに、ミラが座って待つお茶の楽しみを教える。次はミラも淹れてもらう側になる。
- チャチャ × ガル「重さより、持ちやすさ」：茶器を運ぶ盆の持ち手を、ガルが細かな手仕事で直す。大剣を持ち上げるときはチャチャも支え、力と技巧のどちらかだけに頼らない。

各話の登場人物の加入・設備・敵役の初遭遇は `lib/character-encounters.ts` の条件に合わせる。上記最初の3話にスチルを付け、対応動作に達したページから表示する。
