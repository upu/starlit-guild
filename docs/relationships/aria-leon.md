# アリアとレオン

[アリア](../characters/aria.md) · [レオン](../characters/leon.md) · [関係性の一覧](README.md)

二人の関係性の正本。共通の世界設定は [世界観と物語](../world-and-story.md)、場面への落とし込みは [執筆指針](../story-writing.md) を参照する。

## アリアとレオン：制作の核

**幼なじみで、お互いに好意がある。それでも気持ちを言い切れず、煮え切らないふたりを見守る楽しさを大事にする。**

これは書き手向けの設定。ゲーム内の見出しや人物紹介で相互の好意を明かさず、台詞やしぐさからプレイヤーが察する形にする。人物紹介に載せるのは普段の癖や観察できる特徴までとする。

- 好意は互いにある。告白や交際の成立はまだ描かない。
- 長い付き合いから、隣にいることや相手を気遣うことが自然になっている。
- 面白いものを見つけたとき、それを伝えたい相手として真っ先に互いを思い出す。会っていない間にも「次に会ったら話そう」が自然に生まれる。
- アリアは冒険では積極的でも、恋愛の話になると冗談や軽口に逃げる。
- レオンは危険な場面では迷わず手を取れるが、日常で隣に座る理由は探してしまう。
- 「幼なじみだから」で説明してきた優しさに、少しずつ別の意味が見えてくる。
- 言えなかった場面にも変化を残す。前より近くに座る、自分から頼る、ふたりの約束をする。
- 仲間はときどき気づいて見守る。毎回からかったり、告白を代行したりしない。
- 絆の先には「依頼がなくても、ふたりで出かける約束」がある。恋人になることを機械的な到達報酬にしない。

互いの気持ちをどこまで察しているかは、断定しすぎない。「絶対に脈がないと思い込んでいる」「両思いを完全に理解して駆け引きしている」のどちらにも固定しない。

## 食事を分ける時間

第一章の「お昼を持って坂へ行く約束」は、[第二章計画](../story-part-2.md) の2-1で果たす。レオンが食事を多めに用意する気持ちは [レオン個人の軸](../characters/leon.md#アリアがおいしそうに食べる姿) を正とする。

二人のやり取りでは、レオンがアリアへ分けるだけでなく、アリアもレオンの感想を聞き、一緒に味わおうとする。世話をする側・される側を固定せず、同じ食事を楽しむ。気持ちは説明文で断定せず、分け方や食べ始める間で表す。

ミラ加入後も二人だけの予定を残す。2-9では次の往診の日とは別に会う予定も短く確かめ、告白・交際・同居を成立させない。公開済み第一章や従来記録へ出来事を遡って加えない。

## ふたりの性格を動かす仕組み（制作案）

以下は台本に使う継続的な制作方針。第一章で見せた助け合いを引き継ぎつつ、一度の出来事で二人の癖を克服したことにはしない。

**アリアは思いついた可能性に飛びつき、レオンはそれを実行する段取りを考える。どちらも、その得意なやり方をやりすぎることがある。**

| 観点 | アリア | レオン |
| --- | --- | --- |
| 最初に出る反応 | 「面白そう」「それなら、こうすれば？」が考え終わる前に口に出る。話しながら近づいたり、手を伸ばしたりする | 時刻、荷物、帰り道、うまくいかなかった場合を確かめる。気になることが残ると出発を決めにくい |
| 良いところ | 誰も聞かなかったことを聞き、試してみるきっかけを作る。褒め言葉や嬉しさもそのまま出る | 思いつきを実行できる形にする。忘れ物や見落としを拾い、前に起きたことを覚えている |
| 行きすぎるところ | 「できそう」を「できる」と言ってしまう。悪気なく核心を突いて相手を困らせたり、説明を聞き終わる前に動いたりする | 予備の予備まで持ち、荷物と準備が増える。調べれば減らせる不安まで出発前に解消しようとして、行動が遅れる |
| 自分の弱点への言い訳 | 「ちょっと見ようと思っただけ」「今から説明するところだった」。一度は強がるが、具体的な迷惑に気づけば自分でも謝り、やり直す | 「念のためだ」「あと一つ確認したら」。慎重であることを正しさと思い込み、準備が負担を増やしたと認めるのが遅い |
| 相手に甘えているところ | レオンなら続きの段取りを考えてくれる、と無意識に当てにする | 自分が把握していれば大丈夫だ、と段取りを抱える。アリアに任せるより自分で確かめたくなる |
| 恋愛で出るねじれ | 「それ、似合う」「レオンとなら行きたい」は自然に言えるのに、言葉の意味を自分で意識すると軽口で逃げる | 会う段取りは細かく立てられるが、自分が会いたいだけで誘っていいのか考えすぎる。実際に相手が困った瞬間には先に動ける |

### 長い付き合いの中で強まった癖

アリアの急な寄り道に対応するうち、レオンは余分の道具や時間を用意するようになった。アリアもそれに慣れ、思いつきを口にしやすくなった、という関係の案。レオンの慎重さを彼女だけの責任にはせず、元から先を確かめたい性分がある。

レオン自身も新しい場所や道具に興味がある。「念のため」に寄り道の道順まで調べていた、といった行動で本人の楽しみを出せる。口では条件を挙げていても、行ける方法を探していることがある。毎回ため息をつく保護者と、叱られる子どもという役割には固定しない。

### 失敗と成長の扱い

以下は長期的に使う人物の軸であり、第二章で達成させる成長課題ではない。[第二章計画](../story-part-2.md) では癖を克服して無難になる展開を置かず、早合点や過剰な備えが今後もトラブルを生む余地を残す。第一部でできた助け合いや約束までなかったことにはしない。

- アリアの軽率さには、ときどき謝罪や予定の組み直しが必要になる。レオンが全部片づけず、彼女も相手への説明ややり直しを引き受ける。思いつきが常に大正解だったことにしない。
- レオンの慎重さにも、余分な荷物で疲れる、確認を重ねて聞きに行くのが遅れるなどの代償がある。アリアの見立てに助けられ、自分が考えすぎたと認める場面を作る。
- アリアは採取の見分けのように経験のあることでは丁寧に確認できる。レオンは差し迫った場面では迷わず手を出せる。性格を全ての行動に機械的に当てはめない。
- 成長は、アリアが思いつきを一言伝えて相手の返事を待てること、レオンが全部決まらなくても一緒に確かめに行けること。活発さや慎重さを消して二人とも無難にしない。
- 第一部ではアリアの提案で再訪が動き、レオンの記憶と比較の段取りで仮説が確かになる。観察・判断・失敗・立て直しを二人に分ける。

## ふたりの出身と現在の仕事

公開済み第一章と今後の物語で共有する設定。

- 二人は近隣の別々の村に住む。
- 子どもの頃は村どうしの取引の場で何度も顔を合わせ、一緒に遊ぶようになった。青年になった今は、それぞれの村の仕事で少し遠い街へ取引に行くとき、一緒に行く仲。
- 行きには合流し、帰りには別々の村へ帰る。共通の家や同居生活を最初から前提にしない。第一部では待ち合わせと分かれ道を実際の場面として描いた。
- 最初の塔は交易先の街の周辺。街で不調の話を聞き、仕事のついでに見に行く。村の取引、薬草採取、寄り道が冒険の入口になる。
- 第一部は二人だけ。他の既存キャラの加入や任意の掛け合いは置かない。住民や仕事相手との交流はある。

## 村の友人と、二人の特別な距離感

ゲーム内には出さない、書き手向けの背景設定。人物の暮らしと関係性を考える土台とし、友人の名前や登場場面が実装済みだとは扱わない。

### 合意した設定

- それぞれの村に同世代の親しい友達がいる。同性・異性とも普通に付き合いがあり、仕事の合間の雑談や食事、祭りなどを一緒に楽しむ。二人が会っていない間も、各自の村での生活と友人関係が続いている。
- 子どもの頃の村どうしの取引の場には、ほかの子どももいた。みんなで遊ぶこともあり、その中でアリアとレオンは面白いものを探したり、寄り道したりする気が合った。
- 成長して仕事や予定が分かれた今も、二人は街への交易で同行する機会が重なる。村の友達にはそれぞれの仕事や予定があり、毎回同じ道を行くわけではない。
- 互いは唯一の友達ではない。地元の友達との親しさも大切にしながら、発見を分かち合いたい相手として互いが特別になっている。その気持ちはアリアからレオンへの一方通行にせず、二人に共通する距離感とする。
- 村の友達には気軽にできる誘いでも、相手と二人きりで会う意味を意識すると、言葉を選んだり用事を理由にしたりする。幼なじみとしての気安さと、好意ゆえのためらいが同居する。

### 設定を扱うときの境界

- 「真っ先に伝えたい」は、友達との先約や村の仕事をいつも後回しにする意味ではない。二人の親しさを、ほかの人間関係の軽視や孤立で説明しない。
- 村の友達はそれぞれの暮らしを持つ人として扱い、恋敵や二人をからかうためだけの役に固定しない。
- 村の人口、同世代の人数、友達の名前・職業・個別の出来事は未設定。人口減少、種族による隔離、同世代の不在を二人が親しくなった理由にしない。
- 第一部の冒険は引き続き二人で進める。この背景設定を理由に、新しい同行者や村の友人の登場場面を追加しない。既存シーンの出来事やセーブ上の記録にも遡って加えない。

## 関連するプロット・実装

公開済み第一章1-1〜1-6の会話は [第一章前半の会話](../../lib/prologue-stories.ts) にある。二人は別々の村から交易へ出て、帰路の違和感と街の不便を結びつけ、塔で苔灯を作る。光が弱まった後は、仕事のない午後に会って森の苔と比較する。アリアの植生を見る力とレオンの準備・記録を組み合わせ、どちらか一人だけが答えを出す構成にしない。

冒険の待機中には [待機の掛け合い](../../lib/idle-banter.ts) を6組実装。準備、靴紐、荷物、並んで歩くこと、髪を結ぶタイミング、持参したパンを分けることを話す。場所や進行に依存する出来事、同居、交際の成立は追加しない。

1-7・1-8は [水路の調査と復旧の会話](../../lib/waterway-stories.ts)、1-9は [終幕の会話](../../lib/tower-finale-stories.ts) にある。アリアの植生の観察、レオンの管理図の読み取り、管理人の設備知識を合わせて水路を見つけ、地域の作業者と修理する。最後は苔の撤去と運搬を分担し、再点灯後の帰路で次の休みにお昼を持って坂へ行く約束をする。告白・交際・同居の成立は描かない。

[第一部プロット](../story-part-1.md) と各会話データを照合する。従来記録の思い出・モチーフは [従来記録の出来事](../story-writing.md#従来記録の出来事を参照するとき) を参照する。制作案を実装済みの出来事や人物の記憶として扱わない。

`town-deliveries-departure` では、アリアが見えている小箱だけで「一度で運べる」と請け合い、残りの箱を知って一度は強がる。レオンの足元への指摘を受け、自分で依頼主に謝り、荷札を調べて二回に分ける段取りを提案する。レオンに後始末を丸投げせず、最後は相手が持ち手を握るのを待つ。`town-deliveries-return` では自分から残りの荷を確認し、助けられたことにも礼を言う。早合点と責任感を同じ仕事の中で描いた採用済み場面で、性格上の弱点を完全に克服したという扱いではない。
