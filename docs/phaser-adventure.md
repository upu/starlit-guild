# Phaserによる冒険画面

Phaser 4.2.1を追加し、冒険のマップを現在の地点に焦点を当てたCanvas描画へ移行した。サイト全体はReact / Vinextのまま。拠点、編成、会話、セーブ画面は既存の表示を維持する。

## 責務

- `lib/game.ts` / `app/use-local-game.ts`：進行、報酬、端末保存、バックアップ、オフライン精算の正本。変更なし。
- `lib/adventure-presentation.ts`：正本の読み取り専用投影。位置、現在の敵、画像、イベントの期限、入力の意図を計算する。Phaserから保存・進行処理は呼ばない。
- `app/map-stage.tsx`：見出し、出発、キーボード対応の手助け・回復。
- `app/phaser-adventure.tsx` / `app/phaser/renderer-session.ts`：ブラウザーでの遅延読み込み、最新の状態・コールバックへの接続、リサイズ、非表示・メニュー中の停止、破棄、エラー時の再試行。
- `app/phaser/adventure-game.ts`：Phaserの背景、仲間、敵、足元のHP、射撃、斬撃、回復、ダメージ数値とカメラ演出。

## 維持する動作

Canvas内の1回のタップは1つの既存Actionになる。仲間とHP付近は回復、敵と余白は手助け、休憩中の余白は回復。DOMの操作ボタンも同じ判定を使う。

PhaserをSSRで実行しない。エンジン本体も`useEffect`から動的に読み込む。200ms間隔のゲーム状態を描画用の時刻で補間するが、進行・報酬は加算しない。画面を閉じている間やメニュー中は描画ループを休止し、復帰後の古いイベントは時刻で除外する。読み込み完了前に画面を離れた場合もCanvasを後から生成しない。

画像は現在の背景と必要な人物、共通アトラスを読み込む。行き先が変わった場合だけ不足画像を追加する。アトラスは画像の実寸を4列×3行に分けて使用し、ユーザーのオリジナル人物は個別の画像を使う。

「動きを減らす」では歩行の揺れ、踏み込み、背景の移動、粒子、射撃、カメラの揺れを止める。地図上の位置と数値表示は更新し、ゲーム進行は止めない。効果音・BGMは既存の音量・消音・非表示時の停止処理を使用し、Phaserの音声は無効にする。

## 検証範囲

既存の全地点、物語の画像公開時期、演出期限、手助け・回復の検証をCanvasへの投影とDOM操作に合わせて更新した。追加テストは描画によるセーブ非変更、異なる画面サイズでのタップ判定、遅延読み込みのキャンセル、停止・リサイズ・破棄、失敗からの試行を確認する。

自動テストと型検査・ビルドは実行するが、ブラウザーのWebGL描画、タッチ実機、実フレームレート、連続した画面切替の視覚確認は別途必要。

## アリア・レオンのコマ絵

アリアとレオンの透過素材を整え、`heroSheets.ready` をtrueにして有効化した。他の人物は従来の画像を使用する。

`public/animations/` の透過シートを必要な隊だけ読み込む。4列×3行の順番は、歩行4コマ、攻撃4コマ、待機2コマ、被弾2コマ。画像の実寸からPhaserのTexture Frameを登録し、`lib/hero-animation.ts` が現在の時刻とイベントから表示コマを選ぶ。再生完了コールバックで進行を動かさないため、停止・復帰や再マウントで攻撃が二重に発生しない。

被弾は320ms、攻撃は650msで回復ポーズまで再生。歩行は600msで循環し、待機は3.6秒に一度150msまばたきする。被弾を攻撃より優先し、採集は武器攻撃にしない。休憩・「動きを減らす」では静止ポーズにする。他の人物は従来の画像と演出を維持する。歩行・攻撃コマに元の静止画用の回転・上下揺れを重ねず、被弾中は攻撃の踏み込みも重ねない。

追加テストでは各動作の境界、被弾の対象、古い地点・未来・期限切れイベントの除外、採集・休憩・動きを減らす設定、描画によるセーブ非変更を確認する。素材の生成記録は [動作画像](hero-animation-art.md) を参照。
