# STARLIT GUILD ドキュメント案内

調べたい分野の案内から、仕様・設定・制作記録へ進む。

| 分野 | 読めること |
| --- | --- |
| [ゲーム仕様](gameplay/README.md) | 遊び方、章ごとの実装、戦闘・育成、セーブ |
| [世界観・シナリオ](story/README.md) | 世界の設定、執筆指針、章のプロット、台本 |
| [キャラクター](characters/README.md) | 人物の設定、関係性、所属組織 |
| [アート・音](art/README.md) | 背景、人物画像、スチル・動画、アイコン・演出、音 |
| [開発・運用](development/README.md) | 開発・検証・公開、描画の設計、資料の管理 |

章・ステージ・コード上のIDを照合するときは [用語集](glossary.md)、エージェントが作業を始めるときは [共通ルール](agent-rules.md) を読む。

現行仕様・制作案・過去の制作記録は区別する。実装状況はゲーム仕様側で管理し、設定資料の更新だけでゲームに反映されたとは扱わない。

資料を追加・整理するときは [ドキュメントの管理](development/documentation.md) を参照する。この入口には分野の案内を置き、個別の章や素材は担当分野から案内する。
