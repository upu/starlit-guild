# STARLIT GUILD ドキュメント案内

このディレクトリには、現行ゲームの仕様、シナリオ制作資料、アート制作記録、実装上の設計を分けて置く。

READMEはプロジェクトの入口に留め、細かな数値・解放条件・保存形式・実装メモはここから各資料へ分ける。

## 読み分け

| 区分 | 扱い |
| --- | --- |
| 現行実装 | 現在のゲームで動いている仕様。最終的な正はソースコード |
| 制作資料 | 今後の世界観・人物・シナリオを作るための資料。現行実装と一致しない場合がある |
| 制作記録 | 画像・演出などを再現、修正するための記録 |
| 開発資料 | 実装構成、保存、検証、公開など開発者向けの資料 |

シナリオ資料では「合意した核」「制作案」「将来の種」「現行実装」を混同しない。資料だけを更新した場合は、ゲーム内の会話やクエストまで変更されたとは扱わない。

## 文書を増やすとき

READMEへ詳細仕様を追記するのではなく、既存資料の担当範囲へ追加する。新しい分野で既存資料に自然な置き場がない場合だけ、新しい文書を作ってこの目次へ追加する。

変更履歴や一時的な不具合記録はREADMEに積み上げず、Git履歴やIssueへ残す。
