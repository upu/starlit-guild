# 序章の顔アイコンと受け渡しスチル

2026-09-11。組み込みの画像生成ツールを使用。既存の `public/stories/first-map.png` と `public/sprites.png` を人物・画風の参照にした。元の全身絵と既存スチルは保持している。

- `public/portraits/aria.png`：アリアの顔アイコン。
- `public/portraits/leon.png`：レオンの顔アイコン。
- `public/stories/village-trade-handover.png`：街の店主へ薬草と村の交易品を渡すスチル。

ゲーム内の各台詞・会話冒頭・下部のチャット欄に `Portrait` を使用する。現在の小表示用の顔は、後述の専用アトラスを使う。上記のふたりの旧画像は制作参照として保持する。マップや編成画面の全身絵はそのまま使う。

スチルは `village-trade-return` の最初のページから表示し、画像をタップすると拡大できる。冒頭から取引が始まる会話に合わせた。受け渡し先は既存シナリオの「街の取引先の店」に合わせた。

イベント会話には×ボタンを置かず、画面外タップ・Escも途中終了させない。最終ページの「冒険を始める」または「閉じる」でのみ終了する。ブラウザー自体を閉じることを妨げず、未読の到着話は保存されたまま残る。

最終プロンプト一式と保存先は [生成記録](prologue-dialogue-art-generation.json) に記載。

## 小表示用の顔アイコン（2026-09-13）

組み込みの画像生成ツールで `public/portraits/dialogue-atlas.png` を制作。太い輪郭、少ない陰影、大きな目と髪の色面を使い、11人を同じ絵柄で描き分ける。フード、帽子、髪飾り、プティの八重歯などの目印を保つ。人物設定・会話本文・クエスト・セーブ仕様の変更はない。

4列×3行。上段はアリア、レオン、ミラ、フィン。中段はガル、ルナ、ポピー、ノエル。下段はメリル、プティ、チャチャ、空き。`Portrait` のスプライト番号をこのセル順へ対応付け、会話画面とチャット履歴で共用する。

チャットは各セリフの左に本文2行相当（標準約45px）の顔を添え、名前は本文の先頭に表示する。欄は本文4行相当＋間隔・余白（標準約111px）。長文は省略せず折り返し、過去の発言はスクロールで読む。会話画面の顔は従来の72px（狭幅では64px）を維持する。

参照画像と最終プロンプトは [小表示用の生成記録](dialogue-portraits-generation.json) に記載。
