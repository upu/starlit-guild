# 序章の顔アイコンと受け渡しスチル

2026-09-11。組み込みの画像生成ツールを使用。既存の `public/stories/first-map.png` と `public/sprites.png` を人物・画風の参照にした。元の全身絵と既存スチルは保持している。

- `public/portraits/aria.png`：アリアの顔アイコン。
- `public/portraits/leon.png`：レオンの顔アイコン。
- `public/stories/village-trade-handover.png`：街の店主へ薬草と村の交易品を渡すスチル。

ゲーム内の各台詞・会話冒頭・下部のチャット欄に `Portrait` を使用する。序章のふたりは専用画像、他の人物は既存画像の顔の位置を拡大表示し、人物固有の特徴を保つ。マップや編成画面の全身絵はそのまま使う。

スチルは `village-trade-return` の最初のページから表示し、画像をタップすると拡大できる。冒頭から取引が始まる会話に合わせた。受け渡し先は既存シナリオの「街の取引先の店」に合わせた。

イベント会話には×ボタンを置かず、画面外タップ・Escも途中終了させない。最終ページの「冒険を始める」または「閉じる」でのみ終了する。ブラウザー自体を閉じることを妨げず、未読の到着話は保存されたまま残る。

最終プロンプト一式と保存先は [生成記録](prologue-dialogue-art-generation.json) に記載。
