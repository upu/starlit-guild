# 第一部プロット：帰り道の小さな灯り

作成日：2026-09-11。第2稿。世界と素材の共通ルールは [世界観と物語](world-and-story.md)、人物は [キャラクター設定](characters.md)、文章化は [制作指針](story-writing.md) を参照する。

本書は新しいシナリオの制作稿。序章の交易クエスト・出発前と到着後の会話をゲームに実装済み（公開状況とは別）。第一章以後は未実装。既存設定・クエスト順・加入順は変更できる。第一部に他の仲間の加入はなく、冒険を進めるのはアリアとレオンのふたりだけ。

## 第一部の筋

**それぞれの村の交易の仕事で街へ出た幼なじみが、寄り道した塔で便利な苔を拾う。帰り道で灯りが弱まったことから、小さな発見が、街と村をつなぐ道の異変へ結びついていく。**

仕事で街へ → 道中の薬草採取 → 取引先で塔の噂 → 塔への寄り道 → 光る苔を持ち帰る → 帰村する頃に森の苔との似かよりに気づく → 再訪して比較・調査 → 排水と群落の除去 → いつもの交易路が使いやすくなる。

- 範囲：近隣の二つの村、合流する道、少し遠い交易先の街、街の周辺の塔と排水路。
- 達成：最初の一塔とその周辺街道の回復。世界全体の塔の復旧は第一部の目標にしない。
- 完結：近隣の塔の灯りが戻り、街と村の往来がしやすくなった喜びで第一部を閉じる。他の土地の相談、次の事件、敵対者の姿などの予告は付けない。
- 感情の軸：子どもの遊び仲間が、今は仕事も調べ物も頼れる相手になっている。「次に一緒に行く理由」が少し変わる。告白や交際はまだ描かない。
- 危険の規模：道中の小さな魔物、ぬかるみ、排水路の作業。普通の装備、観察、地域の人との協力で対処できる。竜や覚醒は出さない。
- 人物の範囲：ふたりと地域の仕事相手・管理人・作業をする人々。他の既存キャラは任意場面にも入れず、第二部以後へ残す。

## 出発前からある関係

アリアとレオンは別々の近隣の村で育った。子どもの頃は村間の取引に来るたび顔を合わせ、大人たちの仕事の合間に一緒に遊ぶようになった。青年になった今は、自分たちが取引の荷物を持って街へ向かう。

制作案では街道の分かれ道近くに待ち合わせの目印がある。行きはここで合流し、帰りはそれぞれの村への道に分かれる。家族の職業、目印の形、村名・街名はまだ決めない。最初から共同生活や常設の旅団拠点を前提にしない。

今回が街へ行く初めての仕事であるとは固定しない。ふたりは道と取引先に多少の馴染みがあり、以前との小さな違いに気づける。

## 書き手が知っておく原因（本文では先に明かさない）

嵐の倒木で排水路が塞がり、塔の足元の石組みが湿った状態になる。森ではまれに見られる程度の苔が、湿り気と塔の豊富な魔力の組み合わせで繁殖し、魔力を取り込む働きも活発になる。外から見える群落の先、石組みの奥まで増えた苔が塔の力を奪っている。

通常の森の苔は取り込む力が弱く、普通に見ても発光が分からない。塔のそばの苔は採った後もしばらく光る。初見では便利な素材に見え、帰りに光が落ち着いてから元の姿を思い出せる。

最初の事故は自然発生。故意の栽培業者や黒幕は置かない。後の事件で人為的な栽培を描く際にも、この事故を遡って陰謀に変えない。

管理人は塔の通常の点検を続け、専門家にも相談している。苔が見えていても、いつもは害のない生物なので原因と結びつかない。アリアの森での経験と、持ち帰って変化を見たふたりの経験が新しい手がかりになる。住民が何もしなかった、という説明にしない。

## 章ごとの展開

### 序章：いつもの待ち合わせ

**狙い**：暮らしの仕事から始め、ふたりの関係を動作で伝える。

別々の村から荷物を持って来たふたりが合流する。互いの荷物と帰りに買う物を確かめ、街へ出発する。昔は取引が終わるのを待って遊んだ場所を、今は自分たちの仕事のために通る。説明を長く置くより、道端の遊び場を覚えている一言で過去を見せる。

道中、街で渡す分や村から頼まれた分の薬草を採る。具体的な依頼主は台本で一本に揃える。アリアが採り、レオンが荷物の置き場所や戻る時刻を確かめる。どちらか一方だけが仕事をする場面にしない。

性格を出す場面案：アリアは薬草を見つけ、話の途中でそちらへ足を向ける。レオンは持ち運ぶ包みまで出すが、予備の包みや道具を積みすぎて荷が重い。アリアに指摘され、分けて持つことにする。彼の準備が助けになることと、やりすぎることを同時に見せる。村から預かった商品を余計な荷物として扱わない。

**残るもの**：採った薬草、取引の荷物、帰りに分かれる場所。後の苔の発見も、素材を見分けて持ち運ぶ普段の仕事の延長になる。

### 第一章：街で聞いた話

**狙い**：塔の不調が、ふたり自身の仕事に関わることを知る。

取引先へ荷物と薬草を渡す。道が歩きづらかったことを話すと、相手も「最近、塔が弱くてね」と返す。出発を早めたり、暗くなる前に道を抜けたり、配達を翌日に延ばしたりしている。二つの村の荷物も同じ影響を受ける。

ふたりはその時点で修理を頼まれていない。取引を済ませ、帰るまでの時間を見て、街の周辺の塔を少し見に行こうと話す。急ぎの荷物を放置したり、最初から危険な調査を請け負ったりしない。

アリアは話を聞いてすぐ「じゃあ、見に行ってみようよ」と言う。レオンは帰る時刻から逆算して条件を挙げるが、実は取引の合間に塔への道も聞いていた。「俺も気になったから」の一言で、本人も行きたいことを出す。彼が許可を出すまでアリアが待つ構図にはしない。

**転換**：仕事の行程に小さな寄り道が加わる。動機は好奇心と、話に出た場所を自分で見たい気持ち。

### 第二章：足元の拾いもの

**狙い**：苔を、問題の原因ではなく嬉しい発見として見せる。

塔を眺め、管理人と短く話す。掃除や通常の点検では良くならないらしい。足元は湿っていて道の端もぬかるむが、この時点では最近の天候のせいにも見える。先に水路の詰まりや吸収の仕組みを説明しない。

日陰の石組みに、柔らかな光を放つ苔を見つける。アリアは珍しがり、レオンが少量を容器に寄せると手元が見えることに気づく。管理人に採ってよい場所と量を確認し、見学できる外側の群落から少し分けてもらう。ふたりも管理人も、まだ苔と塔の不調を結びつけない。

仮のやり取りは「これ、帰りに使えそう」「こぼさない入れ物がいるな」程度。章題、地の文、アイテム説明も未知の吸収能力を予告しない。

**残るもの**：即席の苔灯。初回は拾った少量を入れ物に収めた簡単な使い方で、商品や完成した発明にはしない。

### 第三章：分かれ道までの灯り

**狙い**：持ち帰って使う経験から、最初の見方が変わる。

帰りの荷物を持ち、村へ向かう。夕方の道で苔灯が足元や手元を照らす。苔が役立ったことを二人が喜ぶ時間を取る。塔の魔物除けまで持ち歩けることにはせず、必要なら普段の灯りも使える支度にする。

村々へ分かれる地点に近づく頃には、光が弱まる。レオンは採った時より暗いと気づく。アリアが覗き込むと、光に紛れていた葉の並びや色がよく見える。

「これ、森で見たのに似てる。でも、あれは光ってなかった」

この一言で章の見方を変える。正体も原因もまだ確定しない。採ったせいか、乾いたのか、それとも生えていた場所で何かが違ったのか。ふたりは荷物を各村へ届け、次に会うとき苔を見比べる約束をする。仕事を終えるために一度帰り、再訪までに時間が流れる。

**人物の変化**：別れ際に、次の交易日を待たずに会う理由ができる。謎を話したい相手が自然に相手であることを描く。

### 第四章：同じかもしれない

**狙い**：見覚えを手がかりに、ふたりが自分から調べることを選ぶ。

再び待ち合わせ、アリアがまれに苔を見た森の場所へ行く。取りすぎず、形を見比べる。暗くなった塔の苔と似ている。森の苔は同じように湿っているのに、手元を照らすほどには光らない。

塔の苔も水分を保ってみるが、強い光は戻らない。レオンが、採った場所は塔のすぐ足元だったと振り返る。湿り気だけでなく、場所から何かを得ていたのではと二人で考える。苔が光らなくなったことだけを、塔を弱めた証拠にしない。

取引先へ次の訪問予定を伝え、塔の管理人にも観察したことを持っていく。必要な道具と時間を用意し、仕事相手の協力を得て再訪する。「専門家が来るまで、分かったことを確かめてみよう」程度の引き受け方から始める。

ここでは慎重なレオンが「別の理由も調べてから」と、伝える前に説明を完成させようとして話が進まなくなる。アリアが「分からないところを聞きに行くんでしょ」と返し、二人で観察済みのことと疑問を分けて書く。レオンも考えすぎたと認め、問い合わせと再訪へ進める。アリアの一言は原因の断定ではなく、調べ始める助けになる。

**転換**：寄り道で拾った物の話が、目的を持った再訪になる。

### 第五章：石の向こう側

**狙い**：比較と現地の調査によって、原因へたどり着く。

管理人と、同じ湿り気を保った標本を塔の石組みのそばと離れた場所に分けて置く。近くの苔にだけ少しずつ光が戻る。用意できる範囲で日当たりなども揃え、塔の近くで違うものを疑う。管理人が石組みには塔の力が通っていると説明し、魔力を取り込んでいるという仮説が具体的になる。

それだけでは、この少量の苔が塔全体を弱めるかは分からない。アリアは湿った場所に沿って群落が続いていることに気づき、レオンは水の行き先と点検できる足場を探す。管理人と奥を調べると、見えていた分よりはるかに多く繁殖している。

地域の水路を知る作業者に話を聞き、嵐の倒木で排水が詰まったことが分かる。湿り気と塔の魔力が、普段とは違う量と明るさを生んだと考える。小さな魔物への対処や足場の準備は、調査を進めるための仕事として置く。

**到達**：「珍しい新種を見つけた」から「見覚えのあるものが、この場所では違う様子になっていた」へ理解が変わる。正式な分類や学名まで決めない。

### 第六章：いつもの道を戻す仕事

**狙い**：発見を実際の改善に結びつける。

管理人と取引先に調査を伝え、復旧作業の段取りと報酬・支度の協力を決める。ふたりは魔物の追い払いと現場の確認、地域の作業者は道具の準備と倒木の切り分け・排水を担当する。住民の協力は仲間加入とは別で、冒険の主役は最後までふたり。

山場は足場を確かめながら排水を戻し、石組みの奥の群落を除く作業。大木を二人だけで持ち上げたり、突然現れた強敵を倒して直したりしない。水をどこへ流すかも地域の人に確かめる。

小さな成長として、アリアは見つけた足場へすぐ移る前に「ここを確かめたい」と声をかけ、レオンは自分で全部調べ直そうとせず彼女の確認を頼る。地形や現場の判断の台詞にし、「成長したね」と本人たちに解説させない。失敗と立て直しの配分は [人物資料](characters.md) に従う。

作業後、塔の力が戻り始める。苔を塔から離した比較と、群落を除いた後の回復を合わせて原因を確認する。再発を防ぐ水路と苔の点検も管理人へ引き継ぐ。

最初は便利だと喜んだ苔なので、すべてを悪者として焼き払わない。少量を保管して使い道を考える余地を残す。ただし収集や商売を復旧より優先しない。

### 終章：灯りの戻った帰り道

**狙い**：近隣の塔の灯りが戻った喜びと、日常の回復で第一部を完結させる。

後日の交易で、以前の道を選べるようになり、取引先も荷物の予定を組み直せたと話す。管理人からは、点検を続けて灯りが安定していると聞く。街全体の盛大な英雄祭より、普段の仕事がしやすくなった実感を渡す。

帰り道、苔灯に助けられた場所を通る。今回は塔の灯りが届いている。二人は自分たちの発見が、このいつもの道を変えたことを見る。

分かれ道でふたりは振り返り、戻った塔の灯りを一緒に見る。いつもの道が明るくなったことを短く喜び、「またね」とそれぞれの村へ帰る。互いの気持ちを説明する地の文や告白には進めない。近隣の一件を解決し、普段の暮らしへ戻れたところで「第一部 完」とする。

他の土地の困りごと、新しい依頼、噂が広がる場面、人工栽培を始める業者の場面は挿入しない。第二部のきっかけは、その内容を決めるときに第二部の序章として作る。第一部の余韻を次の事件への引きで置き換えない。

## 手がかりと、その時点の理解

| 出来事 | ふたりが分かること | まだ分からないこと |
| --- | --- | --- |
| 街で塔の話を聞く | 不調が交易に負担をかけている | 原因、修理できるか |
| 塔で光る苔を採る | 珍しく、手元の灯りに使える | 魔力の取り込み、塔への害 |
| 苔灯が弱くなる | 採った時と変わった。森の苔に似ている | 同じ種類か、乾燥か、別の原因か |
| 森の苔と比較する | 湿り気だけでは明るさの差を説明しきれない | 塔との具体的な関係 |
| 塔の近くで光が戻る | 近くの力を取り込む可能性が高い | 塔を弱めるほどの量があるか |
| 石組みの奥と排水路を調べる | 豊富な魔力と湿り気で群落が増えたと考えられる | 除去でどの程度回復するか |
| 排水・除去・再点検 | 塔が回復し、再発を抑える手入れが分かる | 長期保存、安定栽培、食用や調合の用途 |

観察の答えを章題・アイテム名・ナレーションから先に知らせない。「灯りを食べるもの」という旧章題と「灯吸い苔」という旧仮称は使用しない。

## 第一部のあとにも残る設定（書き手向け）

以下は物語を後で作る際に使える材料で、第一部の終幕に表示する伏線・予告の一覧ではない。第二部の内容は未定であり、苔や人工栽培とは別の問題を扱ってもよい。

- 苔の少量の標本と、森・帰り道・塔で見た変化の記録。
- 身近な素材も環境が変われば別の様子を見せるという経験。
- 地域の仕事相手との信頼。後の物語で必要なら、取引を通じて発見の噂が他の街へ伝わる経路にできる。第一部で伝播を描写する必要はない。
- 苔灯を試しに使った経験。研究、栽培、売買の話へ進む入口。
- 同じ症状の塔でも原因は違うという、後の調査の余地。

ポピーの栽培、ルナの研究、ミラの利用、メリルの味見、利益優先の業者との対立は [世界設定の将来の種](world-and-story.md) に記録する。第一部の枝話にはせず、加入や登場の順序もここでは決めない。

人工栽培による問題を採用する場合は、「第一部の発見・解決 → その内容が噂として他の街へ伝わる → 利用を考える人が現れる → 栽培とその被害が発生する」という順になる。第一部の裏で既に同じ手法の人工栽培問題が起きていたことにはしない。何部で扱うかは未定。

## 現行ゲームとの違いと、次の制作

- 交易の出発と街への到着は [序章の物語データ](../lib/prologue-stories.ts) に実装済み。塔への寄り道、苔灯を使う帰路、別々の村への帰宅、再合流・再訪は未実装。
- 最初の薬草採取は交易路の途中の仕事として再構成できる。既存の台詞やクエスト順を維持するために、導入を再び純粋な塔見物の旅へ戻さない。
- [現行の加入条件](../lib/recruitment.ts) は新しい第一部と両立していない。実装時には第一部中に加入が起きない進行へ見直す。現在の加入順・条件・加入話は変更でき、第二部以後の順序は未定。
- 現行の共同拠点は新しい物語の冒頭から同居する証拠にしない。第一部の画面でどこを拠点として扱うか、旅団の共同生活へいつ移るかは今後設計する。
- 現行の「古塔の星喰い竜」は第一部から外す。後の配置と解放条件を見直す。既存プロフィールや台詞も必要に応じて更新できる。
- シナリオを決めた後、進行、初回と周回の違い、留守中の達成、読み返し、既存の手元の記録への対応を設計する。資料の改稿だけでゲームや保存形式を変更したとは扱わない。

## 台本に進めるときの確認

1. 出発理由は村の交易の仕事。二つの村からの合流と、帰りの分かれ道がある。
2. 塔は街の周辺にあり、その不調が街と村の行き来に影響している。
3. 薬草採取、取引、塔への寄り道の順序が自然で、預かった仕事を放置していない。
4. 最初の苔は便利な発見として喜べる。持ち帰り、灯りが弱まった後に疑問が生まれる。
5. アリアの見覚えとレオンの観察がつながり、ふたりが帰村後に再訪を選ぶ。
6. 光の減衰だけで原因を断定せず、比較、群落の調査、除去後の回復を描く。
7. 他の仲間の加入・登場を第一部に入れない。地域の人の協力で普通の冒険者にも届く解決にする。
8. 最後は戻った塔の灯りと交易・日常の改善を喜んで完結する。ふたりの好意を解説せず、他の土地や次の事件の予告も付けない。
9. アリアの思いつきだけが毎回失敗し、レオンだけが毎回正しい話にしない。準備のしすぎにも負担を置き、互いの得意な見方で立て直す。
