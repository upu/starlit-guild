# 第五章計画：回り始めるまで

章名と各場面の題は作業題。全体が制作案で、ゲームには未実装。場面の順と中身は台本を作る段階で変えてよい。ゲームの仕組みは [旅団の拠点機能](../gameplay/guild-base.md) にまとめる。発言と動作は [詳細台本](chapter-five-script.md) に書く。

[資料案内](../README.md) · [世界観](world-and-story.md) · [執筆指針](story-writing.md) · [第四章計画](story-part-4.md) · [星章院](../factions/star-badge-office.md)

## 決めた方向

ユーザーとの相談で決めた方向。

- 新しい人物は加えない。既存の五人（アリア・レオン・ミラ・フィン・リコ）を深く描く。
- 旅団を結成した直後で、まだうまく回らない話にする。各人の個性が悪い方向へ働き、初めての旅団運営であたふたする。
- 塔の事件は、依頼の山に埋もれて後回しになった一通から始まる。対応が遅れた分、塔の調査と解決は短く、難度も低めにする。
- 事件の舞台はリンデの丘の塔（第一章の塔）。塔は密集していないので、近場で新しい塔を増やさず、同じ塔が別の原因で困る形にする。近いので、返事を待ちきれない管理人が倉庫まで直接訪ねてくる。
- 旅団の等級は [星章院](../factions/star-badge-office.md) が付ける。第五章では苦情が届いていて、F級のまま上がらない。
- 旅団の拠点機能（菜園・作業台・旅団タブ）を、この章で導入する。アイテム枠と消耗品は、第一章から使える形で先に実装済み。

## 制作担当が置いた案

相談で決めていない部分。

### 旅団になって悪化する癖

第二章以後の方針どおり、欠点を克服させない（[執筆指針](story-writing.md#第二章では人物のとがりを保つ)）。章末でも性格は直らず、役割分担と決まりごとで旅団が回り始める。第四章4-10の代表者決めの場面で予告した癖を回収する。

| 人物 | 旅団になって悪化する癖 | 実害 |
| --- | --- | --- |
| アリア（代表） | 話を聞き終わる前に「任せて！」と受ける。代表の名前で受けたので、断りにくい | 同じ日に依頼が三件重なる |
| レオン（副代表） | 受付帳の書式と確認事項を作り込み、「念のため」の備品も買い込む。段取りを一人で抱える | 受付が遅れる。書式の合わない手紙が保留箱に溜まる |
| ミラ | 旅団の依頼に往診を混ぜる。自分で決めた「依頼には受付を、皆には休みを」を最初に破る | 休みの日にも「あと一件だけ」と出かける |
| フィン | お金は持たされていないが、「星灯りの旅団」の名前でツケが効くと気づく | 代表者宛ての請求書が本当に届く。宛先ができたので、取り立ての人も倉庫へ来る |
| リコ | 依頼は解いても、答えだけ言って帰る。倉庫で実験する。預かり品を試料として気にし、手紙の裏紙を試料の札に使う | 井戸の依頼人から苦情が出る。煙と臭いで倉庫の大家からも苦情が出る |

### 依頼が埋もれた経緯

誰か一人の責任にせず、全員の癖が少しずつ重なる。

1. アリアが依頼を受けすぎて、倉庫はいつも手紙と依頼人で慌ただしい。
2. 管理人の手紙は旅団宛てではなく二人宛てだった。手を洗ったレオンが封を切ったところで依頼人に呼ばれ、便箋を封筒に重ねて保留の箱のふたに置く。二人は「戻ったら読もう」と言ったまま、その日の仕事に追われる（[詳細台本の5-5](chapter-five-script.md#5-5-念のための受付帳)）。
3. 数日後、そのふたの上にフィンのツケの請求書が重ねられる。
4. 箱の脇に落ちた空の封筒を、リコが試料の札に使う。便箋は請求書の下に残る（[詳細台本の5-8](chapter-five-script.md#5-8-保留箱の一通)）。

直接の原因はレオンとアリアの「あとで」だが、全員に同じ重さの落ち度を割り振らない。ミラは原因でなくても、一緒に謝る仲間として並ぶ。

### 塔の原因：光の取り込み口をふさいだ鳥の巣

塔ごとに原因を変える方針（[世界観](world-and-story.md#制作の核)）に沿う。第一章の排水路と苔、第三章の要の石の売買、第四章の人の手による苔の栽培とは違い、動物が構造物をふさいだ型にする（[第一章以後へ残す種](world-and-story.md#第一章以後へ残す種)の「違う原因の塔」）。

- 塔は夜の光を取り込んで蓄える（[星灯りの塔](world-and-story.md#星灯りの塔制作案)）。高い位置にある光の取り込み口へ鳥が巣を作り、取り込む光が減って、灯りが少しずつ弱った。
- 管理人は第一章の経験から、排水路と苔を先に点検している。原因がそこにないと分かったうえで、旅団へ手紙を出した。上の取り込み口を疑ってはいたが、梯子は一人で掛けられず、収穫の時期で押さえる人も見つからなかった。その間、夜の荷には日のあるうちに通るよう頼んで回っていた。管理人を無能にしない。
- 巣立ちまでは、巣に触れずにはみ出した枝だけを寄せ、取り込み口の半分を空ける。管理人の見立てでは、それで少なくとも曲がり角まで灯りが戻り、夜の荷を元の道に戻せる。塔は夜の光を蓄えるので、戻るのは処置をした夕方ではなく、夜を越えてから。
- 苔は原因ではない。リコは管理人の記録を認めたうえで、塔のそばで苔が増えないときの数字を自分の研究として調べる。第一章の原因を再発させない。
- 巣には卵がある（または雛が育っている）ので、壊さない。巣立ちまでの間の対処と、別の巣箱へ移ってもらう段取りで解く。鳥の種類は未設定。
- 戦闘は、灯りが弱まった街道に出る魔物の分だけにする。短く、難度を低めにする。
- 古い管理図には、今の地図にない細い道が一本、塔の裏から森へ描かれている。塔の上から見ると、森の中にも切れ目が続いている。誰が作り、どこへ続くかは答えない。レオンの「地図の端の先を歩いてみたい」という希望の行き先にし、世界への興味を残す。

### 既存の人物を深める

人物資料の「人物を深める軸」にある、まだ使っていない手札を使う。

- **アリア × レオン**：アリアの軸「レオンの行きたい場所を自分から聞く」（[アリア](../characters/aria.md#人物を深める軸)）。副代表として段取りばかり引き受け、自分の希望を言わないレオンに、代表のアリアが「レオンは、どこ行きたいの？」と聞く。レオンの「背負いすぎる備え」（[レオン](../characters/leon.md#背負いすぎる備え)）とつなげる。最後の一歩はレオンから出す。「道を知ってる人を、探してたわけじゃない」と同行をアリアに頼み、誰とでもいいわけではないことを一つ進める。告白・交際には進めない。
- **ミラ × フィン**：ミラの軸「フィンが気づき、いたずらめいた理由をつけて休ませる」（[ミラ](../characters/mira.md#人物を深める軸)）。フィンが受付帳に偽の依頼（お茶会の立ち会いなど）を書き、休みの日のミラを座らせる。嘘をつく手癖が、珍しく人のために働く。お説教の途中でミラが眠ってしまい、いつもは逃げるフィンがその場に残る。台詞で優しさを説明せず、普段の癖との差で見せる。ミラの癖は治らない。
- **フィン**：「各地で待っている人」は取り立て人（[フィン](../characters/finn.md#情報の集め方)）。旅団に宛先ができたので、取り立てが倉庫に届く。第四章の「宛先」の裏返し。
- **リコ**：「ありがとう」「一緒にいたい」が言えない（[リコ](../characters/lico.md#人物概要制作の核)）。旅団にいていいのかを、研究の話でしか確かめられない。5-5で実験を止められたとき、出ていくものと思って道具を鞄にしまい始め、アリアの「裏なら、置きっぱなしにできるね」で蒸留器だけ出し直す。5-12の「来月の分も、ここに書いていい？」で、来月もここにいるつもりが漏れる。菜園を任されることが居場所になる。
- レオンがミラを呼び捨てにする時期は、後の章の手札として残る（[レオン](../characters/leon.md#慣れない相手には敬語丁寧語)）。この章で使うかは台本の段階で決める。

## 場面ごとのピンチと見せ場

第四章と同じく、誰かの癖で困り、その場にいる別の人の得意で切り抜ける（[第四章計画](story-part-4.md#場面ごとのピンチと見せ場)）。旅団を立ち上げたばかりの章なので、困りごとは町の中の小さな失敗が中心。代償は、苦情・信用・時間・二人の午後のような身近なものにし、大きな危機にはしない。

| 5-9 | **リコ**：塔のそばで苔が増えないときの数字に夢中になり、朝の時間を斜面で使う。**アリア**も付き合う | 上を調べるのが昼過ぎにずれる | **アリア**が石畳の羽根と、上から吹く草の匂いに気づく。**レオン**が管理図で取り込み口と、図にだけある細い道を見つける。**管理人**が、枝を寄せて半分空ければ曲がり角まで戻るという見込みを示す。リコの数字はブレッカへ送る記録になる |
| 5-10 | **レオン**：念のため頑丈に作り込んだ巣箱が、梯子では抱えにくい。猫よけに小さくした穴は、鳥にも狭い | 巣箱を作り直す手間がかかる | **アリア**が親鳥の出入りの間隔を読み、留守の間だけ作業する。**リコ**が軽い滑車を組み、**フィン**の手先で巣に触れずに枝を網で留め、取り込み口の半分を空ける。**レオン**は穴を測って巣箱を作り直す。灯りは夜を越えてから戻り、**リコ**が夜通し紫の変わり方を記録する |
| 5-11 | **レオン**：受付帳・日程・備品を一人で抱え込む。塔に登った日も、巣箱が落ちないかばかり見ていた | 疲れがたまり、アリアと約束した午後にも帳面を開く | **アリア**が代表として段取りを分け直す。ミラの構文を借りて「帳面には休みを、レオンには行きたい場所を」と返し、「レオンは、どこ行きたいの？」と聞く。レオンは塔の上から、管理図にあった細い道の先を見たいと答え、「道を知ってる人を、探してたわけじゃない」と、同行をアリアに頼む |
| 5-12 | 全員：癖は直らない。依頼がまた一度に届く | アリアはまた即答しかけ、ミラは抜け出しかけ、フィンは別の抜け道を探す | 5-11までに決めた**受付帳の決まり**が働く。受けるかはアリア、日程はレオン、ミラの休みは当番表、ツケは禁止、リコの作業は倉庫裏。仕組みで回り、窓口の苦情が止む |

- 短所が好都合に働いたことにはしない。5-5のアリアの即決は、レオンが書く役に回ったから成り立つ。5-7のフィンの偽の依頼も、見つかって叱られ、帳面から消される。
- 注意された直後にまた失敗する流れを続けない。癖は、得意なことに夢中になる場面として見せる（5-2のリコの見立てと言葉足らず、5-9のリコの計測、5-10のリコの夜の記録）。5-2のリコは失敗したのではなく、解いた中身を伝えていない。
- 一章で癖が治ったことにしない（[執筆指針](story-writing.md#第二章では人物のとがりを保つ)）。5-12でも全員の癖は残り、決まりごとで回る。
- 5-8の埋もれた手紙の直接の原因は、レオンとアリアの「あとで」。フィンの請求書とリコの札も重なるが、同じ重さの落ち度にはしない。ミラは原因でなくても、一緒に謝る。
- 5-11でアリアがミラの構文を借りるのは、第二章でアリアがミラを休ませた「私たちは受け取りを、ミラは休息を。」（[第二章の台本](game-script/chapter-2.md)）を、今度はレオンに向ける形。構文の正本は [ミラ](../characters/mira.md#口癖決め台詞構文)。

## 章末の着地

性格は直らない。代わりに、倉庫に決まりごとが増える。

- 依頼を受けるかどうかは代表のアリアが決め、日程は副代表のレオンが組む。アリアはそれでも即答しかける。
- ミラの休みは、ほかの人が当番表に書き込む。ミラはそれでも抜け出そうとする。
- 旅団の名前でのツケは禁止。フィンは別の抜け道を探す。
- リコの作業場所は倉庫裏。煙は減るが、なくならない。
- 等級はF級のまま。苦情が止んだことを窓口で聞く程度に留める。

## 守ること

- 新しい人物を仲間にしない。地域の人（倉庫の大家、窓口の受付の人、第一章の管理人、取り立ての人など）は役名で出せる。[メリル](../characters/merrill.md)が菜園の作物を食べに来るのは、任意の日常会話の候補。
- リンデで光る苔を育てない。塔のそばで苔を増やすのは第四章の事件そのもの。光る苔は、塔から離れたブレッカの苔床で育てる（[第四章計画](story-part-4.md#4-10-同じ宛先へ)）。
- 塔の知識で何でも解ける集団にしない。管理人の点検と記録を尊重する。
- アリアとレオンの好意を、ほかの三人に代弁させない。
- リンデは連絡と作業の拠点で、共同生活の場にしない（[第四章計画の拠点](story-part-4.md#拠点)）。
