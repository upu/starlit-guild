# 世界観と物語の設定資料

書き手向けの制作資料。公開済み第一章で確定した事実と、第二章以後の制作案を分けて扱う。

人物の口調・関係性は [キャラクター設定](../characters/README.md)、場面の書き方は [物語・会話の制作指針](story-writing.md)、公開済み第一章の出来事は [第一章プロット](story-part-1.md) を参照する。世界と素材の共通ルールは本書を正とし、変更時は関連資料も整合させる。

## 設定の状態と見直し方針

| 区分 | 扱い |
| --- | --- |
| 制作の核 | 今後の物語でも守る方向。変更する場合は関連資料と実装を揃える |
| 制作案 | 核を具体化するために制作担当が置いた設定。ユーザーが個別に確定した事実とは区別する |
| 将来の種 | 後の話に使える案。発生時期・登場人物・結末は固定しない |
| 公開済み | ゲーム内で起きた出来事。後の物語はこの事実から続ける |

第一章はアリアとレオンのふたりだけで進み、近隣の塔と街道を復旧して完結した。[第二章計画](story-part-2.md) ではミラを最初の新しい仲間にし、[第三章計画](story-part-3.md) ではフィンを迎える。[第四章計画](story-part-4.md) ではリコを迎え、旅団を結成する案とする。その先の加入順は未定であり、従来記録の依存順序を新しい物語の固定条件にはしない。

資料の更新とゲームの更新は別の作業。制作案は、会話・クエスト・表示条件へ実装されるまでゲーム内で起きた出来事として扱わない。

## 制作の核

- アリアとレオンは近くの別々の村に住む。子どもの頃、村どうしの取引の場で繰り返し顔を合わせ、仲良くなって一緒に遊ぶようになった。
- 青年になった現在は、それぞれの村の仕事で少し遠い街へ取引に行くとき、一緒に道を行く仲。家や村が同じだから常に一緒なのではなく、会う場所と次に会う予定がある。
- 導入は村の仕事としての街への交易。道中で薬草を採るなど、暮らしに必要な仕事と小さな寄り道を重ねる。
- 最初の塔は交易先の街の周辺にある。その力が弱まり、街と近隣の村の行き来がしにくくなっている。
- 街で塔の不調の話を聞き、仕事のついでに「少し見に行こう」と寄り道する。最初から塔の修理や世界の救済が目的ではない。
- 第一章の冒険を進めるのはふたりだけ。他の仲間の加入や、既存キャラが解法を教える場面を置かない。仕事相手や塔の管理人など、地域の人との交流・協力は描く。
- 最初の苔は珍しくて便利な発見。持ち帰る苔灯が弱まり、アリアが森で見た苔に似ていると気づくことから、塔との関係を疑い始める。
- 塔が力を失う理由は塔ごとに違う。同じ討伐や素材集めだけで解決しない。
- 第一章は一般の冒険者にも対処できそうな規模。竜討伐、伝説の武器、覚醒した力を解法にしない。
- 第一章は近隣の塔の灯りと往来が戻った喜びで完結する。隣の土地の困りごとや次の事件の予告は不要。第二章の導入は第二章側で描き、公開済み第一章の終幕へ追加しない。
- ふたりだから気づける違和感は、観察する対象と日々の経験の違いから生む。住民の知識と合わせて調べ、村人を無能にして主人公を持ち上げない。
- 塔に害を与える素材にも価値や用途がある。後の話では、撤去したい人、利用したい人、利益のために増やす人の違いを扱える。
- メリルは珍しいものの噂を聞くと食べられるか確かめに行く。この絡みは第一章以後へ置く。
- 幼なじみふたりの親しさと言い切れない好意を制作の核とする。細部は物語に合わせて具体化する。

## ふたりの暮らしと地理

### 村、街、塔の関係

アリアの村とレオンの村は近隣にある。村どうしの取引の場が幼少期の接点で、現在の街への取引はそこから少し行動範囲が広がった仕事。二つの村の取引先は共通の街で、道の途中で合流して一緒に向かえる。街の周辺の塔が弱まると、両方の村の交易にも影響する。

街道の分かれ道で待ち合わせ、帰りはそこから別々の村へ帰る。目印の形、村名、街名、所要時間は未設定。「明日またここで」が実際の待ち合わせを意味する関係にする。

最初の塔は街の外れの丘にある。塔の周辺では、詰まった排水路が湿った場所を作っていた。

### 青年になったふたり

各村での友人関係と幼少期からの交流は、[二人の関係性「村の友人と、二人の特別な距離感」](../relationships/aria-leon.md#村の友人と二人の特別な距離感) を正本とする。ゲーム内には出さない背景設定として扱い、村の人口や住民構成の詳細とは分ける。

- 交易では村の品を届け、代金や頼まれた物を持ち帰る。担当する品物・家族の職業・初めて任された年齢はまだ固定しない。
- アリアは道中の薬草や植生を見るのが得意。採取は仕事のついでにできる範囲で行い、預かった荷物を放り出す行動にしない。
- レオンは荷物、道順、足場、帰路の段取りに目が向く。彼にも街で見たい物や寄りたい場所がある。
- アリアは考え終わる前に感想や思いつきが口・行動に出やすい。レオンはそのフォローに慣れ、元からの慎重さが強まり、準備しすぎることがある。長所と失敗、互いへの甘え、成長の扱いは [二人の関係性](../relationships/aria-leon.md#ふたりの性格を動かす仕組み制作案) を正とする。
- 子どもの頃の遊び仲間が、今は仕事を互いに頼れる相手になっている。恋愛については、会う理由がいつも仕事なのか、仕事がなくても会いたいのかという余白を使える。
- 宿泊が必要な距離かどうかは今後決める。旅団の結成と拠点は [第四章計画](story-part-4.md#旅団の結成と代表者決め) の制作案で扱う。第一章冒頭から同居や共同生活を前提にしない。

### 種族などの制作案

アリアはエルフ、レオンは人間として構成する案を継続する。現行プロフィールでは種族は明記されていない。他の人物の種族まで一括して推定しない。

エルフは成人する頃までは人間に近い速さで育ち、その後ゆっくり年を取る案。具体的な年齢・寿命は未設定。近隣の別の村に住む理由を、種族間の敵対や隔離と即断しない。各村の住民構成も未設定。

ドライアドは草木の精。種族としての設定は次の二点を採用する（メリル個人の設定は [メリル](../characters/merrill.md#ドライアドとしての設定) を参照）。

- 本来は食べなくても生きられる。根や体で水を、葉や髪で光を取れば足りる。食事は好みであって、生きるための必要ではない。
- 本体の木とのつながりは緩く、故郷に木を残して出歩ける。どこまで離れられるか、木が傷んだり倒れたりしたときの影響は未設定。

寿命・年齢の数え方、数や住む場所、エルフなど他の種族との関係は未設定。種族どうしの敵対は設定しない。光をためた植物を食べて平気かどうかも、ドライアド全体へ一般化しない。

子どもの頃に塔へ行く約束は設定しない。髪紐を贈った日や初めて遊んだ日の詳細も未設定。

## 星灯りの塔（制作案）

塔の存在と街道を守る役目は、アリアとレオンを含む地域の人々に知られている。第一章1-3では塔そのものを初めて教わるのではなく、街の仕事の不便を聞いた二人が見慣れた塔を見上げ、光が以前より弱いことに気づく。内部の仕組みや今回の不調の原因まで周知されているとはしない。

塔は周辺の街道を照らし、魔物が寄りつきにくくなる力を持つ。完全な防壁ではなく、明るい街道でも護衛は必要。弱まると迂回や早めの出発が必要になり、荷物の輸送や日々の往来に負担が出る。

塔は夜の光を取り込み、内部の石に蓄え、少しずつ周囲へ放つ案。曇天一晩で止まるものにはしない。強い魔力が流れる部分は足元の石組みにも続いている。第一章はこの力と周辺環境の関係までを扱い、古代技術の全容を説明しない。

塔の灯りは紫系とし、火や普通のランタンの暖色とは見分けられるようにする。第一章1-9の復旧直後は窓の中にほのかな紫が戻る程度。強い光線や道全体を照らす輝きにはせず、蓄えが戻る時間を置く。数日後のエピローグで街道へ届く灯りを描く。苔灯の発光色まで一律に変更する設定ではない。

管理人は通常の掃除や点検を行い、専門家への相談もしている。光る苔の存在を見ただけでは、塔の不調の原因と分からない。苔は石組みの奥で広がり、外に見えているのは一部という案。普段は問題を起こさない生物と環境の組み合わせが、通常の点検範囲から外れていた。

一塔の復旧は、その周辺の街道を改善する。全世界の塔が同時に直る仕組みにはしない。後の物語で範囲を広げる際には、仕事相手の紹介や商人の評判を使えるが、第一章の末尾にその予告は置かない。

## 淡光苔（制作上の仮称）

### 通常の姿と、塔のそばの姿

正式な呼び名や分類は未定。性質を先に明かす名称は使わず、発見時は「光る苔」、持ち運ぶ使い方は「苔灯」と呼ぶ。

森でまれに見かける苔と同じ種類が、塔のそばの条件で変化したものと考えられている。新種の発見とは確定しない。アリアも最初は「似ている」としか言えず、見比べて同じ種類ではないかと考えた。

| 項目 | 通常の森 | 最初の塔のそば |
| --- | --- | --- |
| 生える場所 | 湿った場所にまばらに見られる | 排水不良で湿り気が長く続く石組みの周辺 |
| 魔力の取り込み | ごく弱く、周囲へ目立った影響はない | 強い魔力が近くにあり、取り込む働きが活発になる |
| 成長 | 小さな群落で、めったに見かけない | 水分と豊富な魔力が重なって繁殖が進む |
| 見た目 | 普段の明るさでは発光を見分けられない。アリアの記憶では「光らない苔」 | 日陰でも気づく柔らかな光。採った少量を寄せると手元の灯りになる |
| 塔への影響 | 通常は問題にならない | 石組みの奥まで増えた群落が力を取り込み、塔を弱める |

「光らない」と「ごく弱く光る」は視認条件の違いとして扱い、種族だけに見える特殊な光にはしない。強い魔力のもとで取り込みが活発になるのは環境への反応という案で、突然別種へ進化したとは決めない。

### 持ち帰って分かる性質

- 吸った魔力をしばらく保持するため、採ってもすぐには光が消えない。灯りに使ううちに蓄えが減り、帰村する頃には見た目の印象も変わる。
- 光が落ち着くと、葉の並び、色、枝分かれなどが見えやすくなる。ここでアリアが森の苔との似かよりに気づく。特徴の具体的な造形は台本・絵で揃える。
- 暗くなっただけでは「魔力を吸う」証拠にならない。枯れた、乾いた、採ったため変化したという別の説明もあり得るため、再訪して条件を比べる。
- 水分だけ戻しても強い光は戻らない。同じ湿り気で塔に近づけた標本と離した標本を比べると、近くのものに光が戻る。そこで塔から何かを取り込んでいるという仮説が強まる。
- 少量を採っただけでは塔の明るさは大きく変わらない。石組みの奥の群落を調べ、排水と除去を進めた後に塔が回復することで、影響を確かめる。
- 取り込める量と保持する時間には限界がある。遠方から無制限に魔力を奪ったり、無から力を作ったりしない。採って塔から離した苔の光は、その晩のうちに弱まり始め、一日ほどで抜ける目安とする。正確な時間や量の数値は未設定。
- 光をためた植物に共通する苦味を持つ。苔の味と加工による残り方は [光をためた植物の苦味と加工](#光をためた植物の苦味と加工制作案) を正とする。
- 苔灯は手元を照らす道具。塔の魔物除けまで小型化して持ち歩けると決めない。

### 最初の塔での原因と対処

第一章の因果は、嵐の倒木による排水路の閉塞 → 湿潤化 → 塔の強い魔力との組み合わせで繁殖と吸収が活発化 → 塔の力の低下。事故は自然発生であり、後の業者の仕業へ遡及変更しない。

対処は、水の行き先を確かめて排水を戻し、石組みの奥の群落を除き、管理人へ点検を引き継ぐ。苔を剥がすだけでは再発する。通常の森の群落まで全滅させる必要はない。

### 第一章以後の用途と利害（将来の種）

素材そのものが悪いのではなく、増やす場所と量、被害を知った後の行動で利害が分かれる。

| 人物・立場 | 関心と使える場面 |
| --- | --- |
| 地域の人・管理人 | 街道の回復と再発防止を優先する。灯りに使うなら管理方法を相談したい |
| リコ | 発光と毒の研究のため、苔を増やして自分で確かめる。第四章の制作案では、噂を聞いて塔のそばで苔を増やした悪気のない張本人。被害を知ると後始末に取りかかる（[人物資料](../characters/lico.md#第四章での役割制作案)） |
| ルナ | ふたりの記録を起点に、取り込みと光の仕組みを観測する案 |
| ミラ | 往診用の灯りなど暮らしへの用途を考える案。未知の苔をすぐ患者へ投与しない |
| メリル | 珍しいものの噂を聞いて食べに来る。比較用の標本まで狙い、周囲を困らせる |
| 利益優先の業者 | 栽培費を浮かせるため、塔の力を無断で使って群落を育てる。被害を承知で利益を取る。第四章の制作案では、リコが増やした苔を買い取り、抜ける前に加工して売る商人とする |

第二章以後の案であり、第一章の任意イベントとしても登場させない。誰がいつ加入するか、研究を始める前からの知り合いかなどは未定。既存の加入動機や関係も新しい物語に合わせて変更できる。

「第二章以後」は第一章に入れないという範囲の指定であり、第二章に採用するという決定ではない。第二章では苔や人工栽培とは別の問題を扱ってもよい。

### 人工栽培問題を採用する場合の時間関係

第一章で苔と塔の関係が判明し、一件が解決する。その発見が噂として他の街へ伝わった後、利用に目をつけた人が栽培を始め、問題が発生する。この順序を守る。

人工栽培問題を第一章より前から続く事件や、第一章の事故を起こした陰謀にはしない。噂の伝播、栽培の開始、問題の発生を第一章の終幕で予告する必要もない。[第四章計画](story-part-4.md) で、リコの苔床と醸造所の商人の案として採用する。

## 光をためた植物の苦味と加工（制作案）

淡光苔と[月光を蓄える薬草](#月光を蓄える薬草)に共通する性質。石は対象に含めない。

- 光（塔の星灯や月光）をためた植物は苦い。ためた量が多いほど苦味は強く、塔のそばで育った苔は森の苔よりずっと苦い。森の苔の味は穏やかという案。
- 摘んだ後は光と一緒に苦味も抜けていく。淡光苔の目安は一日ほど。月光を蓄える薬草の保持時間は未設定。
- 抜ける前に加工すると、光は消えても、味や薬効は加工品に残る。乾燥、煮出し、調薬、酒などへの仕込みといった、一般的な手順を想定する。特定の加工法や職人だけの秘術にはしない。
- そのため、光をためた植物の価値は光そのものより、加工後に残る味や薬効に置ける。加工品が光ったり、塔の力を持ち歩けたりはしない。
- 光をためた植物を扱う者には、摘みたてを抜ける前に加工する段取りが要る。採取から加工までの距離と時間が、仕事や商売の条件になる。
- 第二章の薬が苦く、[薬用の蜜](#薬用の蜜)で飲みやすくする描写と合う。ただし、第二章の場面に苦味の理由を説明する台詞を後から加えない。
- 食べて平気かどうか、どこまで食用にするかは種族や人をまたいで一般化しない。苦味の強さの違いは手がかりになり得るが、味見だけで事件を解かない。
- 薬効は基本的に体によい働きとする。ためた量が多いほど苦味と一緒に効き目も強くなり、塔のそばで育ったものは、病み上がりや年寄りなど弱っている人には強すぎることがある。強すぎると、胃が受け付けずに食べられなくなる。夜の光をためた植物は目を冴えさせ、眠れなくなる。倒れるほど急ではなく、弱っている人ほどじわじわ弱っていく。毒ではなく、薬と同じく強さと相手の問題として扱う。
- 苦味や薬効の具体的な強さ・効能、加工ごとの残り方の差は未設定。

## 第二章で見せる自然と道具（制作案）

[第二章計画](story-part-2.md) を具体化する案。世界特有の仕組みを出来事で紹介する方向は制作の核とし、各要素の実装状況は [第二章のゲーム実装](../gameplay/chapter-two-gameplay.md#実装状況) を参照する。

### 月光を蓄える薬草

薬草の中には、浴びた月光を蓄え、それを薬の働きに利用できるものがある案。同じ草でも採取する場所や状態によって用途が違う。アリアは植物と採取、ミラは調薬を知り、片方だけで全ての説明を済ませない。採った草を実際に調薬し、届けた先で使う場面までを通して性質を伝える。

第一章の苔と同じ種類とはしない。光をためた植物として苦味を持ち、抜ける前に調薬すれば薬効が残る。共通の性質は [光をためた植物の苦味と加工](#光をためた植物の苦味と加工制作案) を正とする。薬草名、月の満ち欠けや時刻による違い、保持時間、具体的な効能は未設定。採取に現実の夜間ログインが必要な仕組みや、月光だけで全ての傷病を治せる能力をこの案から追加しない。

### 薬用の蜜

第二章で運ぶ、この土地で薬に使われる蜜。蜜自体に喉の痛みを和らげる薬用効果があり、苦い薬を飲みやすくする役目も持つ。薬草や診察を不要にする万能薬ではなく、飲んだ瞬間に全ての患者が治る描写にはしない。固有名、蜜の採取元、具体的な配合・効果量は未設定。

[第二章計画](story-part-2.md) では2-3で瓶ごとに包み、病気の子たちへ届ける用途を先に伝える。休憩用の菓子とは別の配達品。プティに奪われた蜜を回収し、2-8で薬草から作った薬とともに届け、ミラが使い方を家の人へ説明する。

### 運搬用ゴーレムと蓄える石

この地方では、魔力を蓄える石が運搬用のゴーレムにも使われてきたという案。住民には仕事道具として見覚えがあり、世界で初めて現れた未知の兵器にはしない。プティは古い運搬用の体を大きな人形として使う。操り方、所有者や入手経緯、石の補充方法は未設定で、全てのゴーレムを無条件に支配できるとは決めない。

第一章で見た「取り込み、蓄える」性質が自然だけでなく生活の道具にも広がる。塔と完全に同じ技術・効率・用途だと断定せず、無限の動力や塔の魔物除けの持ち運びにはしない。

その石に第一章の塔と似た印を置く案は第二章で扱わず、[第一章以後へ残す種](#第一章以後へ残す種) に移した（[Issue #78](https://github.com/upu/starlit-guild/issues/78)）。第二章で印の由来は解かず、薬の配達と通行妨害には決着をつける。

## 第三章で見せる自然と道具（制作案）

[第三章計画](story-part-3.md) の共通設定。実装状況は[第三章の実装仕様](../gameplay/chapter-three-gameplay.md#実装状況)を参照する。

### 蓄える石の三つの段階

石は苔や植物より星灯を多く、長くため込める。塔のそばで過ごした年月や大きさ・個体差によって、離した後の光り方と持続時間が違う。

| 段階 | 性質 | どこにあるか |
| --- | --- | --- |
| 採石場の石 | ごく弱く星灯を蓄える。単体で街道の安全は担えない | この地方の地層。第二章の運搬用ゴーレムの石もここから採れる |
| 塔の周辺の石 | 塔の力を受け、星灯を多くためて放つ。塔から離しても数か月〜数年光る | 古い庭石・石畳・壁など。すべてが塔の設備ではない |
| 塔の要の石 | 周辺の石と見た目は似るが、塔を構成する石。取り外すと塔が弱る。詳しい仕組みは分からない | 塔そのものと、それに続く古い石組みの要所 |

周辺の石は取り外した直後に暗くなるわけではない。商人や住民は長く使える灯りとして売買しており、数年使った実物や保管の記録もある。時間がたつと蓄えが減り、灯りは弱くなる。持続期間を一晩の比較実験だけで断定しない。再び塔の近くに置く場合の必要な期間や、繰り返せる回数は未設定。

塔の要の石がなぜ別格なのか、製作者や全体の仕組みは第三章でも解かない。外して庭の灯りにしても光るため、売り手・仲介人・買い手は普通の周辺の石との違いに気づかなかった。形や古い図面、元の位置と照合して、戻すべき石を特定する。

### 石を敷いた街と、その塔

第三章の舞台は、石畳の街ベルネ。街の足元には、塔から続く古い石組みが埋もれている。古い石畳や壁は長年の星灯をため、通りを照らしている。石畳を外せば、その区画は暗くなる。

第三章で塔全体が急に弱る直接の原因は、後世の石段を片づけた際、その下の古い石組みの要の石まで普通の建材として売られたこと。管理人の設備図と街の区画図、石工の撤去記録を結び直して、元の場所を特定する。石工は継ぎ目と石の組み方から、その場所が庭や道ではなく塔の一部だと見抜く。管理人は撤去と不調の時期から関係を疑うが、石が力をどう扱うかまでは知らない。管理人も石工も既に調べており、無能にして主人公を持ち上げない。

売り手は生活のため、買い手は長く光る庭石を欲して売買した。必要な要の石を、用途と見た目の合う周辺の石へ無断ですり替えて戻す。買い手は元々望んだ灯りを得て満足し、より貴重な品だったと知らなければ違いに気づかない。交換用の石は、塔・道の機能から独立した場所から外されて保管された物を正当に入手する。別の場所を暗くして帳尻を合わせない。

復旧には地域の人も参加する。要の石を戻しても蓄えはすぐ満ちず、塔の灯りは徐々に戻る。通りの石も必要な箇所から戻し、売れる保管石と残すべき石を区別する。売買を全面禁止にはしない。

塔の固有名、採石場の規模、正確な蓄積速度・寿命は未設定。装備へ石を嵌める案は白紙のままとする。

## 第一章以後へ残す種

書き手が保管する候補。第二章のプロットや第一章の予告として確定したものではない。

- **暗い苔と観察メモ**：交易荷物と一緒に持ち帰った素材が、後に研究や暮らしの道具につながる。
- **比較用の皿**：リコの苔をメリルが両方食べようとする。珍しい苔の噂を来訪の理由にする。
- **整列した苔**：第一章の発見が他の街へ噂として伝わった後に発生し得る案。別の土地で等間隔の群落と掘り直された水路を見つけ、人為的な栽培を疑う。第一章の自然発生との差が手がかりになる。
- **苦味の商い**：塔のそばで育てた苔を、抜ける前に酒の苦味付けや薬へ加工して売る案。摘みたてを毎日届ける必要が、塔のそばに苔床を並べる動機になる。採用する章・人物は未定。
- **味への不満**：メリルが「前の苔より油くさい」とこぼす案。薬剤や故意の被害の断定には別の証拠を置き、味見だけで事件を解かない。食用かどうかは種族をまたいで一般化しない。
- **違う原因の塔**：苔の生えていない塔、動物が構造物を塞いだ塔、補修や土地利用の事情で止まった塔。全塔を苔や同一組織のせいにしない。
- **取引先の先**：利益優先の一業者との対立が、別の取引や土地へつながる。組織名・首領・最終目的は未定。マッドハロウィンとの関係も必要に応じて検討し、自動的に同一組織としない。
- **後に残す印の似かより**：ゴーレムの石に、第一章で使った塔の管理図のものと似た印を置く案。第二章では扱わず、第三章以降で扱う候補として残す（[Issue #78](https://github.com/upu/starlit-guild/issues/78)）。採用する場合も、帰ってから実際に記録を見比べてレオンが気づく短い任意会話に留め、「似ている」より先へ進めない。第一章でその印をプレイヤーが既に見たことにはしない。プティは動かすことに詳しくても印の由来に関心がない、という温度差を使える。共通の製作者、古代文明、塔の全体構造、陰謀の存在は未設定で、伏線のために第一章の原因や公開済みシーンを書き換えない。

塔の総数、世界地図、最終敵、全体の結末は未設定。範囲が世界へ広がっても、各地の暮らしを知り、観察して調べる姿勢を残す。
