# 本編の全体構想

[資料案内](../README.md) → [世界観・シナリオ](README.md) → 本編の全体構想

今作の本編全体の流れを検討する資料。章のプロットより上の段階で、物語の芯・方向・候補・未決事項を置く。章割り、場所・行路、加入順、ステージ番号、クエストID、シーンID、ゲームシステム、セーブ仕様は扱わない。

**ここにある内容は、現行設定やゲーム内で起きた出来事ではない。** 世界・人物の正本や章のプロット、公開済みの出来事を置き換えず、候補をまとめて採用する根拠にもしない。次世代の主人公や後世の伝承を扱う続編は対象外で、続編案から今作の人物の生死・婚姻・子孫・年数を逆算して決めない。

## 区分と正本との分担

本書では次の区分で書く。各節の見出しや表で区分を示し、本文で繰り返さない。

| 区分 | 扱い |
| --- | --- |
| 方向 | ユーザーと共有した本編の方針。既存資料の「採用済み」ではなく、具体化して正本へ移すときに確定させる |
| 好みの展開 | ユーザーが好みとして挙げた展開。どれを採るか、順序や因果は未決 |
| 候補 | 方向を具体化するための制作側の案。採用は必須ではなく、別の案へ進んでもよい |
| 未決 | まだ決めていないこと。空欄を埋めるためだけに推測で決めない |

具体化して採用した内容は、次の正本へ移す。本書には方向と未決だけを残し、同じ本文を本書と正本の両方で維持しない。

| 内容 | 正本 |
| --- | --- |
| 星の力の仕組み、塔・素材の共通ルール、種族の文化 | [世界観と物語](world-and-story.md) |
| アリアの由来・能力・家族、各人物の設定 | [キャラクター](../characters/README.md)（アリアは [aria.md](../characters/aria.md)） |
| アリアとレオンの関係 | [アリアとレオン](../relationships/aria-leon.md) |
| 出来事の順序と場面 | 各章のプロット（[世界観・シナリオ](README.md#章の資料)） |
| 実装状況 | [ゲーム仕様](../gameplay/README.md#章ごとの実装) |

既存の物語へつなぐときは、次の軸を変えない。根拠と詳細は各正本を読む。

- 第一章は村の交易の仕事と寄り道から始まり、原因は自然発生。家族捜索や世界救済の導入、後の敵の陰謀への遡及変更、終幕への予告の追加をしない（[第一章プロット](story-part-1.md)、[制作の核](world-and-story.md#制作の核)）。
- アリアの観察・採取・好奇心と「見つけたものを、一緒に見たい」という軸を特別な力に置き換えない。明るさを悲しみを隠す演技にしない（[アリア](../characters/aria.md)）。
- アリアとレオンの、互いに好意があって言い切れない関係を引き継ぐ。大事件だけで告白・交際・家族構成を決めない（[アリアとレオン](../relationships/aria-leon.md)、[物語・会話の制作指針](story-writing.md)）。
- 塔ごとに原因と解決が違う。世界規模の危機でも、一塔の復旧で全世界が直ることや、これまでの問題がすべて同じ敵の仕業だったことにしない（[第一章以後へ残す種](world-and-story.md#第一章以後へ残す種)）。

## 物語の芯（方向）

> 外の世界に憧れて旅をするアリアが、赤ん坊の頃に宿した星の力をめぐる危機に巻き込まれる。
> 自分の力も世界を脅かしかねない中で、レオンや仲間たちと、旅で知った人々の普通の暮らしを守ろうとする。

「世界を救うために生まれた少女」という使命から始めず、会いたい人と見たい景色がある少女の旅から、世界の問題へ広げる。

## アリアが外の世界へ向かう理由

### 家族に会いたい、同じ世界を見てみたい（方向）

動機の中心は、旅をしている家族に会いたいことと、その人が見ている世界を自分の目でも見たいこと。失踪事件や置き去りにされた怒りで組み立てず、故郷が嫌で逃げ出す話にもしない。

旅への憧れは本人の気持ちとして扱う。「星の力に呼ばれていたから外へ出たかった」と、後から本人の好奇心を置き換えない。

候補：

- 家族の旅の話を聞いて育ち、今度は自分が見つけた景色や出来事も話したくなる。家族の足跡を追うだけでなく、レオンや仲間が行きたい場所、自分の寄り道も増え、次第に自分たちの旅になる。
- 旅をしているのは植物の調査者の母親で、手紙や調査記録から新しい行き先がわかる。家族の旅を「アリアの髪の秘密を解くため」に一本化する必要はない。

未決：旅人が母親・父親・きょうだいなどの誰か。名前、職業、家族構成。便りが届くのか消息不明か、最後に会った時期と離れている期間。家族自身の旅の目的、赤ん坊の頃の出来事をどこまで知っているか、再会する時期。

### エルフの中では変わり者（方向）

エルフは住み慣れた場所での暮らしを好み、あまり外へ出たがらない。その中で、アリアと旅に出ている家族は外の世界に惹かれる変わり者。

候補：外の世界を敵視したり外出を禁じたりするより、森での暮らしに満ち足りていて遠方を旅する必要をあまり感じない文化とする。必要な交易や近隣との付き合いはあり、未知の土地を渡り歩くのは物好き、という温度なら既存の交易の導入と合う。全員が同じ性格であることや、他種族との敵対・隔離までは決めない（[種族などの制作案](world-and-story.md#種族などの制作案)）。

## 紫の一房と、赤ん坊の頃の流星

### 由来（方向）

アリアが物心つく前の赤ん坊の頃、すぐ近くに流星が落ちて星の力を浴びた。その名残が淡い紫の一房。普通の塔の灯りを浴びて起きることではなく、その時だけの珍しい現象。本人に出来事の記憶はなく、物心ついた時からこの髪色が当たり前だった。

本人にとっては昔からある外見の特徴だが、物語では星の力との特別なつながりを示す。由来を明かして終わらせず、後の困難や結末に関わらせる。

### 出来事の具体化（候補）

- 小さな星の欠片が近くに落ち、宿っていた力が一気に放たれ、辺りを紫の光が満たす。その後、一房だけが紫になり、生え替わっても同じ色が残る。
- 家族に連れられた、本人の覚えていない最初の旅の途中で起きる。家族から「赤ちゃんの時に星が落ちた」と聞いていて、本人はその景色を覚えていないことを残念がる。

未決：落下場所、同席者、欠片の大きさや残存、当日の被害、本人が由来を知っているか。髪が変わった出来事と、家族が現在の長旅へ出た時期を同じにする必要はない。

## 星の力ゆえの危機

### 王道の危機（好みの展開）

- アリアの力には、使い方次第で世界を滅ぼすほどの危険な可能性がある。
- 悪役に操られたり、利用されたりして、その使い方をさせられる。
- 力が強すぎて、本人の意思だけでは暴走を止められなくなる。

組み合わせてよいが、すべての採用や発生順は決めていない。敵の操作が暴走を招くのか、もともとの危険な性質を敵が利用するのか、別々の出来事にするのかは、能力の仕組みと合わせて検討する。

### 人物の願いに返ってくる困難（方向）

効かせたいのは、**アリアが見たくて旅をしてきた世界を、自分の力が壊してしまうかもしれない**というつながり。強い必殺技や一時的な体調不良だけで終わらせない。

アリアを救出されるだけの存在にせず、自分で望みを言い、判断し、仲間と解決へ動く場面を作る。レオンの支えも、行動を禁止する保護者役や、告白だけで全問題を解く役へ狭めない。

候補：

- 力のために行きたい場所へ近づけない、仲間を巻き込むのが怖くて足が止まる、誰かを守るために旅を続けられなくなる。王道の危機を小規模な困りごとへ置き換えるための制約ではない。
- アリアが一か所に残れば危機を抑えられる。旅の自由が脅かされる葛藤の一例で、最終的な自己犠牲の決定ではない。
- アリアは星の力を受け入れ、別のものへ渡せる。能力の一例で、破滅的な使い方や暴走の条件は別に設計する。

未決：能力の種類、発現時期、制御できる範囲、日常では問題がなかった理由、世界規模の破壊につながる条件。序盤の観察や採取の能力まで、後から星の特殊能力だったことにはしない。

## なぜ星の力が世界を支えているのか

### 本編で答えたい問い（方向）

宇宙の星の力がなぜこの世界で重要なのか、流星・塔・草木や石・アリアの力がどうつながるのかを、本編を通して明らかにする。仕組みの結論はまだない。

現在の世界・素材の共通ルールは [世界観と物語](world-and-story.md) を正とする。塔が夜の光を取り込んで蓄え、少しずつ放つ案や、光を蓄える植物・石の性質を土台にし、別の仕組みを重ねる場合は整合を確認する。

### 起源と危険性の説明（候補）

> 太古に降った星の欠片が、地上の土や石、草木へ力をもたらした。
> 今も夜空から同じ力が少しずつ届き、塔や素材がそれを暮らしに使える形で蓄えている。
> 薄まって世界に馴染んだ力は恵みになるが、流星が抱えるような濃い力は、ものの在り方を変えてしまう。
> 大量に解き放てば、大地や生き物も今の形を保てなくなる。

これなら「暮らしを豊かにしてきた力が、世界を壊して作り替える力でもある」とつなげられ、敵が世界を自分の望む形へ作り替えようとする案も組み合わせられる。アリアを星と地上の間をつなぐ存在にするかどうかは、ここから自動的には決めない。

## 結末は、星の力が残る方向

### 取り戻すのは、この世界の普通の暮らし（方向）

星の力を世界からなくして平和にする結末と比べ、**今作は危機を解決して星の力を残す**。永久に失われる結末より、こちらを優先する。

住民にとって星の力がある暮らしは普通。「不思議な世界を守る」という外からの見方だけでなく、灯りがともり、仕事に出かけ、物を届け、家へ帰れる、いつもの暮らしが戻ったと感じられる結末にする。

世界に星の力が残ることと、アリアが世界を滅ぼせるほどの力を持ち続けることは別。最終敵と今回の危機には今作で決着をつけ、続編のために問題を放置しない。

未決：アリアの力が失われるか、弱まるか、制御できるようになるか。紫の一房を残すか。最終的な選択と代償。

### 途中で、当たり前が一度失われる（好みの展開）

物語の途中で星の力が消滅するなどして、当たり前に享受していたものを自覚する。

候補：

- 夜空の星は見えているのに、地上へ力が届かなくなる。塔や石の蓄えがあるなら一斉に止まらず、蓄えや用途の違いに応じて影響が出る。
- 以前訪れた町で、夕方の荷車が来なくなる、店が早く閉まる、必要な物を届けられなくなる。最後に同じ場所で仕事や往来が戻り、世界規模の危機の解決が、知っている暮らしの回復として見える。

未決：完全な消滅、一時的な供給の断絶、敵による奪取、消滅寸前での阻止のどれにするか。どの案でも、アリアが力を使える理由や、再び星の恵みを受け取れる理由を用意し、都合よく復活させない。魔物・生き物・薬草・道具への影響も一括で決めない。

### 解決方法（候補）

- 日常の星灯は残し、世界を壊すほどの力を無理に引き出す仕組みだけを断つ。例として、特別な星の欠片を宇宙へ返し、操られて力を呼び込まされたアリアが、最後は自分の意思でその力を返す。
- アリア一人が受け止めていた力を、仲間の技術や各地の協力で別の受け皿へ移し、彼女がその場を離れられるようにする。受け皿の性質・限界・準備を途中から描く必要がある。
- 巨大な力を手放した後も、紫の一房が旅の名残として残る。

「危険な部分だけを都合よく消す」「終盤で突然別の装置が完成する」ではなく、途中の発見・失敗・協力の積み重ねから解決を用意する。

## 大きな流れのたたき台（候補）

章割りではない。出来事の組み合わせと順序を考えるための仮の流れで、特に危機と星の力の喪失の前後関係は未決。

| 段階 | 描きたいこと | 未決事項 |
| --- | --- | --- |
| 暮らしから旅へ | 家族への愛着と外の世界への憧れ。レオンとの仕事・寄り道が、仲間との冒険へ広がる | 家族の話を出す時期、遠くへ旅する具体的なきっかけ |
| 自分と星のつながり | 紫の一房、赤ん坊の頃の流星、星の力の正体を少しずつ知る | 最初の発現、知る順序、家族との再会 |
| 大きな危機 | 操り・利用・暴走によって、自分の力が世界を脅かしうると向き合う | 敵の目的と手段、アリアの判断、仲間の行動 |
| 普通を失いかける | 星の恵みがある日常を、失う・失いかけることで見直す | 実際に失われるか、原因・期間・影響範囲 |
| 危機を越えて暮らしへ | 星の力が残る世界へ着地し、今回の危機とアリア自身の願いに答えを出す | 解決の仕組み、代償、本人の力、最後に見せる行動 |

家族との再会を最終的な危機より前に置き、「憧れの人を追う旅」から「自分たちの行き先を選ぶ旅」へ進める案もある。再会時期は固定しない。

## 次に詰める問い

1. 普段の星灯、流星が抱える力、アリアに残った力はどう違い、なぜ今になって大きな危機につながるのか。
2. 敵は何を望み、なぜアリアの力が必要で、どのように操る・利用するのか。暴走との因果はどうするか。
3. 家族は誰で、どこまで事情を知っていて、どの時点で会えるのか。アリアの旅への憧れを損なわずに結びつけられるか。
4. 星の力は途中で本当に失われるのか。何が失われ、何が残り、どうやって暮らしが戻るのか。
5. 終盤でアリアは何を自分の意思で選び、仲間は何を担うのか。世界と本人に何が残り、何を手放すのか。

問いに答えが出たら、[区分と正本との分担](#区分と正本との分担) に従って正本へ移し、本書の該当箇所は方向と参照だけに縮める。
