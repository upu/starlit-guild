# 本編シナリオ案 — アリアの旅と星の力

[資料案内](../README.md) → [世界観・シナリオ](README.md) → 本編シナリオ案

2026-10-07の整理時点で、会話に出た本編の長期構想を残す検討メモ。完成したプロットや章割りではなく、方向性と候補を整理するための資料。

**本書の案を、現行設定やゲーム内で起きた事実として扱わない。** 世界・人物の設定の正本や各章のプロットは置き換えない。ユーザーが示した方向・好みと、会話中に出た具体化の提案を分ける。本書だけを根拠に、候補をすべて採用したり、公開済みの出来事を遡って変更したりしない。

対象は今作。次世代の主人公や後世の伝承を扱う続編の話は、今回の検討範囲から外す。

## 物語の芯

> 外の世界に憧れて旅をするアリアが、赤ん坊の頃に宿した星の力をめぐる危機に巻き込まれる。
> 自分の力も世界を脅かしかねない中で、レオンや仲間たちと、旅で知った人々の普通の暮らしを守ろうとする。

「世界を救うために生まれた少女」という使命を出発点にするのではなく、会いたい人と見たい景色がある少女の旅から、世界の問題へ広がる構成案。

## 話し合いの整理

| 区分 | 内容 |
| --- | --- |
| 今回の構想で共有した方向 | 家族に会いたい気持ちと旅への憧れ。外へ出たがらないエルフの中で、アリアと旅する家族は変わり者。物心つく前の流星と紫の一房。最後は世界に星の力が残り、普通の暮らしが戻る方向 |
| 好みとして挙がった展開 | 世界を滅ぼすこともできる力を悪役に利用される、操られる、強すぎる力が暴走する、といった王道の危機。どれを採るか、順序や因果は未決 |
| 展開の候補 | 物語の途中で星の力が一度失われ、当たり前だった暮らしが何に支えられていたかを知る。完全な喪失か、届かなくなるのか、寸前で止めるのかは未決 |
| 具体化待ち | 家族の人物像・消息・再会、星の力の起源、アリアの能力と限界、敵の目的、危機の仕組み、最終的な解決と代償 |

「共有した方向」も、本編シナリオを検討するための方針であり、既存資料の「採用済み」へ一括で移すものではない。

## 1. アリアが外の世界へ向かう理由

### 家族に会いたい、同じ世界を見てみたい

動機の中心は、旅をしている家族に会いたいことと、その人が見ている世界を自分の目でも見たいこと。

初めに挙がった「家族が旅に出て戻ってこない」という案を、失踪事件や置き去りにされた怒りだけで組み立てない。ユーザーが重視したのは、会いたい気持ちと旅への憧れ。故郷が嫌だから逃げ出す話にも寄せない。

家族の旅の話を聞いて育ち、今度は自分が見つけた景色や出来事も話したくなる、という描き方が候補になる。家族の足跡だけを追うのではなく、レオンや仲間が行きたい場所、自分が気になった寄り道も増え、次第に自分たちの旅になる。

旅への憧れは本人の気持ちとして扱う。「星の力に呼ばれていたから外へ出たかった」と、本人の好奇心を後から置き換えない方向で整理する。

### エルフの中では変わり者

エルフは、住み慣れた場所で暮らすことを好み、あまり外へ出たがらない、引きこもり気質のイメージ。その中でアリアと旅に出ている家族は、外の世界へ惹かれる変わり者にする方向。

具体化の案としては、外の世界を敵視したり外出を禁じたりするより、森での暮らしに満ち足りていて、遠方を旅する必要をあまり感じない文化とする。必要な交易や近隣との付き合いはあり、未知の土地を渡り歩くのは物好き、という温度なら既存の交易の導入とも合わせやすい。

ただし、これは種族文化を具体化する提案。全員が同じ性格であることや、他種族との敵対・隔離まで決めたものではない。

### 家族について、まだ固定しないこと

- 旅人が母親・父親・きょうだいなどの誰なのか。名前、職業、家族構成。
- 便りや人づての話は届くが帰ってこないのか、完全に消息不明なのか。最後に会った時期や別れている期間。
- 家族自身の旅の目的、赤ん坊の頃の出来事をどこまで知っているか、再会する時期。

母親を植物の調査者とする案、手紙や調査記録から新しい行き先がわかる案は出たが、決定していない。家族の旅をすべて「アリアの髪の秘密を解くため」に一本化する必要もない。

## 2. 紫の一房と、赤ん坊の頃の流星

### 由来として共有した方向

アリアがまだ赤ん坊で、物心がつく前、すぐ近くに流星が落ちて星の力を浴びた。その名残が淡い紫の一房、という案。

普通の塔の灯りを浴びれば起きることではなく、その時だけの珍しい現象にする。アリアには出来事の記憶がなく、物心ついた時から、この髪色が当たり前だった。

本人にとっては昔からある外見の特徴だが、物語上は、星の力との特別なつながりを示すものになる。その由来を明かすだけで終わらず、後の困難や結末に関わらせたい。

### 出来事の具体化案

小さな星の欠片が近くに落ち、宿っていた力が一気に放たれ、辺りを紫の光が満たす。その光を浴びた後、一房だけが紫になり、生え替わっても同じ色が残る。

「家族に連れられた、本人の覚えていない最初の旅」の途中に起きたとする案もある。家族から「赤ちゃんの時に星が落ちた」と聞かされていて、本人は、その景色を覚えていないことを残念がる、という人物描写も候補。

これらは具体化の例であり、落下場所、同席者、欠片の大きさや残存、当日の被害、本人が由来を知っているかは未決。髪が変わった出来事と、家族が現在の長旅へ出た時期を同一にする必要はない。

## 3. 星の力ゆえの困難

### 王道の危機を物語の中心へつなげる

ユーザーが好みとして挙げたのは、次のような展開。

- アリアの力には、使い方次第で世界を滅ぼすほどの危険な可能性がある。
- 悪役に操られたり、利用されたりして、その使い方をさせられる。
- 力が強すぎるため、本人の意思だけでは暴走を止められなくなる。

これらは組み合わせられるが、すべての採用や発生順を決めたわけではない。敵の操作が暴走を招くのか、もともとの危険な性質を敵が利用するのか、別々の出来事にするのかは、能力の仕組みと合わせて検討する。

物語として効かせたいのは、**アリアが見たくて旅をしてきた世界を、自分の力が壊してしまうかもしれない**というつながり。単なる強い必殺技や、一時的な体調不良だけで終わらせない。

### 人物の願いに返ってくる困難

力のために行きたい場所へ近づけない、仲間を巻き込むのが怖くて足が止まる、誰かを守るために旅を続けられなくなる、といった困難も補助案として出た。ただし、王道の操り・利用・暴走を、小規模な困りごとへ置き換えるための制約ではない。

アリアを救出されるだけの存在に固定せず、自分で望みを言い、判断し、仲間と解決へ動く場面を作りたい。レオンの支えも、行動を禁止する保護者役や、告白だけで全問題を解く役へ狭めない。二人の基本の関係は [アリアとレオン](../relationships/aria-leon.md) を参照する。

能力の種類、発現時期、制御できる範囲、日常では問題がなかった理由、世界規模の破壊につながる条件は未決。序盤の観察や採取の能力まで、後からすべて星の特殊能力だったことにはしない。

## 4. なぜ星の力が世界を支えているのか

### 答えを用意したい問い

宇宙の星の力がなぜこの世界で重要なのか、流星・塔・草木や石・アリアの力がどうつながるのかは、本編を通して明らかにしたい問い。仕組みの結論はまだ出していない。

現在の世界・素材の共通ルールは [世界観と物語](world-and-story.md) を正とする。塔が夜の光を取り込んで蓄え、少しずつ放つ案や、光を蓄える植物・石の性質を土台にし、別の仕組みを重ねる場合は整合を確認する。

### 起源と危険性の説明候補

会話では、次のような説明案が出た。

> 太古に降った星の欠片が、地上の土や石、草木へ力をもたらした。
> 今も夜空から同じ力が少しずつ届き、塔や素材がそれを暮らしに使える形で蓄えている。
> 薄まって世界に馴染んだ力は恵みになるが、流星が抱えるような濃い力は、ものの在り方を変えてしまう。
> 大量に解き放てば、大地や生き物も今の形を保てなくなる。

この説明なら、「暮らしを豊かにしてきた力が、世界を壊して作り替える力でもある」とつなげられる。敵が世界を自分の望む形へ作り替えようとする案も組み合わせられる。

ただし、上記はすべて説明候補。星の力の起源や作用、敵の思想として確定していない。アリアを星と地上の間をつなぐ存在にするかどうかも、ここから自動的には決めない。

## 5. 結末は、星の力が残る方向

### 取り戻すのは、この世界の普通の暮らし

星の力を世界からなくして平和にする結末と、危機を解決して星の恵みを残す結末を比較し、**今作は星の力が残る方がよさそう**という方向になった。

住民にとって星の力がある暮らしは普通。「不思議な世界を守る」という外からの見方だけでなく、灯りがともり、仕事に出かけ、物を届け、家へ帰れる、いつもの暮らしが戻ったと感じられる結末にしたい。

世界に星の力が残ることと、アリアが世界を滅ぼせるほどの力を持ち続けることは別。本人の力が失われる、弱まる、制御できるようになるなど、何が残るかは最終的な選択や代償と合わせて考える。紫の一房を残すかも未決。

### 途中で、当たり前が一度失われる案

ユーザーから、物語の途中で星の力が消滅するなどして、これまで当たり前に享受していたものを自覚する展開も挙がった。

具体化の一案は、夜空の星は見えているのに地上へ力が届かなくなること。既存の塔や石に蓄えがあるなら、一斉に何もかも止まるのではなく、蓄えや用途の違いに応じて影響が現れる。

以前訪れた町で、夕方の荷車が来なくなる、店が早く閉まる、必要な物を届けられなくなる。最後には同じ場所で仕事や往来が戻り、世界規模の危機の解決が、知っている暮らしの回復として見える。

完全な消滅、一時的な供給の断絶、敵による奪取、消滅寸前での阻止は、区別して選ぶ必要がある。どの案でも、アリアが力を使える理由や、再び星の恵みを受け取れる理由を用意し、都合よく復活させない。魔物・生き物・薬草・道具への影響も一括で決めない。

### 解決方法の候補

「日常の星灯は残し、世界を壊すほどの力を無理に引き出す仕組みだけを断つ」という案が出た。特別な星の欠片を宇宙へ返し、操られて力を呼び込まされたアリアが、最後は自分の意思でその力を返す、という具体例もある。

別の案として、アリア一人が受け止めていた力を、仲間の技術や各地の協力で別の受け皿へ移し、彼女がその場を離れられるようにする構成も出た。

どちらも未決。「危険な部分だけを都合よく消す」「終盤で突然別の装置が完成する」ではなく、途中の発見・失敗・協力の積み重ねから解決を用意する。最終敵と今回の危機には今作で決着をつけ、続編のために問題そのものを放置しない。

## 6. 大きな流れのたたき台

以下は章割りではない。出来事の組み合わせと順序を考えるための仮の流れであり、特に危機と星の力の喪失の前後関係は未決。

| 段階 | 描きたいこと | 未決事項 |
| --- | --- | --- |
| 暮らしから旅へ | 家族への愛着と外の世界への憧れ。レオンとの仕事・寄り道が、仲間との冒険へ広がる | 家族の話を出す時期、遠くへ旅する具体的なきっかけ |
| 自分と星のつながり | 紫の一房、赤ん坊の頃の流星、星の力の正体を少しずつ知る | 最初の発現、知る順序、家族との再会 |
| 大きな危機 | 操り・利用・暴走によって、自分の力が世界を脅かしうると向き合う | 敵の目的と手段、アリアの判断、仲間の行動 |
| 普通を失いかける | 星の恵みがある日常を、失う・失いかけることで見直す | 実際に失われるか、原因・期間・影響範囲 |
| 危機を越えて暮らしへ | 星の力が残る世界へ着地し、今回の危機とアリア自身の願いに答えを出す | 解決の仕組み、代償、本人の力、最後に見せる行動 |

家族との再会を最終的な危機より前に置き、その後は「憧れの人を追う旅」から「自分たちの行き先を選ぶ旅」へ進める案もあるが、再会時期は固定しない。

## 7. 既存の物語との接続

[第一章プロット](story-part-1.md) の入口は、村の交易の仕事と寄り道。最初から家族捜索や世界救済を任されていた話に置き換えない。第一章の自然発生の問題を、後の敵が仕組んだ陰謀へ遡及変更しない。

[アリア](../characters/aria.md) の観察・採取・好奇心や「見つけたものを、一緒に見たい」という軸を、特別な力に置き換えない。明るさをすべて悲しみを隠す演技にせず、寄り道や食事、仲間との時間を本当に楽しんでいる人物として残す。

[レオン](../characters/leon.md) とアリアの関係は、幼なじみで互いに好意があり、なかなか言い切れない二人という核を引き継ぐ。大事件を足すだけで告白・交際・その後の家族構成を決定しない。感情の描き方は [物語・会話の制作指針](story-writing.md) に従う。

各地の塔は原因や解決が異なるという既存の軸を残す。世界規模の危機を設定しても、一塔の復旧で全世界が直ることや、これまでの問題がすべて同じ敵の仕業だったことを前提にしない。公開済み第一章の終幕へ、家族・流星・最終敵の予告を追加する指示でもない。

場所・行路、章数、加入順、ステージ番号、クエストID、シーンID、ゲームシステムやセーブ仕様は本書で追加・変更しない。実装状況は [ゲーム仕様](../gameplay/README.md) 側で扱う。

## 8. 本筋と分けて残す補助案

会話中の提案を、共有した方向と取り違えないための控え。すべてを採用する必要はなく、ここにない別の案へ進んでもよい。

| 補助案 | 検討するときの位置づけ |
| --- | --- |
| 母親が植物の調査者で、手紙や記録が行き先を示す | 家族と旅の具体例。母親・職業・消息不明を確定しない |
| 家族に抱かれた最初の旅で流星に遭遇する | 赤ん坊の頃の出来事を具体化する例。家族の現在の不在と直結させない |
| アリアが星の力を受け入れ、別のものへ渡せる | 能力の一例。唯一の能力案ではなく、破滅的な使い方や暴走条件は別に設計する |
| アリアが一か所に残れば危機を抑えられる | 旅の自由が脅かされる葛藤の一例。採用必須でも、最終的な自己犠牲の決定でもない |
| 仲間が力を分散して受け止め、アリアを解放する | 解決の一例。受け皿の性質・限界・準備を途中から描く必要がある |
| 特別な欠片を星へ返し、巨大な力とのつながりを断つ | 星の恵みを残す終幕の一例。宇宙への返還や能力喪失は未決 |
| 紫の一房が、巨大な力を手放した後にも残る | 外見を旅の名残として残す例。終幕の髪色はまだ固定しない |

星の力が永久に失われる結末も比較したが、現在は「星の力が残る」方を優先する。続編案から、今作の登場人物の生死・婚姻・子孫・年数を逆算して確定しない。

## 9. 次に詰める問い

1. 普段の星灯、流星が抱える力、アリアに残った力はどう違い、なぜ今になって大きな危機につながるのか。
2. 敵は何を望み、なぜアリアの力が必要で、どのように操る・利用するのか。暴走との因果はどうするか。
3. 家族は誰で、どこまで事情を知っていて、どの時点で会えるのか。アリアの旅への憧れを損なわずに結びつけられるか。
4. 星の力は途中で本当に失われるのか。何が失われ、何が残り、どうやって暮らしが戻るのか。
5. 終盤でアリアは何を自分の意思で選び、仲間は何を担うのか。世界と本人に何が残り、何を手放すのか。

具体化して採用する際は、世界の共通ルールは [世界観と物語](world-and-story.md)、個人設定は人物資料、共通の関係性は関係性資料、出来事の順序は対象章のプロットへ反映する。採用した内容を本書と複数の正本へ重複して維持せず、本書の区分や参照先も更新する。
