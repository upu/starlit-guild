# 章ごとの戦力と到達時間

戦闘・育成バランスを調整するときの入口。第三章以降もこの文書に章を追加する。目標、実装上の測定結果、未設定事項を分けて扱う。計算式や敵の個別倍率は [戦闘バランス](combat-balance.md) が担当する。

## 時間と戦力の読み方

本書の測定はすべて **ゲーム本体の処理を時間を早送りして実行した、自動シミュレーション上の経過時間**。実行に数秒かかる処理でゲーム内の数十分を進めている。人が数十分・数時間操作した実測ではない。戦闘・回復・報酬・加入・育成は実装の `act` / `settle` を使う。

- **追加育成時間**：育成のために明示的に行った既読ステージの周回時間。攻略中や失敗した挑戦でも経験値を得るので、育成に寄与した時間の全量とは異なる。
- **章全体の時間**：その章の開始から最終ステージ達成・帰還会話読了まで。移動、作業、戦闘、全滅休憩、失敗した挑戦、追加育成を含む。会話の読書時間と判断・操作待ちは0として扱う。
- **通算到達時間**：新規開始から同じ状態を引き継いで到達する時間。異なるプリセットの測定値を単純に足さない。
- **戦力**：各人のLv・経験値、加入状況、装備、習得とセット中の技、共通装備・拠点強化、絆など。同じLvでも次のLvまでの距離や所持金が違うため、章の接続は状態全体を使う。

第二章終了時の能力（採取／護衛／討伐、最大HP）は、アリア63／30／41・HP100、レオン22／51／69・HP142、ミラ43／59／22・HP158。これは装備込みの現行計算結果。所持金・絆・習得技・読了履歴は同コマンドの各章 `start` / `end` 出力で確認できる。次章の試走ではこの表からセーブを再構成せず、関数が返す状態全体を引き継ぐ。

固定の方針での一例であり、最短時間や全員の必須育成時間ではない。第一章は3分以内に終わらなければ既読ステージで5分育成し、店が開いたら二人分の武器と革の上着を購入。第二章も3分で帰還し、既読の2-5→2-4→2-2→2-1の優先順で5分育成して再挑戦する。手助け・追加技の購入は使わない。会話は即読了としている。

## 次の章を調整する手順

1. 上の章別表で前章の終了条件と対象章の目標を確認する。未設定なら開始／終了戦力、追加育成、章全体の目標を提案する。測定値を合意済み目標に昇格させない。
2. 前章の状態全体を渡す連続シミュレーションと、ボス・技・装備を比較する独立シミュレーションを用意する。次章開始用プリセットを作る場合は、通しデータとの差を明記する。
3. [戦闘バランスの調整手順](combat-balance.md#今後の調整手順) に沿って変更前後を比較する。作業量を増やした理由だけで経験値を自動的に増やさず、到達戦力・時間から必要性を判断する。
4. 通し測定で章境界と通算時間を再測定し、本書の対象章の開始・終了・時間・測定対象版を更新する。対象章の終了戦力が変わったら次章の開始条件も確認する。未実装の章は未設定のまま、検討に使う基準だけを更新する。
5. テスト、型検査、lint、build、旧セーブ互換と前章への影響を確認する。実機確認の有無を分けて報告する。

### 新しい章の記録書式

- 対象章／測定対象バージョン・PR：
- 目標の状態：提案／合意済み／未設定。合意内容と根拠：
- 開始・終了戦力：メンバー別Lvと経験値、装備、技、強化、加入・読了条件：
- 時間の目標：追加育成／章全体／通算到達：
- 自動シミュレーション結果：追加育成／その他の経過時間／章全体／通算開始・終了：
- 再現コマンド・入力データ・周回方針・手助け・技の条件：
- 苦戦と余裕の比較、前章終了→対象章開始→次章開始の確認：
- 人が遊んだ実測：未確認、または端末・条件・時間・体感：
