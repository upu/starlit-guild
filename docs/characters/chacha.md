# チャチャ `chacha`

キャラID: `chacha`

[キャラクター一覧・設定の扱い](README.md) · [物語・会話の制作指針](../story-writing.md)

## 制作の核・書くときの手がかり

- 天使族の少女。おっとりした話し方と、しっかりしていて柔らかい体つき。ユーザーの修正により筋肉の輪郭や腕の盛り上がりを抑える。外見は `a26705_bust_2.jpg` を最優先し、長い橙色の髪、赤いリボン、銀の鎧と青い服、白い翼、大剣。
- お茶と筋肉を愛する肉弾派。天使は本来この戦い方に向かないが、本人は筋力で押し通す。穏やかな天使の治癒役へ寄せない。
- 一人称は「わたし」。台詞の間がゆっくりで「〜ですよぉ」「〜しましょうねぇ」。考え込む前に岩を持ち上げる。茶器を扱う指先は丁寧。

## 採用済み

- **従来記録のみ**：加入4話、専用クエスト `join-chacha`、日常 `camp-chacha-tea`、道中会話、拠点の筋トレ。6件達成で出会い、茶葉と資材を用意して茶屋への護衛を達成すると加入する。既存6人の加入連鎖とは独立。[従来モード](../gameplay.md#従来モードの扱い)のため、ここへ新しい場面を足さない。
- **新しい物語**：まだ登場していない。加入の有無・時期・理由は未定で、従来記録の加入条件を引き継がない。
- 特技「蒸らし三分、全力一振り」は前衛の大剣攻撃。4回ごとの戦闘攻撃を2倍にする。回復魔法は使わない。
