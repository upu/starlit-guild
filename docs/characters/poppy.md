# ポピー `poppy`

キャラID: `poppy`

[キャラクター一覧・設定の扱い](README.md) · [物語・会話の制作指針](../story-writing.md)

森の錬金術師。採取と調合が得意。

## 採用済み

- 失敗した薬も「新しい味」と言い張る研究家。
- 調合や薬草園の世話に夢中になる。
- アリアとは森の恵みを分け合い、調合の「かも」に突っ込まれる。

## 書くときの手がかり

試したいことを勢いよく提案する。失敗から次の可能性を見つける前向きさがある。何でも薬で解決させず、試行錯誤そのものを描く。

## 人物を深める軸

口では強気でも、仲間に飲ませる薬は繰り返し確かめる。実験への好奇心と仲間への配慮が同時に見える場面を作る。

一人称は「私」。調合の失敗を、仲間を傷つけても気にしない性格へ拡大しない。

## 現行の加入エピソード

削除した従来モードの加入エピソードの記録。新しい物語での加入理由・順序の確定事項ではない。条件・進行は [仲間加入](../recruitment.md) を参照する。

- 出会いで見える事情：枯れた薬草園を再生しようと、強がりながら試作を続ける
- 準備中に分かる一面：失敗も記録すると言ったのに、落ち込むと消したくなる
- 加入を選ぶ理由：成功だけでなく試行錯誤を受け止めてくれた旅団で、安心して渡せる薬を作りたい
