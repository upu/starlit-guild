# レオン `leon`

キャラID: `leon`

[キャラクター一覧・設定の扱い](README.md) · [物語・会話の制作指針](../story/story-writing.md)

旅路を守る剣士。魔物との戦いが得意。

## 採用済み

- 地図や道筋を丁寧に確かめる。現地で仲間が気づいたことも確かめ、必要なら段取りを見直す。
- 人の荷物や足元を自然に気にかける。自分の望みを聞かれると、言葉を選びすぎる。
- アリアの好物や昔からの癖を覚えている。大切にする理由を「幼なじみだから」で済ませがち。
- アリアのために席を空け、好物を取っておく。明日や明後日も一緒にいるつもりで話す。
- 蜂蜜のお菓子が好き。帰ったら食べたいものとして、アリアが以前作ったスープを挙げる。
- 胡桃のパンを気に入っている（`hilltop-picnic-return`）。遠出には厚手の布を余分に持ち、冷えたアリアの肩へ理由を言わずに掛ける（`moss-night-road-departure`）。詳しくは [二人の関係性](../relationships/aria-leon.md#念のための二枚目)。
- アリアの贈る青晶石の欠片を内ポケットにしまう。

## 書くときの手がかり

一人称は「俺」。アリアを呼ぶときは「アリア」と名前で呼び、「お前」は使わない。ほかの仲間にも名前か自然な主語の省略を使う。簡潔で具体的な言葉を使う。説明より先に手を差し出したり、灯りをふたりの間へ寄せたりする。

### 慣れない相手には敬語・丁寧語

幼なじみのアリアにはタメ口だが、**知り合って間もない相手や仕事の相手には「です・ます」を使い、名前にも「さん」を付ける**。第一章では店主・塔の管理人・作業者へ敬語で話す。第二章のミラは出会って間もない同行者なので、章を通して「ミラさん」と丁寧語のままにする。仲間になったことを理由に自動で崩さない。

崩れるのは緊迫した場面だけ。2-2でミラが倒れた瞬間だけ「ミラ！」と呼び捨てになり、落ち着くとすぐ丁寧語へ戻る。戦闘中の短い指示も素の言葉でよい。一度だけ崩れてすぐ戻る形で、「とっさには動けるが、距離はまだ縮んでいない」人として描く。

口癖も敬語形へ持ち込む。「念のためです」のように、相手が変わっても同じ癖が出るようにする。呼び方が「ミラ」へ変わる時期は第二章では決めず、後の章の手札として残す。

不器用でも、相手を傷つける冷たさにはしない。アリアの希望や能力を尊重し、「守る」を理由に彼女の行動を支配しない。時折、本人にも予想外なほど率直な返事が出る。

### 口癖・台詞の型

- 準備や気遣いを説明するときの口癖は「念のためだ」。替えの道具や帰り道の確認だけでなく、アリアの好物を用意したことなど、自分が楽しみにしていた気持ちを隠す少し苦しい理由にも使える。
- 「遠いとは言った。嫌だとは言ってない」のような「〇〇とは言った。△△とは言ってない」という返しが似合う。反対しているように見えて、実際には行ける方法を考えているときに使う。理屈っぽくなりすぎないよう、アリアに意図を早合点された場面などに絞る。
- 困難な場面では「心配はしてる。無理だとは思ってない」が決め台詞候補。心配することと相手の力を信じることを両立させ、アリアの行動を支配しないレオンの姿勢として使う。
- 普段の「念のためだ」を重ねたうえで、節目では「念のためじゃない。」と、いつもの言い訳を自分から外す率直さを効かせる。外した先を言い切らせず、続きはアリアの反応と間で見せる。2-9末尾で具体化済み（`medicine-road-home-return`）。
- 第二章では「念のためだ」と「〇〇とは言った。△△とは言ってない」を普段の掛け合いで積極的に繰り返し、口癖として覚えてもらう。山場では「心配はしてる。無理だとは思ってない」を効かせる。全ての台詞へ機械的に入れず、短く具体的な話し方の中で反復と崩しを使う。場面は [第二章計画](../story/story-part-2.md) の合意済み会話案を参照する。

公開済み第一章では、自分の村の荷物を持ち、アリアと待ち合わせて交易先の街へ行く。塔への寄り道では自分も坂からの景色を楽しみにし、道順と帰る時刻を考えてくる。苔灯の光の弱まりに気づき、比較の道具と記録を用意し、管理図から古い水路を見つける。共通の出来事と根拠は [二人の関係性](../relationships/aria-leon.md#関連するプロット実装) を参照する。

### 飲酒の描写（制作方針）

レオンはまだ酒を飲める年齢ではない。具体的な年齢や土地の基準は定めず、アリアとともに果実水などを選ぶ。[第四章4-3](../story/chapter-four-script.md#4-3-醸造の町ブレッカ) では、仕事を理由にたまたま酒を断る大人として描かない。

## 人物を深める軸

### アリアがおいしそうに食べる姿

アリアがおいしそうに食べる様子を見るのが好きで、たくさん食べてほしいと思っている。彼女の分を大きく切る、追加を持ってくる、食べた感想を待つ、といった行動へ表す。「念のためだ」は、多めに用意した本当の楽しみを隠す理由にもなる。本人の内心を地の文で解説せず、アリアの表情を見てから自分も食べ始める間などで見せる。

満腹だと言われたら勧めず、自分も一緒に食事を楽しむ。具体的な食事のやり取りは [第二章計画の2-1](../story/story-part-2.md#2-1-お昼を持ってあの坂へ)、二人が分け合う関係は [二人の関係性](../relationships/aria-leon.md#食事を分ける時間) を参照する。

### 背負いすぎる備え

周囲の期待に応えようと背負いすぎる。アリアに助けを求めることで、「自分だけが守らなければ」という構えが少し緩む。

計画や慎重さが過剰になる制作案を加える。アリアのフォローに慣れて「念のため」が増え、準備や荷物を抱え込みすぎる。地図と現地で得た情報を照らし合わせ、調べた予定でも相手の発見によって更新できる。
