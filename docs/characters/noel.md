# ノエル `noel`

キャラID: `noel`

[キャラクター一覧・設定の扱い](README.md) · [物語・会話の制作指針](../story-writing.md)

旅する吟遊詩人。歌で仲間を支える。

## 採用済み

- まだ見ぬ旅団の伝説を、一番近くで歌いたい。
- 拠点で新しい歌を練習する。
- ルナの話す星の声から、次の歌を思いつく。

## 書くときの手がかり

人の話や風景を受け止め、歌の題材を見つける。日常では素直な短い返事もする。全発言を詩や大仰な比喩にしない。

## 人物を深める軸

仲間を歌にする側でありながら、自分もその物語の一員として覚えていてほしい。自分のことを歌われたとき、いつもの言葉が出なくなる。

一人称は「私」。

## 現行の加入エピソード

削除した従来モードの加入エピソードの記録。新しい物語での加入理由・順序の確定事項ではない。条件・進行は [仲間加入](../recruitment.md) を参照する。

- 出会いで見える事情：旅団の歌を作りたいが、歌い手の自分を物語の外に置く
- 準備中に分かる一面：板運びのような地味な手伝いも仲間に覚えてもらえると気づく
- 加入を選ぶ理由：自分の名前も呼ばれる場所で、「私たちの旅」を歌いたい
