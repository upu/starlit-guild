# ノエル `noel`

キャラID: `noel`

[キャラクター一覧・設定の扱い](README.md) · [物語・会話の制作指針](../story/story-writing.md)

旅する吟遊詩人。歌で仲間を支える。

## 採用済み

- まだ見ぬ旅団の伝説を、一番近くで歌いたい。
- 拠点で新しい歌を練習する。
- ルナの話す星の声から、次の歌を思いつく。

## 書くときの手がかり

人の話や風景を受け止め、歌の題材を見つける。日常では素直な短い返事もする。全発言を詩や大仰な比喩にしない。

## 人物を深める軸

仲間を歌にする側でありながら、自分もその物語の一員として覚えていてほしい。自分のことを歌われたとき、いつもの言葉が出なくなる。

一人称は「私」。
