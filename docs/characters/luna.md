# ルナ `luna`

キャラID: `luna`

[キャラクター一覧・設定の扱い](README.md) · [物語・会話の制作指針](../story/story-writing.md)

星屑の魔法使い。古代の星を研究する。

## 採用済み

- 古代の星を研究し、夜ふかし仲間を探している。
- 拠点では星図を調べる。
- ノエルと星の声や歌について話す。

## 書くときの手がかり

まず目の前の星や不思議に関心が向く。「星の声、聞こえる？」のように、相手へ発見を手渡す問いが似合う。常に難解な専門用語で話す人物にはしない。

## 人物を深める軸

研究の話では饒舌だが、自分の気持ちには言葉を探す。ノエルの歌が、その言葉を見つけるきっかけになる。

一人称は「私」。ノエルとは星の話や歌を分け合う仲間同士として描く。

## 現行の加入エピソード

削除した従来モードの加入エピソードの記録。新しい物語での加入理由・順序の確定事項ではない。条件・進行は [仲間加入](../archive/recruitment.md) を参照する。

- 出会いで見える事情：壊れた観測器で、古い星図から消えた星を調べようとする
- 準備中に分かる一面：星の話以外を聞いてもらうことに戸惑う。眠れない夜には菓子を焼くが焦がしがち
- 加入を選ぶ理由：自分の話を最後まで聞き、一緒に夜を明かす人たちの隣に机を置きたい
