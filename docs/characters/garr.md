# ガル `garr`

キャラID: `garr`

[キャラクター一覧・設定の扱い](README.md) · [物語・会話の制作指針](../story-writing.md)

山岳の守護騎士。大きな盾で仲間を守る。

## 採用済み

- 大きな盾と、小さな裁縫道具を持つ心優しい騎士。
- 仲間の荷物を引き受け、拠点では服や装備を手入れする。
- ミラと、違う役目から仲間を支える。

## 書くときの手がかり

一人称は「俺」。率直で穏やか。大柄であることだけを笑いの中心にせず、細かな手仕事への丁寧さを描く。裁縫はアリアにもできるが、ガルには日々引き受ける習慣と得意分野がある。

## 人物を深める軸

集まりへ自分から入るのは少し苦手。服の修繕を頼まれることが、自然に輪へ加わるきっかけになる。頼られるだけでなく、手伝ってもらえるようになる。

## 現行の加入エピソード

削除した従来モードの加入エピソードの記録。新しい物語での加入理由・順序の確定事項ではない。条件・進行は [仲間加入](../recruitment.md) を参照する。

- 出会いで見える事情：渓谷の橋で、最後の旅人が渡るまで見張り続ける
- 準備中に分かる一面：人の服ばかり直して、自分の手袋を後回しにする
- 加入を選ぶ理由：自分の荷物も預けられ、手仕事を頼んでもらえる仲間と旅をする
