# メリル `merrill`

キャラID: `merrill`

[キャラクター一覧・設定の扱い](README.md) · [物語・会話の制作指針](../story-writing.md)

## 制作の核・書くときの手がかり

- ドライアドの女の子。食いしん坊を超えた悪食。エルフの耳、小動物、魔物にも食欲を向け、魔物は実際に食べる。「食べたがるだけ」「普通の料理好き」へ薄めない。
- 悪人ではないが、食欲のために旅人の邪魔をする敵役。相手の困惑と、本人の悪気のなさがずれている。残虐さを楽しむ人物にはしない。
- 緑の髪、緑の目、花飾り、赤いリボン。本人の左腕だけに、前腕から手の甲・全指の指先まで甲側を覆うガントレットを装備する。手のひらと指の腹は開いている。装具そのものが琴で、弦は前腕の手の甲につながる面に張られ、手のひら側・腕の内側には張らない。右腕・右手には籠手を着けず、素手で演奏する。`a10777_zen_2.jpg` を装具の形の優先資料とする。独立したU字の竪琴や、籠手に後付けした小型ハープとして描かない。踊りながら、右手で左腕のガントレット表面の弦を弾く吟遊詩人。詠唱のために立ち止まる魔法使いとは動きが違う。
- マッドハロウィンの一員。一人称は「私」。食感・匂い・次に食べたい物を率直に話す。拒否を聞いた直後に、別の品を提案する。

## 採用済み

- **従来記録のみ**：`midnight-snack` の出発・帰還、`puppet-midnight` の帰還。魔物を食べる、耳を断られた話、小動物を追う、プティの人形をかじろうとする。加入はしない。[従来モード](../gameplay.md#従来モードの扱い)のため、ここへ新しい場面を足さない。
- **新しい物語**：まだ登場していない。珍しいものの噂を聞いて食べに来る絡みは [世界観の将来の種](../world-and-story.md) の候補で、登場する章は未定。

## メリルの描画時の補足

立ち絵は演奏中に固定しない。腕と手首が自然につながる、力の抜けたポーズを優先する。左腕の籠手の構造は上記の設定を維持。日常スチルでは籠手を外してもよく、「試飲役には向かない」は両腕・両手とも籠手を着けない。苦い薬をすでに飲んでしまったギャグ場面へ変更し、台詞とスチルの出現箇所も揃える。
