# 第二章計画：山向こうへ薬を届ける

第一章公開後に進める第二章の制作資料。既存資料の「第一部／第二部」と、この計画の「第一章／第二章」は同じ区切りを指す。章の正式名称、ステージ名・数・ID、台詞、習得レベルや効果量は未確定。以下の物語・育成機能は未実装。

[資料案内](README.md) · [世界観](world-and-story.md) · [執筆指針](story-writing.md) · [第一部プロット](story-part-1.md) · [キャラクター一覧](characters/README.md)

## 合意した方向

- ミラと出会い、山向こうへ薬を届ける冒険を第二章の本筋にする。薬草の採取依頼を入口に、街から山道、集落へ行動範囲を広げる。
- ミラを最初の新しい仲間とする。アリアとレオンに加えた三人の冒険を早めに体験できる構成にする。プティは山道で出会う敵役で、加入しない。他の仲間の加入順は未定。
- プティの大小の人形によって、山賊の大きさに関する証言が食い違う。甘いものを根こそぎ奪う「Trick or Treat」の騒ぎを薬の配達に絡める。今回はゴーレムも人形として使役する。
- この世界ならではの自然・道具・暮らしを、採取と配達の出来事で紹介する。配達と通行妨害は章内で解決し、世界の由来には後へ残せる余地を置く。
- 人格的な成長や欠点の克服を、この章の到達目標にしない。同行するほど人物のとがったところや、繰り返しトラブルを生む癖が分かる楽しさを優先する。能力の育成とは分ける。
- 育成はレベルによる技の習得とセットから始める。アクティブ1枠、パッシブ1枠。スキルポイントとスキルツリーは今回解放しない。

## 本編の大まかな流れ（制作案）

本編7〜9ステージ程度を目安とする。下表は場面の流れであり、そのままクエスト数やステージIDを確定するものではない。

| 場面 | 出来事 | 場面の役目 |
| --- | --- | --- |
| 街の薬草依頼 | ミラが薬の材料集めを依頼する。アリアとレオンが採取に出る | 頼れる依頼者としてミラを紹介し、アリアの採取の得意さを見せる |
| 二度目の訪問 | 薬草を届けると、報酬と二人への傷薬を用意したミラが過労で倒れる。山向こうへの薬が残っている | 「この人を放っておけない」を同行の動機にする |
| 山賊の噂 | 山道の聞き込みで「子どもほど小さい」「荷車より大きい」と証言が割れる。甘いものを奪われた点だけは一致する | 正体を先に明かさず、後で両方の証言が正しかったと分かる仕込み |
| 山道の小さな影 | 小さな人形が菓子を要求する。道標のすり替えや荷物への回り込みが起きる | プティの人形芝居と妨害を実際の旅で体験する |
| 大きな山賊 | 同じように菓子を求める巨大なゴーレムが現れる | 大小の証言を回収し、ゴーレムを生活の道具としても見せる |
| プティとの対面 | 薬に添える甘い蜜まで狙われ、荷物を取り戻すために人形たちと対決する | お菓子狙いが配達の障害になる。プティを大陰謀の首謀者へ変えない |
| 山向こうへの配達 | 薬を届け、ミラが治療し、二人も仕事を手伝う | 戦闘の勝利だけで終わらず、薬が暮らしに役立つところまで描く |
| 帰り道 | 次の往診も同行することになる。ミラの過剰な献身も、プティのいたずら好きも残る | 三人での今後の冒険につなぐ。全員が反省して無難になる結末にしない |

ミラは倒れたまま即座に戦闘へ連れ出すのではなく、休ませて支度を整えた後に同行する。仮同行と正式加入の切り替え位置は台本と進行設計で決める。最後だけ加入して一緒に遊べない構成にはしない。

薬草の依頼、配達の支度、三人での冒険、プティの妨害を一つの進行に結ぶ。旧加入実装の資材・希少素材集めを機械的に追加しない。章の最終達成条件と再挑戦時の扱いは実装時に設計する。

## 人物と関係性の担当資料

- [ミラ](characters/mira.md)：行きすぎた献身、自分の不調の扱い、繰り返し倒れる描写、お茶へのこだわり。
- [プティ](characters/pumpety.md)：大小の人形、ゴーレムへの仕草、お菓子の要求。所属は [マッドハロウィン](factions/mad-halloween.md)。
- [アリア](characters/aria.md)：採取とレンジャーの得意分野。迷子による一時離脱・意外な場所での復帰は将来のネタで、今回は行わない。
- [レオン](characters/leon.md) と [二人の関係性](relationships/aria-leon.md)：第一章の親しさと癖を引き継ぐ。告白、交際、同居を自動的に成立させない。

第一章末尾の「お昼を持って坂へ行く約束」は、第二章途中の短い日常話で描く候補。仲間の加入後も二人だけの時間を残す。具体的な配置は未定で、公開済み第一章の終幕へ新しい伏線や来客を足さない。

## 世界観を見せる出来事

素材や道具の性質は [世界観の第二章制作案](world-and-story.md#第二章で見せる自然と道具制作案) を正本とする。

- 薬草採取でアリアの知識、調薬と配達でミラの知識を見せ、魔力を蓄える自然の性質が生活に使われていることを伝える。
- ゴーレムを珍しい敵としてだけ見せず、地域の人に用途の分かる道具として描く。その使い方をプティが人形芝居へ曲げている。
- 石の印と塔の管理図の似かよりは後に残す謎の候補。第一章で印が画面や台詞に出たことにはせず、第二章で記録を見比べる場面を用意してから示す。共通の製作者や古代文明の真相は確定しない。

前の苔の事件をプティの仕業へ変更しない。苔の人工栽培、別の塔の修復、世界救済の使命を第二章の必須要素にしない。

## 成長・解放要素の計画（未実装）

### 第二章で導入する範囲

| 項目 | 合意した方向 | まだ決めないこと |
| --- | --- | --- |
| 基礎成長 | レベルアップで能力が伸び、新しい技を覚える | 習得レベル、能力値、章の想定レベル |
| アクティブ | 一人1枠。セットした技を戦闘・採取など対応する状況で自動使用する | 技ごとの発動間隔、演出、細かな条件 |
| パッシブ | 一人1枠。セット中は追加操作なしで常時有効 | 効果量、重複計算、対象が本人か隊全体か |
| 習得とセット | 枠数より多く習得できる。外しても忘れず、習得済みの付け替えは無料 | 冒険中の変更と効果反映のタイミング |
| 解放量 | まず既存技に新しい選択肢を足す。パッシブは二つから一つを選ぶ程度 | 全候補を第二章で習得させるとは決めない |
| 仲間 | ミラの同行で回復を含む三人の役割を体験する | 編成操作の範囲、正式加入条件 |

「アクティブ」はプレイヤーの手動ボタンを意味しない。現在の手助け・必殺と、セットして自動使用する技を混同しない。パッシブも未セットのものまですべて有効にはしない。

アリアの植物の知識など、人物の得意分野は装備枠の有無で消えない。採取スキルはその働きを強める選択として扱う。現在のレベル・装備・連携を土台にし、連携を新規解放機能として重ねて説明しない。

### 技の候補（名前・効果とも制作例）

| 人物 | アクティブ候補 | パッシブ候補 |
| --- | --- | --- |
| アリア | 二連矢、複数を狙う矢、丁寧な採取 | 野草の目利き：薬草回収量アップ／狩人の狙い：会心率アップ |
| レオン | 踏み込み、かばう | 堅実な備え：被ダメージ軽減／剣の心得：剣の攻撃力アップ |
| ミラ | 一人への大きな回復、全員への小さな回復 | 丁寧な手当て：回復量アップ／休息の心得：隊の休憩中の回復強化 |

例えばアリアの「二連矢＋野草の目利き」は戦いながら採取、「採取の技＋野草の目利き」は素材集め、「二連矢＋狩人の狙い」は討伐へ寄せられる。上位の技が常に旧技の完全な上位互換になる構成は避ける。

会心やかばうを含め、表は既存戦闘にすべて実装済みという意味ではない。採用する効果は実装時に必要な処理と表示を確認する。

### 将来の解放候補

- パッシブを2枠へ拡張し、既に覚えた能力を組み合わせる。2枠目の解放は第二章の必須内容にしない。さらに枠を増やすかは未定。
- スキルポイントとスキルツリー。振り直しにはお金か継続入手可能なアイテムを使う方向。習得技の無料の付け替えとは別の操作であり、具体的な費用・入手先は未定。
- レアな採取物の発見率アップ。通常回収量とレア狙いの選択が成立する素材用途を用意してから検討する。今回は通常の回収量を先に扱う。
- ミラの「自分のHPが少ないほど回復効果が上がる」固有パッシブ。献身を戦い方に表す候補に留め、瀕死維持が常に最適になる仕様は今回採用しない。

### 補助要素と今回の対象外

山道向け・ミラ向けのショップ装備追加と、小さな休憩場所での日常会話は制作候補。複数隊の同時運用、大規模な拠点建設、調合・栽培システム、新しい専用通貨の乱立は今回の必須範囲から外す。ポピー加入＋調合を主役とする案は今回採用せず、後の章の材料として残す。
